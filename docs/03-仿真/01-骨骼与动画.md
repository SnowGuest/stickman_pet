# 骨骼与动画

> 上级：[文档中心](../README.md) · 领域：仿真层
> 覆盖：骨骼数据、编译校验、FK、姿态表示、剪辑格式、采样、混合、事件、IK。
> 物理如何消费这些数据见 [物理与抓取](02-物理与抓取.md)。

---

## 1. 职责与边界

**做**：定义骨骼拓扑与静止姿态；把"相对角"解算成世界关节坐标；加载/采样/混合动画；提供 IK 修正。
**不做**：不做物理积分（Solver）、不做绘制（Renderer）、不读窗口/鼠标。

依赖方向：`AnimLibrary → PoseSampler → PoseBlender → RigState`；`IkLayer` 在 `RigState` 之前运行。

## 2. 骨骼数据模型

```gdscript
class_name BoneDef extends Resource

@export var id: StringName
@export var parent: StringName = &""            # 空 = 直接挂骨盆
@export var start_joint: StringName
@export var end_joint: StringName
@export var length: float = 20.0                # 世界单位（1x 缩放）
@export var rest_abs_deg: float = 0.0           # 静止绝对角（度）
@export var limit_lo_deg: float = -180.0        # 相对静止角的限位
@export var limit_hi_deg: float = 180.0
@export var mass: float = 1.0
@export var width: float = 3.0                  # 线宽
@export var depth_layer: int = 0                # -1 后 / 0 中 / 1 前 / 3 头
@export var mirror: bool = false                # true 时限位与弯曲方向取反

# compile() 填充，禁止手写
var index := -1
var parent_index := -1
var start_idx := -1
var end_idx := -1
var rest_rel := 0.0                             # 弧度
var lo := 0.0
var hi := 0.0
```

```gdscript
class_name RigDefinition extends Resource

@export var bones: Array[BoneDef] = []
@export var joints: PackedStringArray = []
@export var head_radius: float = 18.0
@export var base_scale: float = 1.25

var joint_index := {}
var topo_order: PackedInt32Array
```

### 2.1 拓扑表

13 骨、14 关节（pelvis 为根关节）。

| id | parent | start_joint | end_joint | length | 质量 | 静止绝对角 | 限位（相对） |
|---|---|---|---|---|---|---|---|
| spine | — | pelvis | chest | 30 | 6.0 | -90° | ±22° |
| neck | spine | chest | neck_top | 8 | 0.6 | -90° | ±30° |
| head | neck | neck_top | head_top | 10 | 3.5 | -90° | ±25° |
| upper_arm_l | spine | chest | elbow_l | 22 | 1.1 | 96° | ±165° |
| forearm_l | upper_arm_l | elbow_l | hand_l | 20 | 0.9 | 100° | -150°..0° |
| upper_arm_r | spine | chest | elbow_r | 22 | 1.1 | 84° | ±165° |
| forearm_r | upper_arm_r | elbow_r | hand_r | 20 | 0.9 | 80° | -150°..0° |
| thigh_l | — | pelvis | knee_l | 26 | 2.6 | 94° | -100°..45° |
| shin_l | thigh_l | knee_l | ankle_l | 24 | 1.9 | 90° | -150°..0° |
| foot_l | shin_l | ankle_l | toe_l | 10 | 0.5 | 0° | ±40° |
| thigh_r | — | pelvis | knee_r | 26 | 2.6 | 86° | -100°..45° |
| shin_r | thigh_r | knee_r | ankle_r | 24 | 1.9 | 90° | -150°..0° |
| foot_r | shin_r | ankle_r | toe_r | 10 | 0.5 | 0° | ±40° |

> 角度约定：+X 右、+Y 下，正角顺时针。"向上"是 -90°。
> `thigh_*` 的 parent 为空，表示相对骨盆（root_angle）；`upper_arm_*` 的 parent 是 spine，`rest_rel` 落在 ±180 附近，插值必须用最短路径归一化。
> 数据文件：[assets/rigs/stickman.json](../../assets/rigs/stickman.json)；派生值与校验见 [README](../../assets/rigs/README.md)。

### 2.2 编译校验

```gdscript
func compile() -> void:
    joint_index.clear()
    for i in joints.size():
        joint_index[joints[i]] = i

    topo_order.clear()
    for i in bones.size():
        var b := bones[i]
        b.index = i
        assert(b.length > 0.01)
        assert(b.mass > 0.0)
        assert(joint_index.has(b.start_joint) and joint_index.has(b.end_joint))
        b.start_idx = joint_index[b.start_joint]
        b.end_idx = joint_index[b.end_joint]

        b.parent_index = -1
        var parent_abs := 0.0
        if b.parent != &"":
            for j in i:                                  # 父必须在前
                if bones[j].id == b.parent:
                    b.parent_index = j
                    parent_abs = bones[j].rest_abs_deg
                    break
            assert(b.parent_index >= 0, "父骨骼必须在子骨骼之前")
        b.rest_rel = deg_to_rad(wrapf(b.rest_abs_deg - parent_abs, -180.0, 180.0))

        var s := -1.0 if b.mirror else 1.0
        b.lo = deg_to_rad(minf(b.limit_lo_deg, b.limit_hi_deg)) * s
        b.hi = deg_to_rad(maxf(b.limit_lo_deg, b.limit_hi_deg)) * s
        topo_order.append(i)
```

校验失败直接 `assert` 崩溃（开发期）；发布版降级为"跳过该骨并写日志"。

## 3. 姿态与 FK

```gdscript
class_name RigPose extends RefCounted

var root_pos := Vector2.ZERO
var root_angle := 0.0
var rel := PackedFloat32Array()        # 每骨相对父骨
var abs_angle := PackedFloat32Array()
var joint_pos := PackedVector2Array()
```

```gdscript
static func resolve(def: RigDefinition, pose: RigPose) -> void:
    pose.joint_pos.resize(def.joints.size())
    pose.abs_angle.resize(def.bones.size())
    pose.joint_pos[def.joint_index[&"pelvis"]] = pose.root_pos

    for i in def.topo_order:
        var b := def.bones[i]
        var parent_abs := pose.root_angle if b.parent_index < 0 else pose.abs_angle[b.parent_index]
        var a := wrapf(parent_abs + pose.rel[i], -PI, PI)
        pose.abs_angle[i] = a
        pose.joint_pos[b.end_idx] = pose.joint_pos[b.start_idx] + Vector2.from_angle(a) * b.length
```

注意：

- `rel[spine]` 是相对 `root_angle`，不是相对世界。站立且朝右时 `root_angle=0`、`rel=-90°`。
- 同一关节被两个骨骼共享（如 chest 是 spine 的 end、neck 的 start），只写一次，FK 顺序保证不覆盖。
- 所有计算用 float32 足够；不要每帧重建 `PackedVector2Array`，`resize` 复用。

## 4. 剪辑格式

```json
{
  "name": "idle",
  "length": 2.4,
  "loop": true,
  "root": {
    "pos":   [[0.0, 0.0], [1.2, 2.0], [2.4, 0.0]],
    "angle": [[0.0, 0.0], [2.4, 0.0]]
  },
  "tracks": {
    "spine":       [[0.0, -90], [1.2, -92], [2.4, -90]],
    "upper_arm_l": [[0.0, 96],  [1.2, 92],  [2.4, 96]]
  },
  "events": [{"t": 1.15, "name": "breath"}]
}
```

规则：

- 轨道角度是**绝对角**（度），加载时统一转相对角；手写时不用关心父子关系。
- 缺少某骨轨道 → 用静止角，不报错。
- 时间单位秒；关键帧必须按时间升序；首帧不必是 0，但采样时按首尾夹取。
- `loop=true` 时，最后一帧与第一帧应相同或显式声明循环闭合（避免跳变）。

### 4.1 加载与校验

```gdscript
func load_clip(path: String) -> AnimClip:
    var data: Dictionary = JSON.parse_string(FileAccess.get_file_as_string(path))
    var clip := AnimClip.new()
    clip.id = data.get("name", path.get_file().get_basename())
    clip.length = maxf(float(data.get("length", 1.0)), 0.001)
    clip.loop = bool(data.get("loop", true))
    for bone_id in data.get("tracks", {}):
        assert(_has_bone(bone_id), "未知骨骼: %s" % bone_id)
        clip.tracks[bone_id] = _sorted_keys(data["tracks"][bone_id])
    clip.events = data.get("events", [])
    return clip
```

## 5. 采样

```gdscript
func sample(clip: AnimClip, t: float, out: PackedFloat32Array) -> void:
    var tt := fposmod(t, clip.length) if clip.loop else clampf(t, 0.0, clip.length)
    out.resize(def.bones.size())
    for i in def.bones.size():
        var b := def.bones[i]
        var keys: Array = clip.tracks.get(String(b.id), [])
        out[i] = deg_to_rad(_sample(keys, tt, b.rest_abs_deg))
```

```gdscript
func _sample(keys: Array, t: float, fallback: float) -> float:
    if keys.is_empty():
        return fallback
    if keys.size() == 1 or t <= keys[0][0]:
        return keys[0][1]
    if t >= keys[-1][0]:
        return keys[-1][1]

    var lo := 0
    var hi := keys.size() - 1
    while lo < hi - 1:
        var mid := (lo + hi) >> 1
        if keys[mid][0] <= t: lo = mid
        else: hi = mid

    var t0: float = keys[lo][0]
    var t1: float = keys[hi][0]
    var w := (t - t0) / maxf(t1 - t0, 0.0001)
    w = w * w * (3.0 - 2.0 * w)                 # smoothstep，避免角速度突变
    return lerpf(keys[lo][1], keys[hi][1], w)
```

不要用 Catmull-Rom：角度过冲会让膝盖瞬间反折。

### 5.1 绝对 → 相对

```gdscript
func to_relative(abs_deg: PackedFloat32Array, out: PackedFloat32Array) -> void:
    out.resize(abs_deg.size())
    for i in def.topo_order:
        var p := 0.0
        if def.bones[i].parent_index >= 0:
            p = abs_deg[def.bones[i].parent_index]
        out[i] = deg_to_rad(wrapf(abs_deg[i] - p, -180.0, 180.0))
```

## 6. 混合

### 6.1 交叉淡化

```gdscript
func blend(a: PackedFloat32Array, b: PackedFloat32Array, w: float, out: PackedFloat32Array) -> void:
    for i in a.size():
        out[i] = a[i] + wrapf(b[i] - a[i], -PI, PI) * w
```

- 权重按剪辑归一化，避免三层以上叠加超调。
- 淡化时长 0.15–0.25s；抓取/抛出用 0.12s，站立/走路用 0.2s。
- 混合在**相对角**空间做；绝对角空间混合会在父子之间产生双重计数。

### 6.2 加性层

```gdscript
func additive(base: PackedFloat32Array, add: PackedFloat32Array, mask: PackedFloat32Array, w: float) -> void:
    for i in base.size():
        base[i] += add[i] * mask[i] * w
```

用途：

| 层 | 作用骨 | 幅度 |
|---|---|---|
| 呼吸 | spine、neck | 0.01–0.02 rad，周期 3–5s |
| 受击抖动 | spine、head | 0.03 rad，衰减 0.4s |
| 看向 | neck、head | 由 IK/偏置给出，≤0.15 rad |

加性层不参与 state 切换，永远叠加在最上层。

### 6.3 事件

```gdscript
func update_events(clip: AnimClip, from: float, to: float) -> void:
    for e in clip.events:
        var t: float = e["t"]
        var hit := (from <= t and t < to)
        if clip.loop and to < from:          # 跨循环点
            hit = (t >= from or t < to)
        if hit:
            event_fired.emit(e["name"])
```

同一帧最多派发一次同名事件；`breath` 这类事件要防抖。

## 7. IK

只做**视觉修正**，不改物理粒子。

### 7.1 双骨 IK

```gdscript
static func two_bone(root: Vector2, target: Vector2, l1: float, l2: float, bend: float) -> Array:
    var to := target - root
    var d := clampf(to.length(), absf(l1 - l2) + 0.01, l1 + l2 - 0.01)
    var base := to.angle()
    var cos_a := clampf((l1 * l1 + d * d - l2 * l2) / (2.0 * l1 * d), -1.0, 1.0)
    var a := acos(cos_a)
    var joint := root + Vector2.from_angle(base + a * bend) * l1
    var end := root + Vector2.from_angle(base) * d
    return [joint, end]
```

`bend = +1` / `-1` 决定肘/膝朝哪边弯；左臂与右臂相反。目标超出可达范围时夹到 `l1+l2`，不要拉伸骨骼。

### 7.2 应用顺序

```
PoseBlender → Solver → IkLayer → RigState.resolve
```

- IK 直接修改 `pose.rel` 的副本（或直接改 `joint_pos` 前的 `abs_angle`）。
- `ik_weight` 0→1 用时 0.15s；`w_sim > 0.9` 时禁用，避免与物理抢控制。
- 手够鼠标时，目标点做 80ms 平滑，否则高 DPI 下手臂抖动。

## 8. 动画工作流

| 阶段 | 做法 |
|---|---|
| 原型 | 手写 JSON，2–3 关键帧/秒，先跑通状态切换 |
| 打磨 | 调试面板拖动时间轴，实时看关节限位弧 |
| 批量 | 外部脚本导出绝对角 → JSON（无需引擎内编辑器） |
| 校验 | 加载时断言骨骼名、时间升序、循环闭合 |
| 热重载 | 开发期监听文件 mtime，重载后保持当前时间 |

剪辑清单（v1）：`idle`、`walk`、`sit`、`sleep`、`poke`、`startle`、`drag`、`recover`、`look`。
`drag` 只提供"被拎起"的参考姿态，实际由物理主导。

## 9. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 角色扭曲 | 绝对角当相对角用 | 统一在加载时转换 |
| 关节反折 | 限位符号错 | 检查 `mirror` 与左右骨 |
| 循环跳变 | 首尾帧不一致 | 校验循环闭合 |
| 事件重复触发 | 浮点跨帧 | 记录上次触发时间 |
| IK 拉伸 | 目标超范围 | clamp 到 `l1+l2` |
| 动作切换抖 | 在绝对角空间混合 | 相对角空间 + wrap |

## 10. 验收

- [ ] 13 骨、14 关节 FK 与手算一致（误差 < 0.01px）
- [ ] 任意剪辑采样 1000 次无 NaN，循环处角度连续
- [ ] 交叉淡化 0.2s 内无可见跳变
- [ ] 加性呼吸不影响状态切换
- [ ] 事件在循环边界各触发一次
- [ ] IK 目标超范围时骨骼不拉伸、不翻折
- [ ] 缺失轨道回退到静止角且只警告一次
