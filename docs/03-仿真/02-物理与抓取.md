## 1. 职责与边界

**做**：在固定步长下推进粒子位置；维护距离/角度/抓取/碰撞约束；输出可渲染的关节位置。
**不做**：不选动画、不改 `pose.rel`、不做绘制、不感知窗口。

求解器与动画的契约：每帧接收 `drive_rel[]`（动画目标相对角）与 `tone[]`（张力），输出 `pos[]`。

## 2. 状态

```gdscript
class_name RagdollSolver extends RefCounted

var def: RigDefinition

# 粒子（关节）状态
var pos: PackedVector2Array
var prev: PackedVector2Array
var inv_mass: PackedFloat32Array
var radius: PackedFloat32Array

# 每骨参数（缓存自 BoneDef）
var rest_rel: PackedFloat32Array
var lo: PackedFloat32Array
var hi: PackedFloat32Array
var subtree: Array[PackedInt32Array]

# 每帧输入
var drive_rel: PackedFloat32Array     # 动画目标相对角（rad）
var tone: PackedFloat32Array          # 肌肉张力 0..1
var world_bias: PackedFloat32Array    # 世界空间保持强度（仅 spine 用）
var bias_abs: PackedFloat32Array      # 世界空间目标角

# 抓取
var grab_bone := -1
var grab_t := 0.5
var grab_target := Vector2.ZERO
var grab_strength := 0.55

# 环境
var gravity := 1200.0
var damping := 0.996
var iterations := 8
var max_corr := 0.20                  # 单次旋转修正上限（rad）
var floor_y := 1000.0
var wall_l := 2.0
var wall_r := 1918.0
var restitution := 0.22
var friction := 0.35

var w_sim := 1.0
var sleeping := false
```

### 2.1 初始化

```gdscript
func build(d: RigDefinition) -> void:
    def = d
    var n := d.joints.size()
    pos.resize(n); prev.resize(n)
    inv_mass.resize(n); radius.resize(n)
    for p in n:
        inv_mass[p] = 0.0
        radius[p] = 2.0

    for b in d.bones:
        var inv := 1.0 / maxf(b.mass, 0.05)
        inv_mass[b.start_idx] += inv
        inv_mass[b.end_idx] += inv

    for p in n:
        inv_mass[p] = 1.0 / inv_mass[p] if inv_mass[p] > 0.0 else 0.0

    radius[d.joint_index[&"head_top"]] = d.head_radius
    for b in d.bones:
        var r := maxf(b.width * 0.5, 1.5)
        radius[b.start_idx] = maxf(radius[b.start_idx], r)
        radius[b.end_idx] = maxf(radius[b.end_idx], r)

    subtree.resize(d.bones.size())
    for i in d.bones.size():
        subtree[i] = _collect(i)
```

质量近似：关节质量 = 相邻骨骼质量倒数和再取倒。骨盆会同时被 spine 与两条大腿加权，天然更"重"，符合直觉。

## 3. 固定步长

调用方负责：

```gdscript
const H := 1.0 / 120.0
var _acc := 0.0

func advance(dt: float) -> void:
    _acc += minf(dt, 1.0 / 30.0)
    var guard := 0
    while _acc >= H and guard < 4:
        _acc -= H
        solver.step(H)
        guard += 1
```

规则：

- `dt` 上限 1/30；卡顿后最多补 4 步，宁可慢放。
- 步长固定，`iterations` 才能对应稳定的刚度。
- 渲染用 `prev/pos` 插值，物理永远用 `pos`。

## 4. 积分（Verlet）

```gdscript
func _integrate(h: float) -> void:
    var g := Vector2(0.0, gravity) * h * h
    for p in pos.size():
        if inv_mass[p] <= 0.0:
            prev[p] = pos[p]
            continue
        var v := (pos[p] - prev[p]) * damping
        prev[p] = pos[p]
        pos[p] += v + g
```

- `damping` 每子步乘一次；120Hz 下 0.996 ≈ 每秒保留 62% 速度。
- 被抓住的粒子不特殊处理，仍受重力；由抓取约束拉回，产生"沉"的手感。

## 5. 约束

### 5.1 距离（骨长）

```gdscript
func _solve_distances() -> void:
    for b in def.bones:
        var a := b.start_idx
        var c := b.end_idx
        var d := pos[c] - pos[a]
        var dist := d.length()
        if dist < 0.0001:
            continue
        var wa := inv_mass[a]
        var wc := inv_mass[c]
        var wsum := wa + wc
        if wsum <= 0.0:
            continue
        var corr := d * ((dist - b.length) / dist)
        pos[a] += corr * (wa / wsum)
        pos[c] -= corr * (wc / wsum)
```

单次迭代只能消除一部分误差；8 次后残差 < 1%。若需要绝对不拉伸，可把最后一次迭代改为把 `pos[c]` 直接投影到圆上（会牺牲自然感）。

### 5.2 角度（限位 + 张力）

```gdscript
func _solve_angles() -> void:
    for i in def.topo_order:
        var b := def.bones[i]
        var cdir := pos[b.end_idx] - pos[b.start_idx]
        if cdir.length_squared() < 1e-8:
            continue

        # 父方向：有父骨用父骨，否则用骨盆朝向（spine / thigh 属于后者）
        var pdir: Vector2
        if b.parent_index >= 0:
            var pb := def.bones[b.parent_index]
            pdir = pos[pb.end_idx] - pos[pb.start_idx]
        else:
            pdir = Vector2.from_angle(root_angle)
        if pdir.length_squared() < 1e-8:
            continue

        var rel := wrapf(cdir.angle() - pdir.angle(), -PI, PI)
        var target := clampf(drive_rel[i], lo[i], hi[i])
        var err: float
        var k: float

        if rel < lo[i]:
            err = lo[i] - rel
            k = 1.0
        elif rel > hi[i]:
            err = hi[i] - rel
            k = 1.0
        else:
            err = wrapf(target - rel, -PI, PI)
            k = tone[i]
            if absf(err) < 0.004:
                continue

        var k_iter := 1.0 - pow(1.0 - clampf(k, 0.0, 0.999), 1.0 / float(iterations))
        var rot := clampf(err * k_iter, -max_corr, max_corr)
        _rotate_subtree(i, rot)
```

要点：

- `root_angle` 是骨盆朝向；`spine`、`thigh_*` 的限位都相对它，所以骨盆转动会带动全身。
- 限位优先于张力：越界时 `k=1`，强制拉回。
- 每骨刚度必须换算成"每迭代刚度"，否则改 `iterations` 会改变手感。
- 旋转整棵子树，保留子树内部形状；只转末端会产生橡皮筋感。

```gdscript
func _rotate_subtree(i: int, angle: float) -> void:
    var pivot := pos[def.bones[i].start_idx]
    for c in subtree[i]:
        var e := def.bones[c].end_idx
        pos[e] = pivot + (pos[e] - pivot).rotated(angle)
```

### 5.3 抓取

设抓点在骨骼参数 `t` 处：`P = lerp(A, B, t)`。要让 `P` 移动 `delta`，两端位移应满足：

```
ΔA = delta * (1-t) * k
ΔB = delta * t     * k
k = 1 / ((1-t)² + t²)
```

```gdscript
func _solve_grab() -> void:
    if grab_bone < 0:
        return
    var b := def.bones[grab_bone]
    var a := b.start_idx
    var c := b.end_idx
    var t := clampf(grab_t, 0.0, 1.0)
    var cur := pos[a].lerp(pos[c], t)
    var delta := (grab_target - cur) * grab_strength
    var norm := 1.0 / maxf((1.0 - t) * (1.0 - t) + t * t, 1e-4)

    pos[a] += delta * (1.0 - t) * norm
    pos[c] += delta * t * norm
```

为什么不是两端各加 `delta`：抓在端点（t=0）时，另一端不应被平移，否则等于把整根骨头钉死。上面的权重让 `P` 精确收敛，同时保留绕抓点的旋转自由。

### 5.4 碰撞

```gdscript
func _solve_collisions() -> void:
    for p in pos.size():
        var r := radius[p]
        if pos[p].y > floor_y - r:
            var vy := pos[p].y - prev[p].y
            pos[p].y = floor_y - r
            if vy > 2.0:
                prev[p].y = pos[p].y + restitution * vy     # 反弹
            else:
                prev[p].y = pos[p].y                        # 静止
            prev[p].x = lerpf(prev[p].x, pos[p].x, friction)

        if pos[p].x < wall_l + r:
            pos[p].x = wall_l + r
            prev[p].x = pos[p].x + restitution * (pos[p].x - prev[p].x)
        elif pos[p].x > wall_r - r:
            pos[p].x = wall_r - r
            prev[p].x = pos[p].x + restitution * (pos[p].x - prev[p].x)
```

- 落地反弹通过改写 `prev` 实现：`prev = pos + e*vy` 使下一步速度反向且衰减。
- 摩擦只作用在地面，水平速度按 `friction` 混合。
- 碰撞在抓取之后执行：地板优先，拖不出屏幕。

### 5.5 世界空间保持（躯干）

抓腰时，仅靠相对角弹簧，脊柱可能整体倒下。加一条世界角偏置：

```gdscript
if world_bias[i] > 0.0:
    var err_w := wrapf(bias_abs[i] - cdir.angle(), -PI, PI)
    var rot_w := clampf(err_w * world_bias[i] * k_iter, -max_corr, max_corr)
    _rotate_subtree(i, rot_w)
```

只给 `spine` 使用；`bias_abs = -PI/2 + clamp(-accel.x * 0.00035, -0.25, 0.25)`。
效果：躯干被"腰力"撑住，但随拖动加速度前后倾。

### 5.6 光标实体（SOLID）

只在"按住左键且不是抓取"时启用；`PASSIVE`/`PENDING`/`GRAB` 不参与碰撞。

```gdscript
func solve_cursor(cursor_pos: Vector2, cursor_vel: Vector2, radius: float, h: float) -> void:
    for p in pos.size():
        var r := radius + radius_bone[p]
        var d := pos[p] - cursor_pos
        var dist := d.length()
        if dist >= r or dist < 0.0001:
            continue
        var n := d / dist
        pos[p] += n * (r - dist)                       # 推出
        var vn := maxf(cursor_vel.dot(n), 0.0)
        var impulse := minf(vn, 1600.0) * 0.35
        prev[p] -= n * impulse * h                     # Verlet 冲量
```

- 光标是**运动学圆**，不参与受力；只影响角色粒子。
- 用上一帧位置到当前位置做线段扫掠，避免高速穿透细骨骼。
- 只有相对速度 ≥ 900px/s 且发生接触时，才广播 `hit` 事件（冷却 400ms）。
- 角色被推到墙/屏幕边缘时，按普通碰撞处理。
- 完整模式与阈值见 [光标交互规范](../05-行为/02-光标交互规范.md)。

## 6. 模式与动画同步

| 模式 | w_sim | 行为 |
|---|---|---|
| 纯动画 | 0 | 不积分；每帧由 FK 姿态直接写 `pos/prev` |
| 混合 | 0..1 | 正常积分；`tone` 由行为层按权重缩放 |
| 纯物理 | 1 | 只保留限位；`tone≈0` |

```gdscript
func sync_kinematic(pose: RigPose) -> void:
    pos[def.joint_index[&"pelvis"]] = pose.root_pos
    for i in def.topo_order:
        var b := def.bones[i]
        pos[b.end_idx] = pos[b.start_idx] + Vector2.from_angle(pose.abs_angle[i]) * b.length
    prev = pos.duplicate()
```

模式切换不能硬切：`w_sim` 用 0.12s 过渡；渲染层再对 `pos` 做 0.08s 的短混合，遮住残差。

## 7. 张力表（自然下垂的核心）

`tone` 是"每帧弹簧刚度"，不是阻尼：

| 抓取部位 | spine | neck | head | 上臂 | 前臂 | 大腿 | 小腿 | 脚 |
|---|---|---|---|---|---|---|---|---|
| 腰（pelvis / spine 下段） | 0.42 | 0.30 | 0.22 | 0.04 | 0.02 | 0.05 | 0.03 | 0.02 |
| 头（head / neck） | 0.10 | 0.06 | 0.03 | 0.02 | 0.01 | 0.02 | 0.01 | 0.01 |
| 手 / 前臂 | 0.35 | 0.25 | 0.20 | 0.08 | 0.05 | 0.06 | 0.04 | 0.03 |
| 腿 / 脚 | 0.30 | 0.20 | 0.15 | 0.03 | 0.02 | 0.10 | 0.06 | 0.04 |
| 抛出（无抓取） | 0.05 | 0.03 | 0.02 | 0.01 | 0.00 | 0.01 | 0.00 | 0.00 |

调参直觉：

- 腿 0.05：单摆 `T ≈ 2π√(0.5/1200) ≈ 1.28s`；张力会把它"提"到 0.9–1.1s。
- 头 0.22：产生 0.1–0.15s 滞后，看起来"头很重"。
- 腰 0.42：躯干塌 15–20° 后被拉回，像被拎起的猫。

## 8. 抓取、拖拽与投掷

### 8.1 命中

```gdscript
func pick(world: Vector2, render_pos: PackedVector2Array) -> Array:
    var best := [-1, 0.0, INF]
    for i in def.bones.size():
        var b := def.bones[i]
        var a := render_pos[b.start_idx]
        var c := render_pos[b.end_idx]
        var ab := c - a
        var t := clampf((world - a).dot(ab) / maxf(ab.length_squared(), 1e-4), 0.0, 1.0)
        var d := world.distance_to(a + ab * t)
        var r := maxf(b.width * 1.4, 8.0) * def.base_scale + 6.0
        if d <= r and d < best[2]:
            best = [i, t, d]
    return best
```

### 8.2 抓取

```gdscript
func begin_grab(bone: int, t: float, point: Vector2, mouse: Vector2) -> void:
    grab_bone = bone
    grab_t = t
    grab_target = point
    grab_offset = mouse - point     # 关键：不记就会瞬移
    grab_strength = 0.55
    w_sim = 1.0
    sleeping = false
```

每帧：

```gdscript
mouse_smooth = mouse_smooth.lerp(mouse_raw, 1.0 - exp(-22.0 * dt))
grab_target = mouse_smooth + grab_offset
```

### 8.3 投掷

速度取 80–120ms 窗口的平均：

```gdscript
func release_velocity() -> Vector2:
    if hist.size() < 2:
        return Vector2.ZERO
    var a: Dictionary = hist[0]
    var b: Dictionary = hist[-1]
    var dt: float = maxf(b["t"] - a["t"], 0.016)
    return ((b["p"] - a["p"]) / dt).limit_length(2400.0)
```

给速度 = 改 `prev`：

```gdscript
func apply_velocity(bone: int, t: float, v: Vector2, h: float) -> void:
    var b := def.bones[bone]
    var near := b.start_idx if t <= 0.5 else b.end_idx
    var far := b.end_idx if t <= 0.5 else b.start_idx
    prev[near] -= v * h
    prev[far] -= v * (0.35 * h)
```

### 8.4 甩动识别

0.5s 内方向反转 ≥ 10 次，或峰值速度 > 1800px/s，标记 `shaken`，松手后进入 `Startle` + 眩晕。

## 9. 休眠

```gdscript
func is_resting() -> bool:
    var e := 0.0
    for p in pos.size():
        e += (pos[p] - prev[p]).length_squared()
    return e < 0.02
```

连续 60 步满足 → `sleeping = true`，跳过积分；`begin_grab` 或冲量唤醒。
桌宠大部分时间静止，休眠可省 80% CPU。

## 11. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 爆炸/NaN | dt 过大、修正无上限 | 固定步长 + `max_corr` + 每步 `is_finite` 检查 |
| 橡皮筋 | 迭代不足/抓取太硬 | 迭代 10，`grab_strength` 0.45 |
| 抖动 | 鼠标噪声/刚度高 | 平滑 22/s，`k_iter` 换算 |
| 反折 | 限位符号/镜像 | 调试面板画限位弧 |
| 下半身不垂 | tone 太高 | 腿 ≤ 0.1，world_bias 只给 spine |
| 拖不出屏幕 | 碰撞顺序错 | 抓取后再碰撞 |
| 抓取瞬移 | 忘记 offset | 抓取瞬间记录 |
| 落地穿模 | 速度过大 | 速度上限 + 子步内夹取 |

## 12. 验收

- [ ] 600 步后骨长误差 < 2%
- [ ] 1000 次随机冲量后膝盖/肘不越限
- [ ] 抓点固定在目标 0.5s 后误差 < 1px
- [ ] 静止 2s 后进入休眠
- [ ] 抓腰 0.2s 内腿摆幅 ≥ 20°，3 周期内衰减到 < 5°
- [ ] 抛掷速度 2400px/s 不穿墙、不 NaN
- [ ] 相同输入两次模拟位置差 < 1e-4
