# AI 控制架构与 WebSocket 协议

> 上级：[AI 集成](README.md) · 架构：[架构与运行时](../01-总览/02-架构与运行时.md)
> 协议版本：`1`（`protocol: 1`）
> 传输：WebSocket over `127.0.0.1`，UTF-8 文本帧，JSON。

---

## 1. 角色

| 角色 | 进程 | 职责 |
|---|---|---|
| Server | Godot 桌宠 | 监听、握手、校验、执行意图、发布状态 |
| Client | Go AI | 连接、推理、下发意图、消费状态/事件 |

默认端口：`8765`（可配置）。只绑定 `127.0.0.1`。

---

## 2. 消息总览

| 方向 | 类型 | 频率 | 作用 |
|---|---|---|---|
| C→S | `hello` | 连接时一次 | 协议版本、token、客户端信息 |
| S→C | `welcome` | 握手后一次 | session、屏幕、宠物、tick 配置 |
| S→C | `state` | 15Hz | 宠物/输入/事件快照 |
| C→S | `command` | ≤30Hz | 高层意图 |
| S→C | `ack` | 每条 command | 接受/拒绝与原因 |
| S→C | `event` | 事件发生时 | 抓取、落地、点击等 |
| C↔S | `ping` / `pong` | 5s | 心跳 |

所有消息必须含 `type` 与 `protocol`。未知字段忽略。

---

## 3. 握手

### C→S `hello`

```json
{
  "type": "hello",
  "protocol": 1,
  "token": "one-time-token",
  "client": { "name": "stickman-ai", "version": "0.1.0" },
  "capabilities": ["state", "command"]
}
```

### S→C `welcome`

```json
{
  "type": "welcome",
  "protocol": 1,
  "session": "s-7f3c",
  "pet_id": "stickman-1",
  "tick_rate": 60,
  "state_rate": 15,
  "max_command_rate": 30,
  "screen": { "width": 1920, "height": 1040, "scale": 1.0 },
  "pet": { "state": "idle", "pos": [960, 900], "facing": 1 }
}
```

失败：`{"type":"error","code":"auth_failed"}` 后关闭；`busy` 表示已有客户端。

---

## 4. 状态

### S→C `state`（15Hz）

```json
{
  "type": "state",
  "protocol": 1,
  "seq": 1042,
  "t": 1730000000.123,
  "mode": "remote",
  "pet": {
    "state": "idle",
    "pos": [960, 900],
    "vel": [0, 0],
    "facing": 1,
    "grounded": true,
    "grab": null,
    "energy": 0.72
  },
  "input": { "mouse": [1200, 400], "inside": true },
  "cursor": { "mode": "solid", "pos": [1200, 400], "vel": [320, -20], "down": true },
  "events": ["breath"]
}
```

- 坐标：窗口局部像素，原点 = 可用区左上角。
- `state` 是 FSM 当前状态（idle/look/walk/sit/sleep/drag/thrown/recover/poke/startle）。
- `cursor.mode`：`passive`（幽灵）、`pending`（角色上按住）、`solid`（实体推/撞）、`grab`（抓取）。
- 只有 `solid` 时光标才与角色碰撞；AI 不能假设 `passive` 下推/撞有效。
- `events` 是自上一帧以来的事件名；完整数据见 `event` 消息。

## 5. 命令

### C→S `command`

```json
{
  "type": "command",
  "protocol": 1,
  "id": "c-0001",
  "t": 1730000000.200,
  "ttl_ms": 250,
  "priority": 0,
  "action": "look_at",
  "params": { "x": 1200, "y": 400 }
}
```

| action | params | 说明 |
|---|---|---|
| `set_mode` | `mode: "remote" \| "autonomous"` | 请求切换模式；用户输入可拒绝 |
| `look_at` | `x, y` | 看向屏幕点 |
| `walk_to` | `x, speed?` | 走到目标 x |
| `face` | `dir: -1 \| 1` | 转身 |
| `jump` | `height?` | 跳一下 |
| `sleep` / `wake` | — | 睡觉/唤醒 |
| `idle` | — | 停止当前 AI 意图 |

规则：

- `id` 幂等；重复 id 只执行一次。
- `ttl_ms` 默认 250；过期丢弃，不补执行。
- `priority` 越大越优先；用户输入始终最高。
- 参数超范围 → `ack.ok=false, reason=clamped` 或 `invalid`。

### S→C `ack`

```json
{ "type": "ack", "protocol": 1, "id": "c-0001", "ok": true }
```

拒绝：

```json
{ "type": "ack", "protocol": 1, "id": "c-0001", "ok": false, "reason": "user_override" }
```

原因：`user_override`、`invalid`、`rate_limited`、`expired`、`not_remote`、`busy`。

---

## 6. 事件

### S→C `event`

```json
{
  "type": "event",
  "protocol": 1,
  "name": "grab_started",
  "t": 1730000000.300,
  "data": { "bone": "spine", "t": 0.3 }
}
```

事件名：`grab_started`、`grab_released`、`landed`、`clicked`、`poked`、`state_changed`。

`event` 用于 AI 的即时反应；`state.events` 只做轻量提示，避免重复处理。

---

## 7. 心跳与超时

- 任一方 5s 无消息 → 发 `ping`；10s 无 `pong` → 断开。
- AI 断开后，Godot 1s 内回到 `AUTONOMOUS`。
- Go 重连退避：0.5s、1s、2s、5s（上限），无限重试。

---

## 8. 错误与关闭

| code | 含义 |
|---|---|
| `auth_failed` | token 不匹配 |
| `busy` | 已有客户端 |
| `bad_protocol` | 协议版本不兼容 |
| `too_large` | 消息 > 64KB |
| `invalid_json` | 解析失败 |

关闭码：`1000` 正常、`1008` 策略/鉴权、`1011` 内部错误。

## 9. Godot 侧实现要点

```gdscript
# 伪代码
var tcp := TCPServer.new()
tcp.listen(8765, "127.0.0.1")

func _process(_dt: float) -> void:
    while tcp.is_connection_available():
        var ws := WebSocketPeer.new()
        ws.accept_stream(tcp.take_connection())
        _pending = ws
    if _ws:
        _ws.poll()
        while _ws.get_available_packet_count() > 0:
            _handle(_ws.get_packet().get_string_from_utf8())
```

- 只接受一个客户端；握手 5s 超时。
- `command` 先校验（JSON/动作/范围/TTL/速率），再交给 `PetBrain`。
- `state` 15Hz 由 `Pet` 聚合，不在渲染线程做 JSON 序列化（可缓存字符串）。
- 断线/非法消息不能影响主循环；所有异常 `push_warning` 并继续。
- 用户输入通过 `InputRouter` 触发 `MANUAL`，同时拒绝 AI 命令。

## 10. Go 侧实现要点

```
cmd/ai/main.go            # 参数、装配、信号
internal/ws/client.go     # 连接、读写、重连、心跳
internal/protocol/*.go    # 消息结构体（与本文一致）
internal/policy/policy.go # Policy 接口、ONNX/TFLite 实现
internal/agent/loop.go    # 状态缓存 → 特征 → 推理 → command
internal/log/jsonl.go     # 回放/训练日志
```

- 读写各一个 goroutine；推理一个 goroutine；用 channel 传递最新 state。
- 只保留最新 state，避免推理追帧。
- command 带 `ttl_ms`；模型慢时不要发过期动作。
- 断线时停止发命令，继续重连；不要退出进程。
- 模型路径、URL、token 从命令行/环境变量读取，不硬编码。

## 11. 验收

- [ ] Go 客户端可连接/断开，桌宠在 1s 内回到自主模式
- [ ] 15Hz 状态、30Hz 命令下无堆积、无抖动
- [ ] 用户拖拽时 AI 命令被拒绝，松手后可恢复
- [ ] 非法 JSON/未知动作/超范围参数不会崩溃
- [ ] 断线重连 10 次，桌宠状态正常
- [ ] 单次推理 500ms 时不阻塞状态接收
- [ ] token 错误/第二客户端被拒绝
- [ ] 日志可回放一次完整交互
