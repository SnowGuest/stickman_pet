# 窗口与穿透

> 上级：[文档中心](../README.md) · 领域：平台层
> 目标：一个真透明、真置顶、不抢焦点、空白处可穿透的桌面窗口，并给出坐标与命中规则。

---

## 1. 窗口形态

| 属性 | 值 | API |
|---|---|---|
| 边框 | 无 | `WINDOW_FLAG_BORDERLESS` |
| 透明 | 是 | `WINDOW_FLAG_TRANSPARENT` + `Window.transparent_bg` |
| 置顶 | 是 | `WINDOW_FLAG_ALWAYS_ON_TOP` |
| 焦点 | 不获取 | `WINDOW_FLAG_NO_FOCUS` |
| 缩放 | 禁止 | `WINDOW_FLAG_RESIZE_DISABLED` |
| 尺寸 | 屏幕可用区域 | `screen_get_usable_rect()` |
| 位置 | 可用区域左上角 | `window_set_position()` |
| 任务栏 | 不显示（可选） | `WINDOW_FLAG_POPUP`（需实测平台行为） |

### 1.1 项目设置

```ini
[display]
window/size/transparent=true
window/per_pixel_transparency/allowed=true
window/size/borderless=true
window/size/always_on_top=true
window/size/resizable=false
window/stretch/mode="disabled"
window/dpi/allow_hidpi=true

[rendering]
viewport/transparent_background=true
```

> 这些键已在 Godot 4.7.2 中确认存在。
> `stretch/mode` 必须为 `disabled`：否则鼠标坐标与画布坐标之间会多一层缩放，抓取会偏。

### 1.2 初始化顺序

```gdscript
func setup() -> void:
    var win := get_window()
    win.transparent_bg = true
    for flag in [
        DisplayServer.WINDOW_FLAG_BORDERLESS,
        DisplayServer.WINDOW_FLAG_ALWAYS_ON_TOP,
        DisplayServer.WINDOW_FLAG_TRANSPARENT,
        DisplayServer.WINDOW_FLAG_NO_FOCUS,
        DisplayServer.WINDOW_FLAG_RESIZE_DISABLED,
    ]:
        DisplayServer.window_set_flag(flag, true)
    _refresh_screen()
```

先设 `transparent_bg` 再设 flags，最后定位。顺序反了在部分驱动上会出现第一帧黑底。

## 2. 透明失败的检测与降级

透明窗口依赖 Windows layered window + GPU 合成。以下情况会失败：

- 远程桌面/部分虚拟机；
- 某些录屏/直播软件的捕获层；
- 老驱动或强制关闭合成。

检测（启动后 500ms）：

1. 读 `RenderingServer.get_video_adapter_name()` 记录日志；
2. 若 `per_pixel_transparency/allowed` 为 false → 直接降级；
3. 视觉自检：在空白区域放一个纯色测试像素，读回窗口截图（仅开发期）；
4. 用户反馈通道：设置里提供"白底模式"。

降级模式：`transparent_bg = false`，窗口改为 480×320 白底小窗，角色仍可玩但不贴桌面。

## 3. 坐标系统

只有一个坐标空间：**窗口像素**。

```gdscript
func global_to_local(g: Vector2) -> Vector2:
    return g - Vector2(DisplayServer.window_get_position())

func local_to_global(l: Vector2) -> Vector2:
    return l + Vector2(DisplayServer.window_get_position())
```

| 量 | 来源 | 注意 |
|---|---|---|
| 全局鼠标 | `DisplayServer.mouse_get_position()` | 多屏可为负 |
| 窗口位置 | `DisplayServer.window_get_position()` | 含边框？无边框窗即内容原点 |
| 可用区 | `screen_get_usable_rect(screen)` | 已排除任务栏 |
| DPI | `screen_get_scale(screen)` | 100%=1.0，150%=1.5 |

所有长度（骨长、线宽、命中半径）统一乘 `base_scale * dpi_scale`。

## 4. 穿透：三种策略

| 策略 | API | 能力 | 限制 |
|---|---|---|---|
| A. 整窗开关 | `WINDOW_FLAG_MOUSE_PASSTHROUGH` | 开/关整个窗口的命中 | 无法只让角色可点；需外部轮询光标 |
| B. 多边形区域 | `window_set_mouse_passthrough(polygon)` | 只让多边形内可点 | 单多边形，多物体合并会吞空白 |
| C. 多窗口 | 每个交互物一个透明窗 | 天然分离 | 层级/移动/同步复杂 |

**决策**：

- 只有宠物一个交互物 → 用 B，凸包跟随骨骼，30Hz 提交。
- 未来有多个分离交互物时，再评估整窗开关或独立窗口。
- 不要同时用 A 和 B。

## 5. 方案 B：凸包区域

### 5.1 生成

```gdscript
func build_region(segments: Array, head: Vector2, head_r: float) -> PackedVector2Array:
    var pts := PackedVector2Array()
    for seg in segments:
        var a: Vector2 = seg[0]
        var b: Vector2 = seg[1]
        var r: float = seg[2] + 3.0
        for k in 6:
            var ang := TAU * k / 6.0
            pts.append(a + Vector2.from_angle(ang) * r)
            pts.append(b + Vector2.from_angle(ang) * r)
    for k in 12:
        pts.append(head + Vector2.from_angle(TAU * k / 12.0) * (head_r + 3.0))

    var hull := Geometry2D.convex_hull(pts)
    if hull.size() < 3:
        return PackedVector2Array()
    if not Geometry2D.is_polygon_clockwise(hull):
        hull.reverse()
    var grown := Geometry2D.offset_polygon(hull, 3.0)
    return grown[0] if grown.size() > 0 else hull
```

### 5.2 提交

```gdscript
const HZ := 30.0
var _acc := 0.0
var _last_rect := Rect2()

func tick(dt: float, region: PackedVector2Array) -> void:
    _acc += dt
    if _acc < 1.0 / HZ or region.size() < 3:
        return
    _acc = 0.0
    var r := _bounds(region)
    if r.position.distance_to(_last_rect.position) < 0.75 \
       and (r.size - _last_rect.size).length() < 0.75:
        return
    _last_rect = r
    DisplayServer.window_set_mouse_passthrough(region)
```

规则：

- 30Hz + 0.75px 滞回；每次调用会触发系统区域重建，60Hz 会掉帧。
- 抓取当帧强制提交一次，避免"手指已经抓住但窗口还没更新"。
- 凸包内的空隙会吞点击 → 判定为 `Poke`（见行为文档）。

## 6. 方案 A：轮询 + 整窗开关（多物体）

```gdscript
var _interactive := false
var _hysteresis := 6.0
var _lock := false          # 拖拽/菜单打开时锁定

func _process(_dt: float) -> void:
    if _lock:
        return
    var local := global_to_local(DisplayServer.mouse_get_position())
    var over := hit_router.hit(local, _hysteresis) != null
    if over == _interactive:
        return
    _interactive = over
    DisplayServer.window_set_flag(
        DisplayServer.WINDOW_FLAG_MOUSE_PASSTHROUGH, not over)
```

状态机：

```
        光标进入命中区                 光标离开
PASS ───────────────────► HOT ───────────────────► PASS
  ▲                        │
  └────────────────────────┘
       拖拽结束 / 菜单关闭（_lock=false）
```

约束：

- 穿透开启时窗口收不到鼠标移动，**必须**用 `mouse_get_position()` 轮询。
- 拖拽期间 `_lock = true`，保持 HOT，否则拖到空白处会丢失捕获。
- 右键菜单打开期间同样锁定，否则点菜单会穿透。
- 迟滞 6px，避免边缘高频切换。
- 切换延迟约 1 帧（16ms），快速"移入即点击"可能落在 PASS 帧；可在鼠标按键按下时强制命中一次重判。

## 7. 点击路由与焦点

| 光标位置 | 行为 |
|---|---|
| 宠物身体 | 抓取/戳（按手势） |
| UI 菜单 | UI 优先 |
| 空白 | 穿透到桌面（PASS 模式） |
| 凸包内空隙 | `Poke`（防误吞） |

焦点：

- `NO_FOCUS` 下点击不激活窗口，不会打断用户打字。
- 代价：拿不到键盘事件；所有交互必须可用鼠标完成。
- 右键菜单是 `PopupMenu`，需要临时获取焦点才能自动关闭 → 打开时 `grab_focus()`，关闭后恢复 flags。

## 8. 与全屏应用、任务栏的关系

- 置顶窗会盖住全屏视频/游戏。v1 声明为已知行为；v2 用 Win32 `GetForegroundWindow` + 窗口矩形等于屏幕且无边框 → 自动隐藏。
- 任务栏：窗口尺寸取 `usable_rect`，天然避开任务栏；任务栏在顶部/左侧时也成立。
- Alt-Tab：透明窗口会出现在列表。可在设置中提供"从 Alt-Tab 隐藏"（需要 `WS_EX_TOOLWINDOW`，v2）。

## 9. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 黑底 | 透明未生效 | 检查三处设置 + 渲染器 |
| 点击穿透失效 | 区域为空/未提交 | 空数组会恢复整窗可点；确保 size ≥ 3 |
| 区域错位 | 用了屏幕坐标 | 必须传窗口局部坐标 |
| 拖拽中丢失鼠标 | 穿透被重新打开 | 拖拽期间锁定 HOT |
| 首次点击没反应 | 初始化未完成 | 首帧前不要处理输入 |
| 多屏坐标错 | 用主屏原点 | 一律 `global_to_local` |
