## 1. 输入模型

桌宠窗口不能依赖常规 `_input`，因为：

- `NO_FOCUS` 窗口拿不到键盘；
- 穿透开启时窗口收不到鼠标移动；
- 拖拽需要持续跟踪光标，即使光标移出命中区。

因此采用**双通道**：

| 通道 | 用途 | 来源 |
|---|---|---|
| 事件通道 | 按下/抬起/双击/滚轮 | `_input` / `_unhandled_input` |
| 轮询通道 | 光标位置、悬停、拖拽目标 | `DisplayServer.mouse_get_position()` |

```gdscript
func _input(event: InputEvent) -> void:
    if event is InputEventMouseButton:
        _gesture.on_button(event.button_index, event.pressed, _local_mouse())
    elif event is InputEventMouseMotion:
        _gesture.on_motion(_local_mouse())
```

轮询每帧执行，事件通道只负责"边沿"。

## 2. 手势识别

### 2.1 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `TAP_MAX_MS` | 180 | 按下到抬起的上限 |
| `TAP_MAX_PX` | 4 | 允许的抖动 |
| `DOUBLE_MS` | 300 | 两次点击的最大间隔 |
| `LONG_GRAB_MS` | 280 | 在角色上长按进入抓取 |
| `LONG_GRAB_MOVE_PX` | 6 | 长按期间允许的抖动 |
| `SOLID_RADIUS` | 10 | 实体光标半径 |
| `HIT_SPEED` | 900 px/s | 撞击判定 |
| `FLING_MIN` | 900 px/s | 甩动判定 |
| `WHEEL_STEP` | 0.1 | 滚轮缩放步长 |

> 完整规则见 [光标交互规范](../05-行为/02-光标交互规范.md)。

### 2.2 状态机

```
PASSIVE ──在角色上按下──► PENDING ──保持280ms──► GRAB ──松手──► THROWN/RECOVER
   │                        │
   │                        ├──移动>6px──► SOLID
   │                        └──抬起<180ms──► TAP (POKE)
   │
   └──在桌面按下──► SOLID ──快速掠过角色──► HIT（仍是 SOLID）
                      │
                      └──松手──► PASSIVE
```

### 2.3 判定代码

```gdscript
func on_button(button: int, pressed: bool, pos: Vector2, over_pet: bool) -> void:
    if button != MOUSE_BUTTON_LEFT:
        return
    if pressed:
        _press_t = _now()
        _press_pos = pos
        _state = PENDING if over_pet else SOLID
        if _state == SOLID:
            _cursor.begin(pos)
    else:
        var dt := _now() - _press_t
        var moved := pos.distance_to(_press_pos)
        if _state == GRAB:
            _emit("grab_release", _velocity())
        elif _state == SOLID:
            _cursor.end()
        elif _state == PENDING and dt <= TAP_MAX_MS and moved <= TAP_MAX_PX:
            _emit("tap", pos)
        _state = PASSIVE
```

`PENDING` 的长按/移动判定在 `_process` 中推进：

```gdscript
if _state == PENDING:
    if _local_mouse().distance_to(_press_pos) > LONG_GRAB_MOVE_PX:
        _state = SOLID
        _cursor.begin(_local_mouse())
    elif _now() - _press_t >= LONG_GRAB_MS:
        _state = GRAB
        _emit("grab_started")
```

> 桌面空白处按下时窗口收不到事件，必须由 `GlobalMouse`（Win32 `GetAsyncKeyState`）提供全局左键状态；见 [光标交互规范](../05-行为/02-光标交互规范.md) 第 6 章。

## 3. 命中优先级

`HitRouter` 每帧构建一次命中缓存，顺序固定：

```
1. UI（菜单、调试面板）
2. 宠物骨骼（胶囊最近距离）
3. 凸包内空隙 → Poke
4. 空白 → 穿透
```

规则：

- UI 打开时屏蔽下层（模态）。
- 命中半径 = `max(线宽×1.4, 8px) × scale + 6px`，比视觉略大。
- 命中结果同时供 `PassthroughService` 使用，二者必须同源。

## 4. 多屏与 DPI

### 4.1 屏幕选择

```gdscript
func current_screen() -> int:
    return DisplayServer.window_get_current_screen()
```

策略：

- v1：始终使用**光标所在屏**或**主屏**（配置项），切换时重建窗口。
- 角色跨屏拖拽：v1 不允许（窗口不跨屏）；提示或直接把角色钳制在当前屏。
- 拔插显示器：`screen_get_count()` 变化 → 重建。

### 4.2 DPI

```gdscript
var scale := DisplayServer.screen_get_scale(screen)   # 1.0 / 1.25 / 1.5 / 2.0
# 部分 Windows 环境 screen_get_scale 固定 1.0；用 DPI 兜底
var dpi := DisplayServer.screen_get_dpi(screen)
if is_equal_approx(scale, 1.0) and dpi > 96:
    scale = snappedf(float(dpi) / 96.0, 0.01)
```

- 骨骼长度、线宽、命中半径统一乘 `base_scale * scale`。
- 字体用 `theme_override_font_sizes` 按比例设置。
- 不要用 `Window.content_scale_factor` 做整体缩放——会破坏 1:1 鼠标映射。

### 4.3 可用区

```gdscript
var usable := DisplayServer.screen_get_usable_rect(screen)
floor_y = usable.size.y - 2.0
```

任务栏在顶部时，`usable.position.y > 0`，角色站立线仍取 `usable` 底边。

## 5. 生命周期

### 5.1 单实例

```gdscript
var _lock := TCPServer.new()

func acquire() -> bool:
    # Windows 下仅 listen 可能允许重复绑定，先探测已有监听。
    for port in [42871, 42872, 42873]:
        if _has_listener(port):
            return false
        if _lock.listen(port, "127.0.0.1") == OK:
            return true
    return false
```

- 失败 → 已有实例，当前进程 `quit()`。
- 端口被其他程序占用 → 换 42872/42873，最多尝试 3 个。
- 退出时 `_lock.stop()`。

### 5.2 启动

`boot → 配置 → 窗口 → 屏幕 → Rig → 动画 → 首帧 → 显示`（详见 [架构文档](../01-总览/02-架构与运行时.md) 第 4 章）。
启动期间窗口隐藏，首帧渲染完成后再 `show()`，避免闪白。

### 5.3 运行

- `Engine.max_fps = 60`；`OS.low_processor_usage_mode = false`。
- 宠物进入 `Sleep` 状态时仍保持 60fps（动画需要）。
- 系统休眠/唤醒：监听 `NOTIFICATION_WM_WINDOW_FOCUS_IN` 或轮询 `Time` 跳变；唤醒后重置 `_acc`，避免追帧。

### 5.4 退出

顺序：

1. 停止物理与计时器；
2. 保存配置（缩放、窗口屏幕、开关）；
3. 恢复窗口 flags（关闭置顶/透明，防止系统残留）；
4. 停止 TCP 锁；
5. `get_tree().quit()`。

异常退出：依赖配置的原子写，不依赖"退出时保存"。

### 5.5 崩溃与日志

- 滚动日志：`user://logs/pet.log`，保留 3 个文件 × 1MB。
- 记录：启动参数、版本、屏幕信息、渲染器、最近 200 条状态切换。
- GDScript 无法捕获原生崩溃；发布版提供"安全模式"启动参数（`--safe`）关闭透明与穿透。

## 6. 启动参数

| 参数 | 作用 |
|---|---|
| `--safe` | 关闭透明/特效，白底窗 |
| `--scale=1.5` | 覆盖缩放，调试 DPI |
| `--screen=1` | 指定屏幕 |
| `--no-passthrough` | 关闭穿透，便于调试 |
| `--pet-debug` | 显示骨架/穿透区域，允许 F1/F6/F7 键 |
| `--screenshot` | 保存一帧到 `user://p1_viewport.png` 后退出 |
| `--dpi=2.0` | 覆盖 DPI 缩放，验证 200% 渲染 |
| `--verbose` | 打开详细日志 |

解析用 `OS.get_cmdline_user_args()`，不要污染系统参数。

## 7. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击变两次单击 | 第二次 `tap` 先触发 | 延迟 300ms 派发单击 |
| 拖拽结束速度方向错 | 速度窗口太短 | 80–120ms |
| 菜单点不中 | 穿透未锁定 | 打开菜单时 `_lock=true` |
| 唤醒后角色飞天 | `_acc` 累积 | 唤醒时清零 + 限制 dt |
| 第二实例抢配置 | 无单实例锁 | TCP 锁 + 原子写 |
| DPI 150% 抓偏 | 未乘 `screen_get_scale` | 统一乘 scale |

## 8. 验收

- [ ] 单击/双击/长按/拖拽/甩动各 20 次，识别正确率 > 95%
- [ ] 快速"移入即点"不丢点击
- [ ] 拖拽出命中区仍持续跟踪
- [ ] 右键菜单打开时点击不穿透
- [ ] 100/125/150/200% DPI 抓取点误差 < 2px
- [ ] 任务栏四个方向站立线正确
- [ ] 双开被拒绝，提示已有实例
- [ ] 强杀后重启，配置未损坏
- [ ] 睡眠唤醒后不追帧、不飞天
