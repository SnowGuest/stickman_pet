# 托盘与基础设置

> 上级：[文档中心](../README.md) · 相关：[窗口与穿透](01-窗口与穿透.md)、[AI 集成](../07-AI集成/README.md)
> **决策状态**：已接受 `desktop_ext` GDExtension 方案（2026-10-19）；实现排入 P1，**当前不写代码**。
> 目标：Windows 通知区（任务栏右下角）常驻托盘图标，提供显示/隐藏、置顶、缩放、静音、AI 开关、自启、退出等基础设置。

---

## 1. 技术前提

Godot 4.7 **没有系统托盘 API**（`DisplayServer` 不提供）。必须用原生扩展：

```
addons/desktop_ext/          # GDExtension（C++/Rust）
  desktop_ext.gdextension
  bin/windows-x86_64/desktop_ext.dll
```

建议把两个原生能力合并到一个扩展：

| 能力 | 用途 |
|---|---|
| `TrayIcon` | 通知区图标、菜单、点击 |
| `GlobalMouse` | 全局左键状态（见 [光标交互](../05-行为/02-光标交互规范.md)） |

理由：两者都需要 Win32 消息/状态，合并可减少一个二进制、一次打包、一套构建。

> 如果暂时不做 GDExtension：降级为"右键宠物菜单 + 热键"，但没有托盘图标，且不能隐藏宠物后找回。

---

## 2. 托盘图标

- 位置：Windows 通知区（任务栏右下角，可能在溢出区）。
- 图标：`icon.ico`（16/32/48/256），AI 连接时可用叠加小圆点/换色。
- Tooltip：`Stickman Pet · AI 未连接 / 等待连接 / 已连接 / 错误`。
- 左键单击：显示/隐藏宠物。
- 右键：菜单。
- 双击：打开设置窗口（可选；MVP 只做菜单）。

---

## 3. 菜单结构

```
Stickman Pet                    AI: 未连接
────────────────────────────────────────
显示宠物                         ✓
始终置顶                         ✓
鼠标穿透                         自动 ▸
缩放                             ▸ 0.8 / 1.0 / 1.25 / 1.5 / 2.0
配色                             ▸ 橙 / 绿 / 蓝 / 红 / 黄
静音                             –
────────────────────────────────────────
AI 控制                          –
  AI 状态：未连接
  启动 AI 客户端（可选）
────────────────────────────────────────
开机自启                         –
打开设置…
查看日志
────────────────────────────────────────
退出
```

规则：

- 勾选项来自当前配置，切换后立即生效并持久化。
- `AI 控制` 在 `AiBridge` 未实现前置灰；实现后可用。
- `启动 AI 客户端` 仅当配置了 Go 可执行文件路径时显示；否则由用户手动启动。
- `鼠标穿透` 子菜单：自动 / 强制穿透 / 关闭（调试用）。
- `退出` 必须走优雅退出：保存配置、停 AI、删托盘图标、恢复窗口 flags。

## 4. AI 开关语义

| 配置 | 行为 |
|---|---|
| `ai.enabled=false` | `AiBridge` 停止监听/断开客户端；模式回 `AUTONOMOUS`；托盘显示"未启用" |
| `ai.enabled=true` | 启动监听；状态"等待连接"；AI 连上后"已连接"；仍默认自主，直到 `set_mode: remote` |
| 连接中断 | 状态"未连接"；1s 后自主；自动重连由 Go 客户端负责 |
| 运行中关闭 | 发送 `error ai_disabled`，关闭连接，停止监听 |
| 启动失败（端口占用） | 状态"错误"；不阻塞桌宠；日志记录 |

- 托盘开关只控制"是否允许 AI 接入"，不直接控制角色。
- AI 命令仍受 `MANUAL > REMOTE_AI > AUTONOMOUS` 仲裁。
- 关闭 AI 不会退出 Go 客户端；Go 客户端重连会收到 `ai_disabled` 并退避。

## 5. 设置项

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `app.autostart` | bool | false | 开机自启（HKCU Run） |
| `app.start_minimized` | bool | false | 启动时只显示托盘（可选） |
| `pet.visible` | bool | true | 显示宠物 |
| `window.always_on_top` | bool | true | 置顶 |
| `window.scale` | float | 1.25 | 0.8–2.0 |
| `pet.color` | string | orange | green/orange/blue/red/yellow |
| `pet.muted` | bool | false | 静音 |
| `ai.enabled` | bool | false | 允许 AI 接入 |
| `ai.auto_launch` | bool | false | 托盘启动时拉起 Go 客户端（可选） |
| `ai.executable` | string | "" | Go 客户端路径（仅本地） |
| `tray.notifications` | bool | true | 连接/错误气泡提示 |

写入 `user://pet.cfg`，沿用 [配置与持久化](../06-工程/01-配置与持久化.md) 的原子写与迁移。

## 6. 生命周期

```
Godot 启动
  → 创建窗口
  → 加载配置
  → 创建托盘（失败则降级）
  → 若 ai.enabled：启动 AiBridge 监听
  → 若 app.start_minimized：隐藏宠物，只留托盘
  → 进入主循环

退出（托盘/右键/命令行）
  → 保存配置
  → 停止 AiBridge / 关闭连接
  → Shell_NotifyIcon(NIM_DELETE)
  → 恢复窗口 flags
  → quit
```

单实例：第二个进程检测到已有实例后退出；可选通过本机 IPC 让已有实例显示托盘/宠物。

## 7. Win32 实现要点

- `Shell_NotifyIcon(NIM_ADD/NIM_MODIFY/NIM_DELETE, NOTIFYICONDATAW)`。
- 创建 **message-only window**（`HWND_MESSAGE`）接收 `WM_COMMAND`、`WM_RBUTTONUP`、`WM_LBUTTONUP`。
- 右键：`CreatePopupMenu` + `TrackPopupMenu`，菜单 ID 映射到 `AppCommand`。
- 图标：`LoadImage` 从 `.ico` 或资源加载；`NOTIFYICONDATA.hIcon`。
- 线程：托盘消息泵放在独立线程，事件通过 `call_deferred` 回到 Godot 主线程；不要在消息线程改场景。
- 退出前必须 `NIM_DELETE`，否则可能残留"幽灵图标"直到鼠标划过。
- DPI：托盘菜单由系统绘制，不需要额外缩放；图标提供多尺寸。

## 8. 失败与降级

| 失败 | 处理 |
|---|---|
| GDExtension 缺失/加载失败 | 托盘不可用；保留宠物右键菜单与热键；不允许隐藏宠物 |
| `Shell_NotifyIcon` 失败 | 记录日志；继续运行 |
| 菜单动作异常 | 捕获并 `push_warning`；不崩溃 |
| 退出时删除图标失败 | 系统会在进程结束后清理；仍记录 |
| 端口被占用（AI） | 托盘显示"AI 错误"；不阻塞桌宠 |

## 10. 与 AI/门禁的关系

- 托盘是 **L0 平台能力**，不依赖 Go AI；AI 只是菜单里的一个开关。
- `TrayService` 只发 `AppCommand`，不直接改 Pet/Brain。
- 门禁需检查 `docs/02-平台/03-托盘与设置.md` 存在，以及配置 Schema 含 `ai.enabled`。
