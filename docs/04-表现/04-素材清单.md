# 素材清单与规范

> 上级：[文档中心](../README.md) · 相关：[内容设计](../01-总览/04-内容设计.md)、[音频与界面](03-音频与界面.md)
> 目的：明确"哪些素材必须提前做、做成什么规格、什么时候要、授权怎么记"。
> 结论：火柴人**不需要角色贴图/序列帧**；需要的是图标、动画数据与音效。

---

## 1. 先说什么不需要

| 不需要 | 原因 |
|---|---|
| 火柴人角色 sprite sheet / 逐帧动画 | 13 骨 + 程序化 Line2D，动作由 JSON 驱动 |
| Spine / DragonBones 工程 | 自研骨骼与 PBD，不引入第三方运行时 |
| 行走/待机序列帧 | 剪辑是骨骼关键帧，不是图片 |
| BGM / 配音 / 对白 | 桌宠不应主动出声；无对白是风格的一部分 |
| UI 背景/大图皮肤 | 默认 Theme + 纯色/线条即可 |
| 自定义鼠标指针 | 系统箭头 + 代码绘制圆环；可选做抓取手型 |

> 角色美术只做两件事：**调骨骼比例/线宽/配色**，以及**写动作关键帧**。

## 3. 动画数据

不是图片，但属于必须提前写的内容。每条是一个 JSON 剪辑（绝对角、时间升序、循环闭合）。

### 3.1 基础（P2，9 条）

`idle`、`walk`、`sit`、`sleep`、`poke`、`startle`、`recover`、`drag_idle`、`look`。

### 3.2 小剧场（P4，8 条）

`peek`、`wave`、`dash`、`stretch`、`punch`、`kick`、`carry`、`play_dead`。

### 3.3 事件

`breath`、`step_l/step_r`、`land`、`grab`、`release`，写在剪辑 `events` 里。

> 动画 JSON 由程序/手工生成，不需要美术软件；但动作节奏需要人调。

## 4. 音效清单

### 4.1 核心音效（P3–P4）

| 文件 | 数量 | 触发 | 优先级 |
|---|---|---|---|
| `sfx_step_01..03` | 3 | 走路脚步 | P0 |
| `sfx_land_soft` / `sfx_land_hard` | 2 | 落地（按冲击） | P0 |
| `sfx_grab` | 1 | 抓住 | P0 |
| `sfx_throw_whoosh` | 1 | 抛出 | P0 |
| `sfx_impact_hit` | 1 | SOLID 撞击/重击 | P0 |
| `sfx_poke_01..02` | 2 | 被戳 | P1 |
| `sfx_dizzy` | 1 | 眩晕 | P1 |
| `sfx_snore_loop` | 1 | 睡觉循环 | P1 |
| `sfx_wake_groan` | 1 | 惊醒 | P1 |
| `sfx_menu_click` | 1 | 菜单点击 | P1 |
| `sfx_menu_open` / `close` | 2 | 菜单开关 | P2 |
| `sfx_error` | 1 | 配置/透明失败 | P2 |
| `sfx_ai_connect` / `disconnect` / `error` | 3 | AI 状态（可选） | P2 |

合计约 **21 个文件**。不需要 BGM、配音、环境音。

### 4.2 规格

| 项 | 要求 |
|---|---|
| 格式 | 短音效（<200ms）WAV 16-bit；循环/较长 OGG Vorbis |
| 采样率 | 44.1kHz |
| 声道 | 单声道 |
| 峰值 | -1 dBFS，避免削波 |
| 响度 | 约 -16 LUFS（短音效），同组一致 |
| 裁剪 | 去头尾静音，5ms 淡入淡出防爆音 |
| 时长 | 脚步 80–150ms；落地 150–300ms；循环 2–4s |
| 大小 | 单文件 <100KB；总音效 <5MB |
| 命名 | `sfx_<category>_<name>_<variant>.wav/ogg` |

### 4.3 变体与随机

- 脚步 3 个变体，音高随机 ±8%；
- 戳 2 个变体；
- 同一音效 50ms 内只响一次（见 [音频与界面](03-音频与界面.md)）。

## 6. 设置与音效开关

| 设置 | 行为 |
|---|---|
| `pet.muted` | 总静音；所有 SFX/UI 停止，播放前判断 |
| `pet.volume` | Master 音量 0–1 |
| `audio.sfx_volume`（可选） | 音效总线 |
| `audio.ui_volume`（可选） | UI 总线 |
| `tray.notifications` | 是否弹连接/错误气泡，不影响音效 |

- 托盘/右键菜单都能开关静音；
- 静音状态持久化，重启保持；
- 启动时不要播放声音，避免突然吓人；首次交互后再出声。

## 7. 授权与来源记录

必须维护 `assets/sfx/LICENSES.md`：

| 字段 | 示例 |
|---|---|
| 文件 | `sfx_step_01.wav` |
| 来源 | 自录 / freesound 链接 |
| 作者 | — |
| 许可证 | CC0 / CC-BY 4.0 / 原创 |
| 修改 | 裁剪、变速、降噪 |

规则：

- 优先自己录/合成，或 CC0；
- CC-BY 必须署名；
- 不使用时删除文件与记录；
- 贴图/图标保留源文件与授权说明；
- 发布包附 `LICENSE` 与 `OFL.txt`。

## 8. 什么时候准备

| 阶段 | 需要准备 |
|---|---|
| **现在（P0/P1 前）** | 应用/托盘 `.ico`、角色配色/线宽、脚步/落地/抓取/抛出/撞击 5 类音效 |
| **P2 前** | 9 条基础动画 JSON、呼吸/脚步事件 |
| **P3 前** | 落地/撞击/投掷音效定稿，音效池参数 |
| **P4 前** | 8 条小剧场动画、戳/眩晕/呼噜/惊醒、菜单音效 |
| **P5 前** | 2.5D 阴影/倾斜参数定稿（无额外贴图） |
| **P6 前** | AI 连接/错误音效、整体响度统一、授权清单 |

> 最小启动集：**图标 + 5 类核心音效 + 配色**。其余可以边做边补。
