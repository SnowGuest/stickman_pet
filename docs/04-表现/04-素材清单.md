# 素材清单与规范

> 上级：[文档中心](../README.md) · 相关：[内容设计](../01-总览/04-内容设计.md)、[音频与界面](03-音频与界面.md)
> 目的：明确"哪些素材必须提前做、做成什么规格、什么时候要、授权怎么记"。
> 结论：火柴人**不需要角色贴图/序列帧**；需要的是图标、动画数据与音效。

---

## 1. 先说什么不需要

| 不需要 | 原因 |
|---|---|
| 火柴人角色 sprite sheet / 逐帧动画 | 13 骨 + 单条 Line2D 单笔路径，动作由 JSON 驱动 |
| Spine / DragonBones 工程 | 自研骨骼与 PBD，不引入第三方运行时 |
| 行走/待机序列帧 | 剪辑是骨骼关键帧，不是图片 |
| BGM / 配音 / 对白 | 桌宠不应主动出声；无对白是风格的一部分 |
| UI 背景/大图皮肤 | 默认 Theme + 纯色/线条即可 |
| 自定义鼠标指针 | 系统箭头 + 代码绘制圆环；可选做抓取手型 |

> 角色美术只做两件事：**调骨骼比例/线宽/配色**，以及**写动作关键帧**。

### 2.3 审查记录（2026-10-19）

- `CustomTextures/` 21 张 PNG 全部是 **1×1 单色色块**，没有空间贴图内容，不能当角色纹理使用；

- 色号已提取到 `assets/palettes/stickman_palette.json`，源纹理全部不入库。

## 3. 动画数据

不是图片，但属于必须提前写的内容。每条是一个 JSON 剪辑（绝对角、时间升序、循环闭合）。

### 3.1 基础（P2，9 条）

`idle`、`walk`、`sit`、`sleep`、`poke`、`startle`、`recover`、`drag_idle`、`look`。

### 3.2 小剧场（P4，8 条）

`peek`、`wave`、`dash`、`stretch`、`punch`、`kick`、`carry`、`play_dead`。

### 3.3 事件

`breath`、`step_l/step_r`、`land`、`grab`、`release`，写在剪辑 `events` 里。

> 动画 JSON 由程序/手工生成，不需要美术软件；但动作节奏需要人调。

## 4. 音效清单

### 4.1 已提供（7）

| 文件 | 时长 | 触发 |
|---|---|---|
| `sfx_step_01.ogg` | 0.17s | 走路脚步 |
| `sfx_land_soft.ogg` | 0.29s | 轻落地 |
| `sfx_wave_whoosh.ogg` | 0.16s | 单次挥动起手 whoosh |
| `sfx_sit.ogg` | 0.93s | 坐下 |
| `sfx_wave.ogg` | 0.89s | 连续挥手（循环） |
| `sfx_clap.ogg` | 1.27s | 鼓掌 |
| `sfx_pop.ogg` | 0.07s | 戳/弹出 |

均为 OGG Vorbis、44.1kHz、双声道；未转码、未做响度归一。来源记录见 [assets/sfx/README.md](../../assets/sfx/README.md)。

### 4.2 待补

`sfx_step_02..03`、`sfx_land_hard`、`sfx_grab`、`sfx_impact_hit`、`sfx_poke_01..02`、`sfx_dizzy`、`sfx_snore_loop`、`sfx_wake_groan`、`sfx_throw_whoosh`、`sfx_menu_click/open/close`、`sfx_error`、`sfx_ai_connect/disconnect/error`。

目标约 24 个；当前可用 7 个。不需要 BGM、配音、环境音。

### 4.3 规格

| 项 | 要求 |
|---|---|
| 格式 | OGG Vorbis（已提供文件直接使用，不强制转 WAV） |
| 采样率 | 44.1kHz |
| 声道 | 双声道（已提供）；后续新增可统一为单声道 |
| 峰值/响度 | 导入后按音频总线统一，避免削波 |
| 裁剪 | 已提供文件保持原样；新增文件去头尾静音、5ms 淡入淡出 |
| 大小 | 单文件 <100KB；总音效 <5MB |
| 命名 | `sfx_<category>_<name>_<variant>.ogg` |

### 4.4 变体与随机

- 脚步目标 3 个变体，当前只有 `01`；
- 戳目标 2 个变体，当前用 `sfx_pop`；
- 同一音效 50ms 内只响一次（见 [音频与界面](03-音频与界面.md)）。

## 6. 设置与音效开关

| 设置 | 行为 |
|---|---|
| `pet.muted` | 总静音；所有 SFX/UI 停止，播放前判断 |
| `pet.volume` | Master 音量 0–1 |
| `audio.sfx_volume`（可选） | 音效总线 |
| `audio.ui_volume`（可选） | UI 总线 |
| `tray.notifications` | 是否弹连接/错误气泡，不影响音效 |

- 托盘/右键菜单都能开关静音；
- 静音状态持久化，重启保持；
- 启动时不要播放声音，避免突然吓人；首次交互后再出声。

## 7. 授权与来源记录

必须维护 `assets/sfx/LICENSES.md`：

| 字段 | 示例 |
|---|---|
| 文件 | `sfx_step_01.wav` |
| 来源 | 自录 / freesound 链接 |
| 作者 | — |
| 许可证 | CC0 / CC-BY 4.0 / 原创 |
| 修改 | 裁剪、变速、降噪 |

规则：

- 优先自己录/合成，或 CC0；
- CC-BY 必须署名；
- 不使用时删除文件与记录；
- 贴图/图标保留源文件与授权说明；
- 发布包附 `LICENSE` 与 `OFL.txt`。
