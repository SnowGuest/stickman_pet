| 名称 | HEX | RGB | 线条/身体 | 头部 |
|---|---|---|---|---|
| Green | `#66CC00` | 102, 204, 0 | 绿色 | 实心圆 |
| **Orange** | `#FF6600` | 255, 102, 0 | 橙色 | **空心圆（默认）** |
| Blue | `#33CCFF` | 51, 204, 255 | 蓝色 | 实心圆 |
| Red | `#CC0000` | 204, 0, 0 | 红色 | 实心圆 |

> 橙色空心头是识别特征；本项目只把它作为配色变体，不使用角色名、不复制具体造型比例之外的原创设计。

## 2. 无脸规则

- 火柴人**没有脸**：不绘制五官，也不做面部参数。
- 头是一个圆，只有"实心"和"空心"两种画法。
- 情绪靠头部朝向、身体倾斜、挤压/拉伸、动作节奏和音效表达。
- 任何配色下都不得添加五官或面部符号（汗滴/星星是身体外的 FX，不是脸）。

## 3. 头部画法

### 3.1 实心（Green / Blue / Red / Yellow）

```gdscript
draw_circle(center, head_radius, body_color)
```

### 3.2 空心（Orange）

```gdscript
# 只画圆环，内部透明；桌面/壁纸透出来
draw_arc(center, head_radius, 0.0, TAU, 48, body_color, head_line_width, true)
```

- `head_line_width` 与身体线宽一致（默认 6px @1x）；
- 空心内部**不填白**，保持透明；
- 深色壁纸下靠白色 halo 保证可见；
- 空心头不画任何内部细节。

### 3.3 描边 / Halo

| 背景 | 处理 |
|---|---|
| 深色壁纸 | 线条外 2.5px 白色 halo（先画白、再画色） |
| 浅色壁纸 | 线条外 1px 深色 halo（`#121212`，alpha 0.35） |
| 黄色 | 浅色背景必须加深色 halo，否则对比度不足 |

- Halo 只描外轮廓，不改变线宽；
- 空心头的 halo 同时描内外圈，避免空心边缘糊；
- 不使用模糊/发光，透明窗下会出灰边。

---

## 4. 渲染参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `line_width` | 6.0 px @1x | 身体线宽 |
| `head_radius` | 18.0 px @1x | 头圆半径 |
| `head_line_width` | 6.0 px @1x | 空心头环宽 |
| `halo_dark` | 2.5 px | 深色背景白 halo |
| `halo_light` | 1.0 px | 浅色背景深 halo |
| `joint_cap` | round | 关节圆头 |

所有值乘 `scale`；`line_width` 与 `head_line_width` 保持一致，避免空心头看起来比身体粗。

## 5. 配置

```ini
[pet]
color="orange"          # green | orange | blue | red | yellow
head_style="auto"       # auto: orange=hollow, 其他=filled；调试可强制
```

- `head_style=auto` 时由 `color` 推导，不单独存两份配置；
- 切换颜色立即生效，持久化；
- 调试面板可强制 `filled/hollow` 检查描边；
- 未来皮肤包只换色板，不改渲染代码。

## 6. 对比度与可读性

| 颜色 | 白底 | 深色底 | 备注 |
|---|---|---|---|
| Green `#66CC00` | 中 | 好 | 白底建议深 halo |
| Orange `#FF6600` | 好 | 好 | 空心头靠 halo |
| Blue `#33CCFF` | 弱 | 好 | 白底必须深 halo |
| Red `#CC0000` | 好 | 中 | 深色底加白 halo |
| Yellow `#FFCC00` | 弱 | 好 | 白底必须深 halo |

验收时在纯白、纯黑、桌面壁纸三种背景下各看一眼。

## 7. IP 边界

- 色号本身是事实数据；但"橙色空心头 + 火柴人"的组合具有识别性，**不要**把角色命名为 The Second Coming、Green、Blue、Red、Yellow 等原作角色名。
- 不复制 Comic Studio 内的 sprite、分镜、动作帧、音效。
- 不声称与 Alan Becker 官方合作/授权。
- 发布页保留非官方声明；如未来商业化，重新评估角色形象与商标风险。

详见 [风险与合规](../00-项目/03-风险与合规.md)。
