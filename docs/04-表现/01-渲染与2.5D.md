# 渲染与 2.5D

> 上级：[文档中心](../README.md) · 领域：表现层
> 覆盖：绘制顺序、线条与描边、局部坐标、分层、视差、倾斜/挤压、转身、头与朝向、阴影。

---

## 1. 职责与边界

**做**：把 `RigPose` 画成可读的火柴人；维护 2.5D 层级与视觉变换；输出绘制轮廓供命中/穿透使用。
**不做**：不改 `pose`、不做物理、不做命中判定（只提供几何）。

渲染是**纯函数**：相同 `RigPose + 时间 + 速度` → 相同画面。便于录制回放与截图对比。

---

## 2. 节点结构

```
Pet (Node2D)                     # position = 骨盆世界坐标
├── Visual (Node2D)              # rotation = lean, scale = squash
│   ├── LayerBack   (z=-5)       # 左臂、左腿
│   ├── LayerBody   (z=0)        # spine、neck
│   ├── LayerFront  (z=8)        # 右腿
│   ├── LayerArm    (z=12)       # 右臂
│   ├── LayerHead   (z=20)       # 头（无五官）
│   └── LayerFx     (z=30)       # 汗滴、星星
├── Shadow (Node2D)              # 世界坐标，不随 Visual 变换
└── Debug (Node2D, 可选)
```

为什么 `Visual.position = 骨盆`：`rotation/scale` 自动绕骨盆生效，不需要 `pivot_offset`，也不会让头部绕屏幕原点旋转。

---

## 3. 绘制顺序与深度层

`CanvasItem.z_index` 在同级内排序，子节点默认 `z_as_relative`，实际 z = 父 z + 自身 z。宠物内部使用局部 z，范围 -5..30。

| 层 | z | 内容 | 视觉处理 |
|---|---|---|---|
| LayerBack | -5 | upper_arm_l、forearm_l、thigh_l、shin_l、foot_l | 亮度 ×0.72，缩放 0.97 |
| LayerBody | 0 | spine、neck | 纯黑 #121212 |
| LayerFront | 8 | thigh_r、shin_r、foot_r | 纯黑 |
| LayerArm | 12 | upper_arm_r、forearm_r | 纯黑，描边更亮 |
| LayerHead | 20 | 头圆（无五官） | 白底 + 黑边 |
| LayerFx | 30 | 粒子/情绪符号 | 叠加混合 |

> 左/右是"角色面朝右"的定义；转身时交换前后层（见第 7 章）。

## 4. 线条与描边

每根骨骼两个 `Line2D`：

```gdscript
func _make_line(color: Color, width_pad: float) -> Line2D:
    var l := Line2D.new()
    l.default_color = color
    l.begin_cap_mode = Line2D.LINE_CAP_ROUND
    l.end_cap_mode = Line2D.LINE_CAP_ROUND
    l.joint_mode = Line2D.LINE_JOINT_ROUND
    l.antialiased = true
    l.round_precision = 8
    l.width = width_pad
    return l
```

- 先画白色描边（`width + 2.5`，alpha 0.9），再画黑色本体。
- 圆头端点让相邻骨骼自然"焊"成关节，不需要额外画圆。
- `antialiased` 在深色壁纸上有轻微灰边，可接受；追求绝对锐利时改用自定义多边形胶囊。
- 线宽随 `base_scale * dpi` 缩放；`Visual.scale` 会二次缩放线宽，挤压时需按 `1/scale.y` 补偿（可选）。

## 5. 同步

```gdscript
func sync(pose: RigPose, root: Vector2) -> void:
    position = root
    for i in bones.size():
        var b := bones[i]
        var a := pose.joint_pos[b.start_idx] - root
        var c := pose.joint_pos[b.end_idx] - root
        _halo[i].points = PackedVector2Array([a, c])
        _line[i].points = PackedVector2Array([a, c])
        _line[i].width = b.width * px_scale
        _halo[i].width = b.width * px_scale + 2.5
```

- 只更新 `points` 与 `width`，不重建节点。
- 复用 `PackedVector2Array`（`resize(2)` 后赋值），避免每帧分配。
- 头圆在 `LayerHead._draw()` 中绘制，位置用 `head_center - root`。

## 6. 倾斜、挤压与视差

```gdscript
func update_visual(dt: float, velocity: Vector2, drag_velocity: Vector2) -> void:
    var target_lean := clampf(-drag_velocity.x * 0.0008, -0.16, 0.16)
    rotation = lerp_angle(rotation, target_lean, 1.0 - exp(-10.0 * dt))

    var stretch := clampf(1.0 + absf(velocity.y) * 0.00030, 1.0, 1.12)
    scale = Vector2(1.0 / sqrt(stretch), stretch)
```

- 水平拖动 → 整体倾斜，模拟"被拎着走"的滞后。
- 下落 → 纵向拉伸 + 横向收窄（体积守恒）。
- 落地瞬间反向：`stretch = 0.88` 持续 80ms，再弹回。
- 倾斜上限 0.16rad（约 9°）；再大就不像火柴人。

视差：

```gdscript
for layer in _layers:
    layer.position = -drag_velocity * 0.0015 * layer.depth
```

`depth` 取 -5..30 的归一化值；拖得越快，前后层错位越明显。

## 7. 转身

```gdscript
func update_facing(dt: float, vx: float) -> void:
    if absf(vx) > 30.0:
        facing = signf(vx)

    var target := float(facing) / sqrt(scale.y)
    scale.x = lerpf(scale.x, target, 1.0 - exp(-18.0 * dt))
    if absf(scale.x) < 0.05:
        _swap_depth_layers()
```

- 转身时 `scale.x` 经过 0，在"看不见"的瞬间交换左右层。
- `_swap_depth_layers` 只改层的 `z_index` 与骨骼归属，不改骨骼数据。
- 交换必须幂等：记录 `_swapped` 布尔，避免每帧翻转。

## 8. 头与朝向

火柴人**没有脸**：头是一个圆，不画五官。

```gdscript
func _draw_head(center: Vector2, r: float) -> void:
    draw_circle(center, r, Color.WHITE)
    draw_arc(center, r, 0.0, TAU, 40, Color("#121212"), 3.0, true)
```

- 头部朝向由 `HeadAim` 给目标角，`neck`/`head` 两根骨平滑转向；
- 不靠面部：注意力通过头转、抬头/低头、身体前倾表达；
- 眩晕用三颗小星星绕头，`LayerFx` 里画；
- 受惊只做后仰/弹跳/汗滴，不做瞪眼。

头部不跟随 `Visual.rotation` 以外的变换，否则挤压时会变形过度；必要时对头部做反向缩放补偿。

## 9. 阴影

```gdscript
func sync_shadow(pose: RigPose) -> void:
    var h := maxf(floor_y - pose.joint_pos[pelvis], 0.0)
    var t := clampf(h / 420.0, 0.0, 1.0)
    scale = Vector2(1.15 - 0.55 * t, 0.32 - 0.16 * t)
    modulate.a = 0.30 * (1.0 - 0.65 * t)
    position = Vector2(pose.joint_pos[pelvis].x, floor_y)
```

- 阴影是"离地高度"的主要线索，参数比模型更重要。
- 颜色用 `#000000` 加 alpha，不用模糊贴图（透明窗下模糊会出灰边）。
- 落地瞬间阴影短暂放大 1.1×，制造冲击。

## 10. 分辨率与缩放

| 量 | 规则 |
|---|---|
| 骨骼长度 | `length * base_scale * dpi` |
| 线宽 | `width * base_scale * dpi` |
| 命中半径 | 同线宽公式 + 6px |
| 屏幕坐标 | 不缩放，窗口 1:1 |
| 阴影 | 随 `base_scale * dpi` |

不要在根节点用 `scale` 做整体缩放：会让线宽、阴影、命中半径全部失控。统一乘到骨骼与绘制参数上。

---

## 11. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 线宽不一致 | 部分骨骼漏乘 scale | 统一从 `px_scale` 取值 |
| 头旋转错位 | 头用世界坐标绘制 | 改为 `head_center - root` |
| 转身闪烁 | 每帧交换层 | 只在 |scale.x| < 0.05 时交换一次 |
| 深色壁纸消失 | 无描边 | 白色描边 + 阴影 |
| 挤压时线变粗 | Visual.scale 二次缩放 | 线宽乘 `1/scale.y` |
| 高 DPI 模糊 | 窗口 stretch 未关 | `stretch/mode=disabled` |
