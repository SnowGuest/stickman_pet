# 渲染与 2.5D

> 上级：[文档中心](../README.md) · 领域：表现层
> 覆盖：单笔纯色路径、头、倾斜/挤压、转身、阴影、缩放。
> 线条规范：**无白色/深色描边；整只火柴人一条连续 Line2D，关节处无缝。**

---

## 1. 职责与边界

**做**：把 `RigPose` 画成一只纯色、一笔画完成的火柴人；维护头圆、视觉倾斜与后续阴影。
**不做**：不改 `pose`、不做物理、不做命中判定（只提供几何）。

渲染是**纯函数**：相同 `RigPose + 时间 + 速度` → 相同画面。便于录制回放与截图对比。

---

## 2. 节点结构

```
Pet (Node2D)                     # position = 骨盆世界坐标
├── Visual (Node2D)              # rotation = lean, scale = squash
│   ├── SdfLayer (CanvasLayer)   # 默认：全屏 SDF 笔画
│   │   └── SdfStroke (ColorRect)
│   ├── Stroke (Line2D)          # --line 回退：21 点单笔
│   └── HeadCircle (Node2D)      # --line 回退：纯色圆/圆环
├── Shadow (Node2D)              # P5，接触阴影
└── Debug (Node2D, 可选)
```

默认渲染是 **SDF 屏幕空间笔画**：13 根骨骼的胶囊距离场取并集，头圆环单独计算。
`--line` 回退到 21 点单笔 Line2D。2.5D 前后关系由投影/姿态表达，不做压暗或换色。

---

## 3. SDF 笔画与单笔路径

### 3.1 默认 SDF

- 13 根骨骼投影为屏幕空间线段；
- 双臂用二次贝塞尔曲线（肩→肘控制→手），肘部自然弯折；
- 双腿从骨盆单点分出：左腿 70° 向右、右腿 90°，双脚同向 +X；
- 每像素取到所有线段的最小距离；
- 距离小于线宽 → 纯色；
- 骨头端点和关节天然圆角；
- 空心头的圆环单独计算；
- 头圆内部会清除骨骼线，避免颈线穿进空心头。

### 3.2 `--line` 回退

`Stroke` 是一条 `Line2D`，共 21 个点，顺序为：

```text
左手 → 左肘 → 胸 → 颈顶 → 胸 → 骨盆
→ 左膝 → 左踝 → 左脚（+X）→ 左踝 → 左膝 → 骨盆
→ 右膝 → 右踝 → 右脚（+X）→ 右踝 → 右膝 → 骨盆
→ 胸 → 右肘 → 右手
```

要点：

- 躯干、颈、双臂、双腿、双脚都在**同一条路径**里，利用回头段连接分支；
- 双脚为 L 形：左踝→左脚、右踝→右脚都朝同一方向（+X），脚长 3px，只露出很短一截；
- 所有拐点使用 `LINE_JOINT_ROUND`，两端使用 `LINE_CAP_ROUND`；
- 同色、同宽、无描边，因此关节处不会出现白缝或"几根棍子拼接"的接缝；
- 头骨 `head` 不画成线段，只画一个圆；圆底边与 `neck_top` 相接，同色所以仍然连续；

`Line2D` 不包含头圆；头圆是独立节点，但颜色与线完全一致，不添加任何轮廓。

## 4. 线条：纯色，无描边

```gdscript
func _make_stroke(color: Color, width: float) -> Line2D:
    var l := Line2D.new()
    l.default_color = color
    l.width = width
    l.begin_cap_mode = Line2D.LINE_CAP_ROUND
    l.end_cap_mode = Line2D.LINE_CAP_ROUND
    l.joint_mode = Line2D.LINE_JOINT_ROUND
    l.antialiased = true
    l.round_precision = 8
    return l
```

- **只画一遍**：不画白色 halo，也不画深色 halo；
- 线条用 `Line2D.antialiased`，项目开启 2D MSAA 8×，降低斜线锯齿；
- 线宽取 `render.line_width`（固定 6px @1x），头部取 `head_line_width`；
- 纯色：同一只火柴人的所有肢体、躯干、头使用同一个颜色；
- 深色/浅色壁纸的对比度由**换色板**解决，不靠描边；
- 黄色 `#FFCC00` 在浅色壁纸上对比弱，这是已知取舍，不再加白边。

## 5. 同步

```gdscript
func sync(pose: RigPose, root: Vector2) -> void:
    position = root
    var points := PackedVector2Array()
    for joint in PATH_JOINTS:
        points.append(pose.joint_pos[joint] - root)
    stroke.points = points
    head.position = pose.joint_pos[neck_top] - root + Vector2(0, -head_radius)
```

- 每帧只更新 `points` 与头部位置，不重建节点；
- 路径点全部来自 `RigState.resolve()`，渲染层不改姿态；
- 头圆位置用 `neck_top` 上方 `head_radius`，不用 `head_top`，避免颈部线段穿进空心圆。

## 6. 倾斜、挤压与视差

```gdscript
func update_visual(dt: float, velocity: Vector2, drag_velocity: Vector2) -> void:
    var target_lean := clampf(-drag_velocity.x * 0.0008, -0.16, 0.16)
    rotation = lerp_angle(rotation, target_lean, 1.0 - exp(-10.0 * dt))

    var stretch := clampf(1.0 + absf(velocity.y) * 0.00030, 1.0, 1.12)
    scale = Vector2(1.0 / sqrt(stretch), stretch)
```

- 水平拖动 → 整体倾斜，模拟"被拎着走"的滞后。
- 下落 → 纵向拉伸 + 横向收窄（体积守恒）。
- 落地瞬间反向：`stretch = 0.88` 持续 80ms，再弹回。
- 倾斜上限 0.16rad（约 9°）；再大就不像火柴人。

视差：

- P1 没有多层，不做视差；
- P5 若增加层，只允许同色层的 z-order 错位，不允许压暗、换色或加描边。

## 7. 转身

```gdscript
func update_facing(dt: float, vx: float) -> void:
    if absf(vx) > 30.0:
        facing = signf(vx)

    var target := float(facing) / sqrt(scale.y)
    scale.x = lerpf(scale.x, target, 1.0 - exp(-18.0 * dt))
```

- 转身只翻转 `scale.x`，路径点不变，因此不会产生接缝；
- 头是圆，翻转时不需要换层；
- P1 没有 `_swap_depth_layers()`；P5 若引入分层，只在 `|scale.x| < 0.05` 时交换一次 z-order。

## 8. 头与朝向

火柴人**没有脸**：头是一个圆，不画五官。颜色与实心/空心规则见 [配色与无脸规范](05-配色与无脸规范.md)。

```gdscript
func _draw_head(center: Vector2, r: float, palette: Palette) -> void:
    if palette.head_style == Palette.HOLLOW:      # 橙色：空心头
        draw_arc(center, r, 0.0, TAU, 48, palette.color, palette.head_line_width, true)
    else:                                          # 其他颜色：实心圆
        draw_circle(center, r, palette.color)
```

- 默认橙色 `#FF6600` + 空心头；其余四色实心；
- 空心头只有一圈颜色，没有内外描边；
- 头部朝向由 `HeadAim` 给目标角，`neck`/`head` 两根骨平滑转向；
- 不靠面部：注意力通过头转、抬头/低头、身体前倾表达；
- 眩晕用三颗小星星绕头，`LayerFx` 里画；
- 受惊只做后仰/弹跳/汗滴，不做瞪眼。

头部不跟随 `Visual.rotation` 以外的变换，否则挤压时会变形过度；必要时对头部做反向缩放补偿。

## 9. 阴影

```gdscript
func sync_shadow(pose: RigPose) -> void:
    var h := maxf(floor_y - pose.joint_pos[pelvis], 0.0)
    var t := clampf(h / 420.0, 0.0, 1.0)
    scale = Vector2(1.15 - 0.55 * t, 0.32 - 0.16 * t)
    modulate.a = 0.30 * (1.0 - 0.65 * t)
    position = Vector2(pose.joint_pos[pelvis].x, floor_y)
```

- 阴影是"离地高度"的主要线索，参数比模型更重要。
- 颜色用 `#000000` 加 alpha，不用模糊贴图（透明窗下模糊会出灰边）。
- 落地瞬间阴影短暂放大 1.1×，制造冲击。
- P1 不画阴影；P5 实现。

## 10. 分辨率与缩放

| 量 | 规则 |
|---|---|
| 路径点 | `(joint - root) * base_scale * dpi` |
| 线宽 | `render.line_width` 随 `Visual.scale` 缩放 |
| 头半径 | `head_radius * base_scale * dpi` |
| 命中半径 | 同线宽公式 + 6px |
| 屏幕坐标 | 不缩放，窗口 1:1 |
| 阴影 | P5 随 `base_scale * dpi` |

P1 用 `Visual.scale` 统一缩放路径；命中与穿透使用未缩放的 `RigPose` 再乘同一比例，
禁止在坐标链里混入两次缩放。

## 11. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 关节有白缝 | 每根骨单独画、带白 halo | SDF 并集或单条 Line2D，纯色、无描边 |
| 看起来像几根棍子 | 分骨绘制、线宽不一致 | SDF 并集 + 统一 `line_width` |
| 头颈断开 | 头圆按 `head_top` 定位 | 用 `neck_top - head_radius` |
| 空心圆内有线段 | 画了 `head` 骨线段 | 头骨不画线，只画圆 |
| 浅色壁纸看不清 | 无描边 + 黄色对比弱 | 换深色/高对比色板，不加白边 |
| 高 DPI 模糊 | 窗口 stretch 未关 | `stretch/mode=disabled` |
