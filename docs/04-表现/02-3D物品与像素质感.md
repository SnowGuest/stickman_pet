# 3D 物品与像素质感

> 上级：[文档中心](../README.md) · 领域：表现层
> 覆盖：Minecraft 风格掉落物的离屏 3D 渲染、像素完美规则、与 2D 的合成、交互与性能。
> 窗口与穿透见 [窗口与穿透](../02-平台/01-窗口与穿透.md)。

---

## 1. 方案边界

**做**：让物品看起来在 3D 里旋转（绕 Y、俯视、像素风），并作为 2D 精灵参与桌面。
**不做**：不做完整 3D 世界、不做 3D 碰撞、不做 3D 阴影贴图。

核心：**3D 只发生在 64×64 的离屏画布里；2D 决定它在哪里、挡住谁、被谁点。**

```
DroppedItem (Node2D)              # 2D 位置/速度/z_index
├── Sprite2D                      # texture = SubViewport.get_texture()
└── SubViewport 64×64
    └── Node3D (own_world_3d)
        ├── Camera3D (orthogonal, 俯角 ~25°)
        ├── WorldEnvironment (BG_CLEAR_COLOR)
        ├── DirectionalLight3D
        └── Pivot → MeshInstance3D
```

---

## 2. 为什么不用全屏 3D 层

Godot 中 2D `CanvasItem` 默认绘制在 3D 之上。若用全屏 `Node3D`，物品永远挡不住宠物，也无法被宠物踩在脚下。
把 3D 渲染成贴图再交给 `Sprite2D`，`z_index` 就能自由夹在宠物的各层之间——这是方案成立的根本原因。

## 3. SubViewport 配置

```gdscript
func _build_viewport() -> void:
    _vp = SubViewport.new()
    _vp.size = Vector2i(viewport_px, viewport_px)   # 64
    _vp.transparent_bg = true
    _vp.own_world_3d = true
    _vp.msaa_3d = Viewport.MSAA_DISABLED
    _vp.screen_space_aa = Viewport.SCREEN_SPACE_AA_DISABLED
    _vp.use_taa = false
    _vp.use_debanding = false
    _vp.render_target_update_mode = SubViewport.UPDATE_ALWAYS
    add_child(_vp)
```

| 设置 | 值 | 原因 |
|---|---|---|
| `transparent_bg` | true | 背景透明，才能贴桌面 |
| `own_world_3d` | true | 每个物品独立光照/相机，互不干扰 |
| `msaa_3d` | Disabled | 抗锯齿会糊像素 |
| `screen_space_aa` | Disabled | 同上 |
| `use_taa` | false | 运动拖影 |
| `use_debanding` | false | 抖动噪点 |
| 更新模式 | Always（旋转时） | 静止切 `UPDATE_ONCE` |

## 4. 相机

```gdscript
var cam := Camera3D.new()
cam.projection = Camera3D.PROJECTION_ORTHOGONAL
cam.size = float(viewport_px) / float(item_px)   # 1 世界单位 = item_px 屏幕像素
cam.near = 0.05
cam.far = 50.0
cam.position = Vector3(2.2, 1.7, 3.2)
cam.look_at_from_position(cam.position, Vector3(0.0, 0.08, 0.0), Vector3.UP)
cam.current = true
```

- 正交投影：没有近大远小，方块上下边平行。
- 俯角 20–30°：太高像卫星图，太低看不到顶面。
- `size = viewport_px / item_px`：保证 1 方块正好 `item_px` 屏幕像素。
- 视口边长取物品的 2 倍，给旋转对角线留余量（立方体对角线 ≈ 1.73×）。

| 参数 | 建议 |
|---|---|
| `viewport_px` | 64（物品 32px）或 48（物品 24px） |
| `item_px` | 24–40 |
| 俯角 | 22–28° |
| 相机距离 | 2–4（正交下只影响裁剪） |

## 5. 材质与模型

### 5.1 方块

```gdscript
func make_block_material(tex: Texture2D) -> StandardMaterial3D:
    var m := StandardMaterial3D.new()
    m.albedo_texture = tex
    m.texture_filter = BaseMaterial3D.TEXTURE_FILTER_NEAREST
    m.roughness = 1.0
    m.metallic = 0.0
    m.specular_mode = BaseMaterial3D.SPECULAR_DISABLED
    m.shading_mode = BaseMaterial3D.SHADING_MODE_PER_PIXEL
    return m
```

草方块/工作台这类**逐面不同**的贴图：用 6 面 `ArrayMesh` 写 UV，或 6 个 `QuadMesh` 拼盒；`BoxMesh` 只有 1 个 surface，做不到。

### 5.2 薄片物品

- 两个背靠背 `QuadMesh`（间隔 0.02）或厚度 0.06 的 `BoxMesh`。
- `cull_mode = CULL_DISABLED`。
- 镂空贴图：`transparency = TRANSPARENCY_ALPHA_SCISSOR`，`alpha_scissor_threshold = 0.5`，不要用 alpha blend。

### 5.3 光照

```gdscript
var env := Environment.new()
env.background_mode = Environment.BG_CLEAR_COLOR
env.ambient_light_source = Environment.AMBIENT_SOURCE_COLOR
env.ambient_light_color = Color.WHITE
env.ambient_light_energy = 0.55
env.tonemap_mode = Environment.TONE_MAPPER_LINEAR

var sun := DirectionalLight3D.new()
sun.rotation_degrees = Vector3(-48, -35, 0)
sun.light_energy = 0.75
sun.shadow_enabled = false          # 阴影用 2D 椭圆
```

- `BG_CLEAR_COLOR` 才能透明；`BG_SKY` 会填满背景。
- `TONE_MAPPER_LINEAR` 保住像素原色；Filmic 会让 16×16 调色板发灰。
- 不开 3D 阴影：透明窗下阴影贴图会在 alpha 边缘露馅。

## 6. 像素完美的五个开关

| 开关 | 值 |
|---|---|
| `msaa_3d` | Disabled |
| `screen_space_aa` | Disabled |
| `use_taa` | false |
| 材质 `texture_filter` | `TEXTURE_FILTER_NEAREST` |
| `tonemap_mode` | `TONE_MAPPER_LINEAR` |

补充：

- 纹理导入关闭 Mipmaps（Import → Mipmaps → Off）。
- `Sprite2D.scale` 只用整数倍。
- 根视口可开 `snap_2d_transforms_to_pixel`，减少半像素抖动。

## 7. 旋转与浮动

```gdscript
func _process(dt: float) -> void:
    _pivot.rotation.y = fposmod(_pivot.rotation.y + spin * dt, TAU)
    _pivot.position.y = base_y + sin(Time.get_ticks_msec() * 0.0032 + phase) * 0.04
```

| 状态 | spin | 浮动 |
|---|---|---|
| 地面静止 | 0.2 rad/s | 0 |
| 被拖拽 | 6.0 rad/s | 0.06 |
| 空中 | 2.5 rad/s | 0.02 |

落地后 `spin` 在 0.6s 内衰减到 0.2，避免"永远在转"。

## 8. 与 2D 的合成

### 8.1 位置

物品 `position` 是 2D 窗口坐标（中心）。3D 只影响贴图内部。
重力、撞墙、落地、拖拽全部用 2D：

```gdscript
if not held:
    velocity.y += 1400.0 * dt
    position += velocity * dt
    if position.y >= floor_y:
        position.y = floor_y
        velocity.y *= -0.35
        velocity.x *= 0.70
        if absf(velocity.y) < 40.0:
            on_floor = true
```

### 8.2 层级

宠物内部层在 `-5..30`。物品：

```gdscript
z_index = 35 if position.y > pet.position.y else -45
if held:
    z_index = 40
```

更平滑的做法：`z_index = clamp(int((position.y - pet.position.y) * 0.5), -45, 45)`。
注意宠物 `Visual` 的子层 z 会累加，调试时先把最终 z 打出来。

### 8.3 阴影

```gdscript
var h := maxf(floor_y - position.y, 0.0)
shadow.scale = Vector2(1.0, 0.35) * clampf(1.0 - h / 300.0, 0.4, 1.0)
shadow.modulate.a = 0.30 * clampf(1.0 - h / 400.0, 0.2, 1.0)
```

## 9. 交互

| 操作 | 行为 |
|---|---|---|
| 单击 | 抓取；拖动时旋转加速 |
| 松手 | 按鼠标速度抛出，落地弹两次 |
| 被宠物拿起 | 每帧对齐 `hand_r`，`z_index=40`，spin=0.8 |
| 双击 | 切换物品（调试）或触发闪光 |

命中用圆形：`distance(mouse, position) <= item_px * 0.6`。旋转中的轮廓变化不大，圆形手感更好。

被宠物拿起：

```gdscript
var hand := pose.joint_pos[def.joint_index[&"hand_r"]]
position = hand + Vector2(6, -4).rotated(pose.abs_angle[forearm_r])
z_index = 40
```

## 10. 穿透（多物体）

一旦有散落物品，"宠物凸包"会把宠物与物品之间的空白圈进去，导致点击被吞。此时改用：

> 每帧轮询 `DisplayServer.mouse_get_position()`，命中任一交互物时关闭 `WINDOW_FLAG_MOUSE_PASSTHROUGH`，否则打开。

细节见 [窗口与穿透](../02-平台/01-窗口与穿透.md) 第 6 章。拖拽期间锁定为可交互。

## 11. 性能

| 项 | 数值 |
|---|---|
| 单个 64×64 视口 | 1 个 RT、约 3 draw call |
| 10 个物品 | < 0.5ms |
| 30 个物品 | 开始明显 |
| 静止 | `UPDATE_ONCE` |

超过 30 个：

- 共享一个大 SubViewport（512×512）渲染所有 3D 物品，2D 从大图裁切；代价是物品无法与宠物交错遮挡。
- 或预渲染 32/64 帧转盘，压成图集。

## 12. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 黑底 | Environment 用了 Sky/Color | `BG_CLEAR_COLOR` + `transparent_bg` |
| 灰边 | 开了 MSAA/TAA/FXAA | 全关 |
| 糊 | Linear + mipmap | Nearest，导入关 mipmap |
| 发灰 | Filmic | Linear tonemap |
| 大小不对 | 相机 size 与 item_px 不匹配 | `size = viewport_px / item_px` |
| 薄片闪烁 | z-fighting | 间隔 0.02 或单面双面 |
| 镂空排序错 | alpha blend | alpha scissor |
| 物品间光照串扰 | 共用 World3D | `own_world_3d=true` |

## 13. 验收

- [ ] 1 个草方块在 100%/150% DPI 下像素锐利、无灰边
- [ ] 旋转一周无闪烁、无透视变化（正交）
- [ ] 落地弹跳两次后静止，spin 衰减
- [ ] 可拖拽、可抛出、可被宠物拿起
- [ ] 物品在宠物前/后层级正确
- [ ] 10 个物品同屏 < 0.5ms
- [ ] 静止物品不持续占用 GPU
