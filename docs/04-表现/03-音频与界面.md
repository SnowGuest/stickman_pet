## 1. 音频

### 1.1 总线

| 总线 | 用途 | 默认 |
|---|---|---|
| Master | 总音量 | 0.7（配置 `pet.volume`） |
| SFX | 动作/碰撞音效 | 1.0 |
| UI | 菜单点击 | 0.8 |

总线在 `default_bus_layout.tres` 中固定，运行时不动态建总线。

### 1.2 播放池

不要为每个音效建 `AudioStreamPlayer`；用固定池 + 轮转：

```gdscript
class_name AudioService extends Node

const POOL := 8

var _players: Array[AudioStreamPlayer] = []
var _next := 0
var _last_play := {}

func _ready() -> void:
    for i in POOL:
        var p := AudioStreamPlayer.new()
        p.bus = &"SFX"
        add_child(p)
        _players.append(p)

func play(stream: AudioStream, volume_db := 0.0, pitch := 1.0) -> void:
    var p := _players[_next]
    _next = (_next + 1) % POOL
    p.stream = stream
    p.volume_db = volume_db
    p.pitch_scale = pitch
    p.play()
```

规则：

- 同一音效 50ms 内只响一次（防止落地时多关节同时触发）。
- 音高随机 ±8%，避免机械重复。
- 同时最多 8 个，超出时抢占最旧的。
- 静音时仍推进逻辑，只是不 `play()`。

### 1.4 资源

- 已提供文件为 `.ogg`，44.1kHz、双声道、未做响度归一；
- 新增音效可用 `.ogg`（短音效）或 `.wav`（极短、需零延迟）；
- 单文件 < 100KB，总音效包 < 5MB；
- 发布前统一响度（约 -16 LUFS），避免忽大忽小。

## 2. 界面

桌宠没有主窗口 UI，只有**右键菜单**与**设置面板**（可选）。

### 2.1 右键菜单

```gdscript
func _open_menu(at: Vector2) -> void:
    _passthrough_lock = true
    _menu.position = Vector2i(at)
    _menu.popup()
    _menu.grab_focus()          # 让菜单能响应"点外面关闭"
```

菜单项：

| 项 | 行为 |
|---|---|
| 大小 − / + | 改 `window.scale`，步进 0.1，范围 0.8–2.0 |
| 静音 | 切换 `pet.muted` |
| 始终置顶 | 切换窗口 flag（持久化） |
| 重置位置 | 回到主屏地面 |
| 关于 | 版本、渲染器、日志路径 |
| 退出 | 保存并清理 |

规则：

- 菜单打开期间 `PassthroughService` 锁定为可交互，关闭后恢复。
- 菜单关闭（`popup_hide`）时检查是否有拖拽在进行，避免误恢复穿透。
- 菜单不依赖键盘：`PopupMenu` 的快捷键仅作提示。

### 2.2 设置面板（P2）

极简三项即可：缩放、音量、是否开机自启。
用 `AcceptDialog`/`Window` 实现，同样需要穿透锁定；不做多页、不做主题系统。

### 2.3 视觉

- 字号随 `dpi_scale` 缩放，最小 12px。
- 深色/浅色壁纸都要能读：菜单用系统主题（Godot 默认），不做透明菜单。
- 不使用动画菜单（桌宠的 UI 越轻越好）。

## 3. 无障碍

| 项 | 做法 |
|---|---|
| 减少动态 | 设置项关闭"抖动/倾斜/星星"，物理照常 |
| 对比度 | 角色始终白描边；菜单用不透明背景 |
| 音量 | 独立静音，不与系统音量耦合 |
| 误触 | 抓取阈值 6px，点击 180ms 判定 |

"减少动态"只影响表现层（Renderer/Fx），不影响物理与行为，避免改变手感。

## 4. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 音效叠成一团 | 无节流/池太大 | 50ms 节流 + 8 池 |
| 菜单点外面不关 | 未 `grab_focus` | 打开时取焦点 |
| 菜单打开时点到桌面 | 穿透未锁 | `_passthrough_lock` |
| 静音后仍有声 | 只改了 Master 未改播放 | 播放前判断 + 总线静音 |
| 音频设备缺失 | 无输出 | 捕获错误，静默降级 |

## 5. 验收

- [ ] 落地/抓取/抛出/被戳各有独立音效，不重叠爆音
- [ ] 同一事件连发 10 次，响度稳定、无破音
- [ ] 静音后重启仍静音
- [ ] 菜单在 100%–200% DPI 下不模糊、不超出屏幕
- [ ] 菜单打开时点击外部关闭且穿透立即恢复
- [ ] 减少动态开启后不再倾斜/抖动，物理不受影响
