# 架构与运行时

> 上级：[文档中心](../README.md) · 同级：[产品与边界](01-产品与边界.md) · 工程配置：[Godot 工程基线](03-Godot工程基线.md)
> 本文是**唯一**的系统全景图：分层、模块、数据所有权、一帧的执行顺序、ADR 索引。
> 各模块的实现细节不在这里展开，只给接口与约束。

---

## 1. 分层

```
┌──────────────────────────────────────────────────────────────┐
│ L4 表现层   StickRenderer · Shadow · Fx · ItemSprite · UI     │
├──────────────────────────────────────────────────────────────┤
│ L3 行为层   PetBrain(FSM) · Expression · IkTarget · ItemLogic  │
├──────────────────────────────────────────────────────────────┤
│ L2 仿真层   PoseSampler → PoseBlender → RagdollSolver → IK    │
├──────────────────────────────────────────────────────────────┤
│ L1 交互层   InputRouter · Gesture · GrabController · HitRouter│
├──────────────────────────────────────────────────────────────┤
│ L0 平台层   DesktopShell · ScreenProbe · Passthrough · Store  │
└──────────────────────────────────────────────────────────────┘
```

依赖规则（评审必查）：

1. 只能向下依赖。
2. L2 不出现 `DisplayServer`、`Input`、`get_window()`。
3. L0 不出现 `BoneDef`、`Pose`、`Solver`。
4. L3 只输出"意图"（剪辑名、权重、IK 目标、表情），不写关节坐标。
5. 跨层通信走信号或注入的服务对象，不用 `get_node("../../..")`。

## 2. 模块与所有权

| 模块 | 层 | 唯一职责 | 写什么 | 读什么 |
|---|---|---|---|---|
| `DesktopShell` | L0 | 窗口 flags、屏幕矩形、DPI | 窗口状态 | 系统 API |
| `ScreenProbe` | L0 | 200ms 轮询屏幕/任务栏变化 | `usable`、`scale` | 系统 API |
| `PassthroughService` | L0 | 穿透策略与提交 | 系统区域/flag | 命中结果 |
| `PetStore` | L0 | 配置读写与迁移 | `user://pet.cfg` | — |
| `InputRouter` | L1 | 全局鼠标位置、窗口事件、手势状态机 | `InputFrame` | 窗口事件 |
| `HitRouter` | L1 | 光标下的优先级：UI > 物品 > 宠物 > 空白 | `HitResult` | 渲染坐标 |
| `GrabController` | L1 | 抓取命中、offset、平滑、投掷速度 | `GrabState` | `RigPose` |
| `PetBrain` | L3 | 状态机、剪辑选择、张力、表情 | `BrainOutput` | 物理/输入 |
| `AnimLibrary` | L2 | 剪辑加载、校验、绝对→相对 | `AnimClip` | JSON |
| `PoseSampler` | L2 | 时间→相对角 + 事件 | `PoseFrame` | `AnimClip` |
| `PoseBlender` | L2 | 交叉淡化、加性层、物理权重 | `pose.rel` | `PoseFrame` |
| `RagdollSolver` | L2 | PBD 求解 | `pos/prev` | `pose.rel`、`GrabState` |
| `IkLayer` | L2 | 双骨 IK 视觉修正 | `pose` 副本 | `BrainOutput` |
| `RigState` | L2 | FK、关节世界坐标 | `joint_pos` | `pose` |
| `StickRenderer` | L4 | 线条/头/眼/分层/倾斜 | 节点变换 | `RigPose` |
| `ShadowRenderer` | L4 | 接触阴影 | 节点变换 | `RigPose` |
| `ItemLayer` | L4 | 物品 2D 位置、3D 自转、层级 | 物品状态 | `ItemModel` |
| `FxLayer` | L4 | 汗滴、星星、尘土 | 粒子 | 事件 |
| `AudioService` | L4 | 音效池、节流、音量 | 播放状态 | 事件 |
| `SettingsMenu` | L4 | 右键菜单、缩放/静音/退出 | 配置 | `PetStore` |

**所有权铁律**：

- `pose.rel` 只由 `PoseBlender` 写。
- `solver.pos/prev` 只由 `RagdollSolver` 写。
- `joint_pos` 只由 `RigState.resolve()` 写。
- 渲染层只读，不修正姿态（IK 也必须在 `resolve()` 之前）。

## 3. 运行时实体

```
App (main.tscn)
├── DesktopShell
├── World
│   ├── Pet
│   │   ├── Brain (L3)
│   │   ├── Solver (L2)
│   │   ├── Rig (L2, 纯数据)
│   │   └── Visual (L4)
│   ├── Items (L4)
│   └── Debug
└── UI (CanvasLayer)
```

- **Pet**：一个实例，持有 RigDefinition、RigPose、Solver、Brain。
- **Item**：N 个实例，每个持有 2D 状态 + 一个 SubViewport 3D 舞台。
- **World**：共享 2D 坐标与地面 `floor_y`。

## 4. 启动序列

| # | 步骤 | 失败处理 |
|---|---|---|
| 1 | 单实例锁（TCP 42871） | 已有实例 → 退出 |
| 2 | 加载配置（含 schema 迁移） | 损坏 → 备份并重建默认 |
| 3 | 创建透明窗口 + flags | 透明失败 → 白底降级模式 |
| 4 | 选屏、算可用区、设窗口尺寸/位置 | 失败 → 主屏 (0,0) |
| 5 | 加载 RigDefinition 并 `compile()` | 断言失败 → 报错退出（开发期） |
| 6 | 加载动画库（校验所有轨道骨骼名） | 缺轨道 → 用静止角 + 警告 |
| 7 | 初始化 Solver、Renderer、Brain | — |
| 8 | 首次 `RigState.resolve()`，把宠物放地面 | — |
| 9 | 启动穿透策略、注册信号、显示窗口 | — |
| 10 | 打点：`boot_ms` | — |

启动期间窗口应保持不可见或用黑色遮罩，避免闪一下未初始化的画面。

## 5. 帧管线

```
每帧（可变 dt，上限 1/30）
 1. ScreenProbe.refresh()            200ms 节流
 2. InputRouter.poll(dt)             全局鼠标 + 事件 + 手势
 3. HitRouter.update()               光标命中：UI/物品/宠物/空白
 4. PetBrain.update(dt)              选剪辑、w_sim、tone、IK、表情
 5. PoseSampler.sample()             目标相对角 + 事件
 6. PoseBlender.resolve()            crossfade + additive
 7. Solver.advance(dt)               固定步长 1/120，8 迭代
 8. IkLayer.apply()                  只改渲染副本
 9. RigState.resolve(pose)           绝对角 → 关节坐标
10. StickRenderer.sync(pose)
11. ItemLayer.sync(pose)             物品 2D 位置与 z
12. Shadow/Fx.sync()
13. HitRouter.rebuild()              更新命中缓存（供下一帧）
14. Passthrough.tick()               30Hz 或光标轮询
15. DebugOverlay.tick()
```

顺序的硬约束：

- **6 必须在 7 之前**：物理需要本帧动画目标角。
- **7 必须在 9 之前**：FK 读的是求解后的姿态。
- **9 必须在 10/11 之前**：渲染与命中都读 `joint_pos`。
- **13 必须在 14 之前**：穿透依赖最新命中形状。

## 6. 固定步长与插值

```gdscript
const H := 1.0 / 120.0
var _acc := 0.0
var _prev_render: PackedVector2Array
var _alpha := 0.0

func _physics_process(dt: float) -> void:
    _acc += minf(dt, 1.0 / 30.0)
    var guard := 0
    while _acc >= H and guard < 4:
        _acc -= H
        _prev_render = solver.pos.duplicate()
        solver.step(H)
        guard += 1
    _alpha = _acc / H
```

渲染：

```gdscript
func render_pos(i: int) -> Vector2:
    return _prev_render[i].lerp(solver.pos[i], _alpha)
```

规则：

- `dt` 上限 1/30，防止断点/卡顿后追帧把角色弹飞。
- `guard` 最多 4 步，宁可慢放也不爆炸。
- 插值只用于渲染与命中，物理永远用真实 `pos`。

## 7. ADR 索引

| 编号 | 决策 | 替代方案 | 影响 |
|---|---|---|---|
| ADR-01 | 自研 PBD 物理 | `RigidBody2D` 布娃娃 / `PhysicalBone2D` | 无原生角度限位、需固定步长 |
| ADR-02 | `RigPose` 为唯一姿态真源 | `Skeleton2D` 驱动 | 渲染/物理/命中天然一致 |
| ADR-03 | 程序化胶囊线条 | 贴图骨骼 / Spine | 零美术、任意缩放清晰 |
| ADR-04 | 伪 2.5D（分层+视差+阴影） | 真 3D 场景 | 保持手绘感、成本低 |
| ADR-05 | 全屏透明置顶窗 | 小窗跟随 / 多窗口 | 坐标统一，但会出现在 Alt-Tab |
| ADR-06 | JSON 剪辑 + 自研采样 | `AnimationPlayer` | 逐骨混合与热调方便 |
| ADR-07 | 3D 物品用 SubViewport 贴图 | 全屏 3D 层 | 2D/3D 层级可控，物品数受渲染目标限制 |
| ADR-08 | 多岛命中用光标轮询 + 整窗穿透开关 | 凸包区域 / 多窗口 | 支持任意数量交互物，代价 1 帧延迟 |
| ADR-09 | 配置 `user://pet.cfg` + schema 版本 | JSON 单文件 / 注册表 | 可迁移、可回滚 |
| ADR-10 | 单实例用 TCP 端口锁 | 文件锁 / 互斥体 | 跨平台、无残留 |

每条 ADR 的背景与代价见对应领域文档；被推翻时保留原文并标注 `Superseded by`。

## 8. 失败域与降级

| 失败 | 检测 | 降级 |
|---|---|---|
| 透明窗口黑底 | 启动后采样窗口像素/日志 | 切 Compatibility；仍失败 → 白底小窗 |
| `window_set_mouse_passthrough` 不可用 | 调用无效果/平台判断 | 整窗穿透开关 + 热键 |
| 3D 视口初始化失败 | `SubViewport` 无纹理 | 物品退化为 2D 图标序列帧 |
| 音效设备缺失 | `AudioServer` 输出为空 | 静音，不报错 |
| 配置文件损坏 | 解析异常 | 备份 `.bak`，重建默认 |
| 物理出现 NaN | `is_finite` 检查（调试期） | 重置姿态到地面 Idle，写日志 |
| 帧时间 > 50ms 连续 3 帧 | 自建计时 | 降级：关阴影/特效，降物理迭代 |

降级必须**可恢复**：条件消失后逐级恢复，不重启进程。

## 9. 扩展点

| 扩展 | 接入方式 | 不允许的做法 |
|---|---|---|
| 新手势 | `InputRouter` 注册识别器 | 在 Pet 里读 `Input` |
| 新物品类型 | `ItemModel` 资源 + ItemLayer | 改 Solver |
| 新行为 | `PetState` 子类 + 注册 | 在 Renderer 里改状态 |
| 新渲染层 | 加 `Node2D` 层并声明 depth | 改 `RigState` |
| 新配置项 | Schema 表 + 迁移 | 直接读 `OS.get_environment` |
| 新平台 | 实现 `DesktopShell` 接口 | 在业务代码里判断 OS |
