# 内容设计（GDD-lite）

> 上级：[文档中心](../README.md) · 领域：设计
> 这不是完整的游戏设计文档，而是"内容清单 + 交互规则 + 手感目标"，用于排期与验收。
> 技术实现见 [状态机](../05-行为/01-状态机与交互.md) 与 [物理](../03-仿真/02-物理与抓取.md)。

---

## 1. 核心循环

```
观察（待机/看向） → 好奇（靠近/看光标） → 互动（戳/抓/拖/扔/推）
        ↑                                        │
        └──────── 恢复（爬起/眩晕/睡觉） ◄────────┘
```

没有输赢、没有关卡、没有数值成长。乐趣来自**物理反馈的不可预测性**和**角色的小情绪**。

---

## 2. 交互目录

| 输入 | 条件 | 角色反应 | 反馈 |
|---|---|---|---|
| 悬停 | 光标靠近头 | 眼睛跟随、歪头 | 无 |
| 短按 | 身体任意处 <180ms | 弹跳 + 瞪眼 | `poke` |
| 长按抓取 | 角色上按住 280ms 不动 | 进入抓取 | `grab` |
| 抓取后拖拽·腰 | 抓 spine 下段/pelvis | 下半身下垂摆动，躯干保持 | — |
| 抓取后拖拽·头 | 抓 head/neck | 全身倒挂，腿晃 | 眼睛睁大 |
| 抓取后拖拽·手 | 抓 forearm/hand | 手臂拉长，身体被带偏 | — |
| 抓取后拖拽·脚 | 抓 shin/foot | 倒提，手乱抓 | 挣扎动画 |
| 甩动 | 0.5s 内 10 次反向 | 眩晕 | `dizzy` |
| 抛出 | 松手速度 > 900px/s | 飞出、撞边、翻滚 | `whoosh` |
| 落地 | 冲击 > 阈值 | 扬尘、弹跳 | `land` |
| 爬起 | 静止 0.3s | 摇晃站起 | — |
| 按住空白 | 桌面按下左键 | 光标变实体，可推角色 | `impact` |
| 快速撞 | 实体光标速度 > 900px/s | 被撞、后仰/眩晕 | `impact` |
| 右键 | 任意 | 菜单 | UI 音 |

## 3. 内容清单

### 3.1 动画（9）

| 名称 | 循环 | 用途 | 关键姿态 |
|---|---|---|---|
| `idle` | 是 | 待机 | 呼吸、眨眼、重心左右 |
| `look` | 是 | 看光标 | 头转、身体微倾 |
| `walk` | 是 | 走近 | 腿交替、身体上下 |
| `sit` | 是 | 坐 | 腿悬空、手撑地 |
| `sleep` | 是 | 睡 | 蜷缩、Zzz |
| `poke` | 否 | 被戳 | 弹跳、瞪眼 |
| `startle` | 否 | 受惊 | 后仰、汗滴 |
| `recover` | 否 | 爬起 | 撑地、摇晃、站直 |
| `drag_idle` | 是 | 被抓参考 | 四肢放松、头低 |

### 3.2 表情（6）

`neutral`、`curious`、`startled`、`dizzy`、`sleepy`、`happy`。
实现为头部绘制参数（眼睛大小/形状/眉毛/汗滴），不做独立贴图。

### 3.3 音效（约 21）

`step_1..3`、`land_soft/hard`、`grab`、`whoosh`、`impact`、`poke_1..2`、`dizzy`、`snore`、`wake`、`menu_click/open/close`、`error`、`ai_connect/disconnect/error`。
全部原创或 CC0；单文件 < 100KB。完整清单与规格见 [素材清单](../04-表现/04-素材清单.md)。

### 3.4 文本（约 20 条）

菜单：放大/缩小/静音/置顶/重置/关于/退出。
关于：版本、渲染器、日志路径。
错误：配置损坏、透明不可用、单实例。

### 3.5 内置小剧场（10 条）

无 AI、无操作时的自主行为，详见 [内置行为清单](../05-行为/03-内置行为清单.md)：

| ID | 行为 | 一句话 |
|---|---|---|
| B01 | 探头打招呼 | 从屏幕边缘探出，挥手，再缩回 |
| B02 | 底部散步 | 沿任务栏上方的地面来回走 |
| B03 | 追光标 | 冲刺扑向快速移动的光标，扑空后装没事 |
| B04 | 木头人 | 被盯着就定住，只有眼睛跟着你 |
| B05 | 边缘躲猫猫 | 躲到屏幕外，探头，靠近就缩回去 |
| B06 | 任务栏晃腿 | 坐在屏幕底边，腿悬空晃 |
| B07 | 打瞌睡点头 | 站着打盹，惊醒后假装没睡 |
| B08 | 影子拳击 | 对空气打拳踢腿，最后失去平衡 |
| B09 | 转圈圈 | 原地转圈，转晕后摇晃扶头 |

这些活动需要补充剪辑：`peek`、`wave`、`dash`、`stretch`、`punch`、`kick`、`spin`、`play_dead`；不改变 P2 的 9 个基础剪辑结构。

## 4. 手感目标

| 项 | 目标 | 来源 |
|---|---|---|
| 抓取响应 | ≤ 1 帧 | 平台/输入 |
| 抓腰进入下垂 | ≤ 0.2s | 物理 |
| 腿部摆动周期 | 0.9–1.1s | 物理 |
| 摆动衰减 | 3 周期 < 5° | 物理 |
| 抛出最大速度 | 2400px/s | 物理 |
| 松手到站起 | ≤ 2.5s | 行为 |
| 落地弹跳 | 2 次内停 | 物理 |
| 待机动作重复 | 10 分钟不显机械 | 行为 |

## 5. 首次运行与日常

**首次运行**

1. 出现在主屏底部中央，2s 内从"站立"淡入。
2. 3s 后做一个"招手/看向光标"的动作。
3. 不弹教程、不弹权限请求。
4. 右键可发现菜单（菜单里第一项是"放大"）。

**日常**

- 启动即待机，不抢焦点。
- 长时间无操作 → 坐 → 睡。
- 有光标靠近 → 看；被戳 → 反应。
- 退出通过右键菜单；不强制挽留。

## 6. 本地化

| 项 | 值 |
|---|---|
| 默认语言 | 简体中文 |
| 第二语言 | English |
| 实现 | `tr()` + `translations/*.translation` |
| 键名 | `MENU_SCALE_UP`、`ABOUT_VERSION`、`ERR_CONFIG_CORRUPT` |
| 字体 | 已内置 Noto Sans SC 可变字体（OFL），`assets/themes/pet_theme.tres` 全局生效 |

注意：Godot 默认主题字体不含完整 CJK，中文 UI 会显示方框。项目已内置 Noto Sans SC（`assets/fonts/NotoSansSC-Variable.ttf`，完整 17MB，非子集），并用 `tests/font_test.tscn` 验证菜单/错误提示无方框；新增文案直接复用该字体即可。

## 7. 内容生产管线

| 内容 | 工具 | 产物 | 校验 |
|---|---|---|---|
| 动画 | 手写/脚本生成 JSON | `assets/anims/*.json` | 骨骼名、时间升序、循环闭合 |
| 图标 | 矢量/ICO | `assets/icons/*` | 多尺寸、透明背景 |
| 音效 | Audacity/Reaper | `assets/sfx/*.ogg` | 响度、时长、单声道 |
| 文本 | 表格/JSON | `assets/i18n/*.csv` | 键完整、无硬编码 |

规则：内容文件命名 `snake_case`；新增内容只加资源 + 配置，不改核心代码（G3 目标）。

## 9. 非目标

- 不做剧情、任务、成就系统。
- 不做数值/养成/饥饿惩罚（energy 只影响睡觉，不惩罚）。
