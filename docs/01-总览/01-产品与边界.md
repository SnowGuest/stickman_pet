## 1. 一句话

**一段住在 Windows 桌面上的、可以随时伸手打断的无声火柴人短片。**

表现得像 Alan Becker 的 *Animator vs. Animation*：透明置顶、会待机、会看你、可以被鼠标抓住任何部位拖拽；被抓时身体按"重力 + 肌肉张力 + 关节限位"自然下垂与摆动，松手会被扔出去、落地、犯晕、自己爬起来；桌面上还可以有 Minecraft 风格的 3D 旋转掉落物，宠物能捡起来玩。没有对白，但有幽默和情绪。

> 技术只是手段。最终验收不是"物理正确"，而是"像一段能互动的小短片"——详见 [最终产品定义](05-最终产品定义.md)。

## 2. 六条体验支柱

| # | 支柱 | 判断标准 |
|---|---|---|
| P1 | **活着** | 静止 10 分钟不显机械；有呼吸、眨眼、重心转移、随机小动作 |
| P2 | **可抓** | 抓任意部位都有符合直觉的反应；抓腰不瘫软、抓头会倒挂 |
| P3 | **有物理** | 摆动有惯性、落地有回弹、被扔会翻滚；但不抖、不穿模、不爆炸 |
| P4 | **贴桌面** | 真透明、真置顶、不抢焦点、空白处点击穿透 |
| P5 | **像素干净** | 线条锐利、3D 物品不糊、深色壁纸下仍可见 |
| P6 | **像短片** | 15 秒无声录屏能让陌生人看出情绪与事件；反应有停顿/夸张/变化 |

> 排期说明：P6 为**后置目标**（v1.1）；v1.0 先保证物理、桌面融合与可选 AI 控制。表演层不删除，只是不阻塞当前版本。

## 4. 关键场景（验收剧本）

| 场景 | 步骤 | 期望 |
|---|---|---|
| S1 启动 | 双击 exe | 2s 内出现在主屏地面，无黑框、无控制台 |
| S2 待机 | 放置 10 分钟 | 至少 4 条不同小剧场；呼吸/眨眼/看向光标；CPU 均值 < 2% |
| S3 被戳 | 短按身体 <180ms | 弹跳 + 瞪眼 + 汗滴，0.8s 恢复 |
| S4 抓腰 | 在腰部按住 280ms 后上提 200px | 双腿下垂摆动，躯干保持近竖直，0.2s 内进入姿态 |
| S5 抓头 | 按住头提起 | 全身倒挂，腿/臂自然晃，颈不反折 |
| S6 抛出 | 快速甩动后松手 | 按速度飞出，撞边反弹，落地翻滚，2.5s 内站起 |
| S7 3D 物品 | 右键"丢一个方块" | 方块绕 Y 轴旋转、有阴影、可拖拽、可被宠物拿起 |
| S8 穿透 | 在角色 100px 外点击桌面图标 | 图标正常选中 |
| S9 多屏 | 拖到副屏 | 窗口重建，站立线在副屏任务栏上方 |
| S10 按住推 | 桌面空白按住左键，移动到角色身上 | 光标变实体，角色被推开/踉跄；松手不再受力 |
| S11 快速撞 | 按住左键快速掠过角色 | 角色被撞、后仰/眩晕，有冲击音效 |
| S12 退出 | 右键退出 | 清理窗口 flags 与自启项（若勾选），无残留进程 |
| S13 托盘 | 右键通知区图标 | 可显示/隐藏、缩放、静音、置顶、开关 AI、自启、退出 |
| S14 托盘退出 | 菜单退出 | 保存配置、停 AI、删托盘图标、无残留 |

## 5. 非目标（明确不做）

- 多角色同屏、联机、账号体系。
- 语音唤醒、摄像头、麦克风。
- 读取或修改其他窗口内容（不截屏、不注入、不 Hook）。
- 真 3D 场景（掉落物只是"离屏 3D 贴图"，不是 3D 世界）。
- 移动端、macOS 商店分发（代码可移植，但不做适配验收）。
- 创意工坊/在线更新（v1 只做手动更新）。

## 6. 成功指标

| 维度 | 目标 | 测量方式 |
|---|---|---|
| 帧率 | 60fps（前台/后台一致） | `Engine.get_frames_per_second()` |
| 逻辑耗时 | < 4ms/帧 | `Performance.TIME_PROCESS` + 自建计时 |
| 常驻内存 | < 120MB | 任务管理器 8h 采样 |
| 冷启动 | < 2s | 打点日志 |
| 抓取响应 | < 1 帧 | 录像逐帧 |
| 穿透正确率 | 角色外 100% | 手动 50 次点击 |
| 稳定性 | 8h 无崩溃、无 NaN | 挂机 + 日志 |
| 安装包 | < 60MB | 导出产物 |

## 8. 角色与术语边界

- **Pet**：一只火柴人，拥有 Rig / Solver / Brain / Renderer。
- **Item**：桌面上可交互的 3D 贴图物品，有 2D 位置与 3D 自转。
- **Shell**：窗口、屏幕、穿透、单实例等平台能力。
- **World**：2D 坐标空间，单位是窗口像素；所有物理/位置都在这里。
- **Scene3D**：仅存在于 `SubViewport` 内的 3D 空间，只服务于物品外观。

> 边界：Pet 不感知窗口，Shell 不感知骨骼；两者只通过 World 坐标与信号交互。

## 9. 假设与风险前置

假设：

1. 目标机器为 Windows 10 1903+，支持 per-pixel transparency。
2. 用户接受"全屏透明窗口"这一实现方式（会出现在 Alt-Tab 列表，可在设置中关闭）。
3. 不做反作弊/安全敏感场景，置顶窗口可被用户手动关闭。

前置风险（详见 [工程文档](../06-工程/02-规范测试与发布.md)）：

- 部分显卡驱动/录屏软件下透明失效 → 启动自检 + 白底降级。
- 全屏独占游戏被置顶窗干扰 → v1 文档声明，v2 做检测隐藏。
- 杀软对"置顶透明窗 + 全局鼠标轮询"敏感 → 代码签名 + 说明文档。
