# 内置行为与小剧场清单

> 上级：[状态机与交互](01-状态机与交互.md) · 相关：[光标交互](02-光标交互规范.md)
> 目标：不接 AI、也没有用户操作时，桌宠仍然像有生命一样自己找事做。
> 范围：10 条内置小剧场，挂在 `AUTONOMOUS` 模式；AI 接入或用户操作时暂停。

---

## 1. 设计原则

- 不是 10 个新 FSM 状态，而是 `Idle` 之上的**活动（Activity）**；每条活动由 1–3 个已有状态/剪辑组合而成。
- 每条活动有触发条件、权重、冷却、最短/最长时长、打断条件。
- 优先使用已有系统：Walk/Sit/Sleep、头部看向、IK、3D 物品、物理。
- 不读取其他窗口内容，不移动系统光标，不做破坏性操作。
- 失败要能优雅退出：卡住/出界/超时都回到 `Idle`。

---

## 2. 与状态机的关系

```
PetBrain
 ├─ MANUAL / REMOTE_AI：活动暂停
 └─ AUTONOMOUS
      └─ IdleActivityScheduler
            ├─ 选活动（权重 + 条件 + 冷却）
            ├─ 执行：Walk/Sit/Look/Sleep/物品/IK
            └─ 结束/打断 → Idle
```

- 活动可以临时切到 `Walk`/`Sit`，但不新增长期状态。
- 用户点击/拖拽、AI 命令、屏幕变化、物品消失都会打断活动。
- 打断后回到 `Idle`，并给该活动一个冷却。

## 3. 十条内置行为

### B01 探头打招呼

| 项 | 内容 |
|---|---|
| 触发 | 空闲 >90s；距上次 ≥5min；靠近屏幕左/右/下边缘 |
| 流程 | 走到边缘 → 滑出 30% → 停 0.4s → 挥手 1.2s → 歪头 → 缩回 |
| 依赖 | 边缘越界、`wave` 剪辑、手部 IK |
| 打断 | 光标靠近（<120px）→ 立刻缩回；点击 → 受惊 |
| 验收 | 3s 内完成探头+挥手+缩回；不卡在屏幕外 |

### B02 底部散步

| 项 | 内容 |
|---|---|
| 触发 | boredom >0.4；energy >0.3；冷却 60s |
| 流程 | 沿屏幕底部走 200–500px → 随机转向 → 停 1s 看光标 → 继续 |
| 依赖 | `walk` 剪辑、根位移、地面碰撞 |
| 打断 | 用户操作/AI 命令/到达屏幕边缘 |
| 验收 | 不越界、不抖动、最多 8s |

### B03 追光标

| 项 | 内容 |
|---|---|
| 触发 | 光标在 400px 内且速度 >400px/s；curiosity >0.6；冷却 90s |
| 流程 | 下蹲预备 → 冲刺 → 扑空 → 滑停 → 左右看 → 挠头 |
| 依赖 | `dash` 剪辑、看向、急停 |
| 打断 | 光标停止 1s 后自然结束；点击立即中断 |
| 验收 | 0.3s 内起跑；3s 内结束；不真的抓住光标 |

### B04 木头人

| 项 | 内容 |
|---|---|
| 触发 | 光标停在角色身上 >1.5s；无按键 |
| 流程 | 突然定住（当前姿势）→ 只有眼睛跟随 → 光标离开 1s 后放松呼气 |
| 依赖 | 姿势保持、眼球跟随 |
| 打断 | 点击/拖拽/光标快速离开 |
| 验收 | 身体不漂移；眼睛跟随；不误触发抓取 |

### B05 边缘躲猫猫

| 项 | 内容 |
|---|---|
| 触发 | 受惊后/随机；靠近边缘；冷却 3min |
| 流程 | 躲到屏幕外 70% → 探头 → 光标靠近就缩回 → 重复 2–3 次 → 回到地面 |
| 依赖 | 边缘越界、`peek` 剪辑、眼睛 |
| 打断 | 点击 → 跳出来；拖拽 → 直接进入 Drag |
| 验收 | 光标接近 0.2s 内缩回；不丢失角色 |

### B06 任务栏晃腿

| 项 | 内容 |
|---|---|
| 触发 | energy <0.6；光标距离 >300px；冷却 3min |
| 流程 | 走到屏幕底边坐下 → 双腿悬空晃 → 后仰 → 看光标 → 起身 |
| 依赖 | `sit` 剪辑、脚部限位、地面 |
| 打断 | 点击/拖拽/物品靠近 |
| 验收 | 脚不穿任务栏；腿有摆动；5–10s 结束 |

### B07 打瞌睡点头

| 项 | 内容 |
|---|---|
| 触发 | energy <0.35；光标空闲 >60s |
| 流程 | 站着/坐着 → 头一点一点 → 身体晃 → 突然惊醒 → 左右看 → 假装没事 |
| 依赖 | `sleep`/`idle`、头颈物理、表情 |
| 打断 | 点击/拖拽/大声（未来音效） |
| 验收 | 不进入完整 Sleep；惊醒有 0.1s 停顿 |

### B08 影子拳击

| 项 | 内容 |
|---|---|
| 触发 | energy >0.7；boredom >0.5；冷却 2min |
| 流程 | 弹跳 → 左右直拳 → 回旋踢 → 失去平衡 → 摇晃 → 站直 |
| 依赖 | `punch`/`kick` 剪辑、squash & stretch、可选的冲击线 |
| 打断 | 用户操作/AI 命令 |
| 验收 | 不穿模；3–5s；结束回到 Idle |

### B09 搬方块堆叠

| 项 | 内容 |
|---|---|
| 触发 | 场景中有 3D 物品，距离 <200px；curiosity >0.5；冷却 4min |
| 流程 | 走到物品 → 拿起 → 搬到空地 → 放下 → 再搬一块 → 堆 2–3 层 → 后退欣赏 → 碰倒 → 抱头 |
| 依赖 | 物品抓取/携带、IK、物品物理、层级 |
| 打断 | 物品被抢/消失；用户拖拽；超时 12s |
| 验收 | 物品跟手、堆叠稳定、倒塌有反应 |

### B10 装死偷看

| 项 | 内容 |
|---|---|
| 触发 | 被 HIT/Startle 后 20% 概率；或无聊时；冷却 5min |
| 流程 | 倒地不动 → 闭眼 → 睁开一只眼 → 偷看 → 光标离开后爬起 → 拍拍灰 |
| 依赖 | 物理倒地、`play_dead` 剪辑、眼睛参数 |
| 打断 | 被戳 → 立刻跳起；被拖拽 → Drag |
| 验收 | 躺 2–4s；偷看可见；爬起不穿模 |

## 4. 调度与权重

```gdscript
class IdleActivity:
    var id: StringName
    var weight: float
    var cooldown: float
    var min_time: float
    var max_time: float
    func can_start(ctx) -> bool
    func start(ctx) -> void
    func update(ctx, dt) -> bool   # false = 结束
    func stop(ctx) -> void
```

选择逻辑：

1. 过滤 `can_start`（条件、冷却、当前状态、屏幕边缘可达）。
2. 按 `weight * need_bias` 加权随机。
3. 同一活动连续触发不超过 2 次；最近 3 条不重复。
4. 每 0.5s 决策一次，不在每帧 roll。
5. 选中后锁定 1 个最短时长，避免"刚蹲下就起身"。

`need_bias` 示例：

| 需求 | 加权活动 |
|---|---|
| energy 低 | B06 晃腿、B07 打瞌睡、B10 装死 |
| energy 高 | B03 追光标、B08 影子拳击 |
| boredom 高 | B02 散步、B03 追光标、B05 躲猫猫 |
| curiosity 高 | B03 追光标、B09 搬方块 |
| 光标靠近 | B04 木头人、B01 探头 |

## 5. 打断规则

| 事件 | 处理 |
|---|---|
| 用户按下/拖拽 | 立即中断，进入 PENDING/SOLID/GRAB |
| AI `set_mode: remote` | 立即中断，进入 AI 控制 |
| 屏幕/DPI 变化 | 中断，回到地面 Idle |
| 物品消失 | B09 中断 |
| 活动超时 | 强制 `stop()`，回 Idle |
| 角色出界/NaN | 重置到地面，写日志 |

打断延迟 ≤1 帧；`stop()` 必须幂等。

## 6. 需要补充的资源

| 资源 | 用途 | 优先级 |
|---|---|---|
| `peek` / `wave` | B01/B05 | P2 |
| `dash` | B03 | P2 |
| `stretch` / `yawn` | B07 惊醒 | P4 |
| `punch` / `kick` | B08 | P4 |
| `carry` / `stack` | B09 | P4 |
| `play_dead` | B10 | P4 |
| 眼球参数 | B04/B10 | P4（表演层后置，但眼睛是基础） |
| 边缘越界 | B01/B05 | P3/P4 |

> 表演层（FaceRig/Acting）后置不影响这 10 条的结构；先用基础眼睛与姿态实现，后续替换为更精细的表演。

---

## 7. 验收

- [ ] 10 条活动都能在 `AUTONOMOUS` 下触发
- [ ] 连续待机 10 分钟，至少出现 4 条不同活动，无卡死
- [ ] 同一活动不连续出现 >2 次
- [ ] 每条活动都能被用户/AI 在 1 帧内打断
- [ ] 出界/超时/物品消失都能回 Idle
- [ ] 活动期间不影响 60fps 与休眠策略
- [ ] AI 接入后活动暂停，断开后恢复

---

## 8. 与 AI 的关系

- 这 10 条是 `AUTONOMOUS` 的内置行为，不依赖 Go 客户端。
- AI 接入后进入 `REMOTE_AI`，活动暂停；AI 可以下发 `set_mode: autonomous` 让它们恢复。
- AI 也可以把某条活动当作"技能"调用（未来扩展）：`action: "activity", params: {id: "B01"}`。
- 用户输入始终最高优先级，可随时打断活动。
