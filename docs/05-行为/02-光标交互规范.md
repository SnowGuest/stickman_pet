# 光标交互规范

> 上级：[状态机与交互](01-状态机与交互.md) · 相关：[窗口与穿透](../02-平台/01-窗口与穿透.md)、[物理与抓取](../03-仿真/02-物理与抓取.md)
> 规则：**默认鼠标是"幽灵"；只有按住左键时，光标才变成实体；在角色身上长按则改为抓取。**

---

## 1. 一句话

鼠标不按键时不影响角色；按住左键后光标变成一个可推、可撞的实体圆；如果按住的位置在角色身上并保持不动，则进入抓取。

---

## 2. 五种模式

| 模式 | 触发 | 光标物理 | 角色反应 |
|---|---|---|---|
| `PASSIVE` | 没有按左键 | 无碰撞，纯幽灵 | 可以看光标，但不会被推 |
| `PENDING` | 在角色身上按下，未到长按阈值 | 无碰撞 | 等待：短按=戳，移动=实体，保持=抓取 |
| `SOLID` | 在桌面按下；或在角色上按下后移动超过阈值 | 10px 实体圆，推/撞 | 被推、被撞、受惊 |
| `GRAB` | `PENDING` 保持 ≥280ms 且移动 ≤6px | 关闭实体圆，改用抓取约束 | 被抓，身体下垂/摆动 |
| `HIT` | `SOLID` 速度 ≥900px/s 且撞到角色 | 仍是实体 | 受击、后仰、眩晕，进入短暂冷却 |

> `HIT` 不是独立持久状态，是 `SOLID` 下的一次事件；触发后仍在 `SOLID`，直到松手。

---

## 3. 状态机

```
                无按键
                  │
                PASSIVE ◄──────────────── 松手（任何模式）
                  │
        ┌─────────┴─────────┐
   在角色上按下          在桌面按下
        │                   │
     PENDING              SOLID
      │  │  │               │
      │  │  └─保持280ms─► GRAB ──松手──► THROWN / RECOVER
      │  │
      │  └─移动>6px──► SOLID
      │
      └─抬起<180ms──► TAP（POKE）
```

补充：

- `SOLID` 下快速掠过角色 → `HIT` 事件（仍 `SOLID`）。
- `GRAB` 下松手 → 按速度进入 `THROWN` 或 `RECOVER`。
- 任何模式松手都回到 `PASSIVE`（`GRAB` 例外，进入投掷/恢复）。

## 4. 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `LONG_GRAB_MS` | 280 | 200–400 | 在角色上长按进入抓取 |
| `LONG_GRAB_MOVE_PX` | 6 | 4–10 | 长按期间允许的抖动 |
| `TAP_MAX_MS` | 180 | 120–250 | 短按判定 |
| `TAP_MAX_PX` | 4 | 2–6 | 短按抖动 |
| `SOLID_RADIUS` | 10 | 6–16 | 实体光标半径 |
| `SOLID_VEL_WINDOW_MS` | 50 | 30–80 | 光标速度采样窗口 |
| `HIT_SPEED` | 900 px/s | 600–1500 | 撞击判定 |
| `HIT_COOLDOWN_MS` | 400 | 200–800 | 连续撞击防抖 |
| `PUSH_MAX` | 1600 px/s | 800–2400 | 单次推力上限 |

所有值乘 `dpi_scale`；可通过调试面板热调。

## 5. 物理交互

### 5.1 只在 SOLID 时碰撞

- `PASSIVE`/`PENDING`/`GRAB`：光标不参与物理，不产生碰撞。
- `SOLID`：光标是**运动学圆**，位置跟随鼠标（可用 30–60Hz 平滑），不参与受力。
- 角色粒子与光标圆做圆-点/圆-胶囊推出。

### 5.2 推出与推力

对每个骨骼胶囊/头部圆：

```
n = normalize(point_on_bone - cursor)
penetration = radius_cursor + radius_bone - distance
if penetration > 0:
    pos += n * penetration          # 位置推出
    impulse = clamp(relative_velocity · n, 0, PUSH_MAX)
    prev -= n * impulse * H * 0.35  # Verlet 加冲量
```

- 推力方向：从光标指向角色，加上少量切向拖拽。
- 光标速度取 50ms 窗口平均；松手后不保留推力。
- 角色被推到墙/屏幕边缘时按正常碰撞处理。

### 5.3 防穿透

- 光标一帧位移可能超过半径：用上一帧位置到当前位置做**线段扫掠**，取最早接触点。
- 快速甩动（>2000px/s）仍可能穿过细骨骼：对 13 根胶囊逐一做扫掠，或用子步。
- 撞击事件只在接触且相对速度 ≥ `HIT_SPEED` 时触发，冷却 400ms。

### 5.4 HIT 反应

- 对被抓/待机角色：`Startle` + 后仰 + 星星/汗滴 + 音效。
- 对已倒挂/被抓角色：额外晃动的物理冲量。
- 不影响 AI 控制，只作为事件广播。

## 6. 全局鼠标：必须解决的技术前提

窗口是穿透的：**在桌面空白处按下时，Godot 收不到 `InputEventMouseButton`**。但本规则要求"在桌面任何地方按住都能推角色"，因此必须知道全局左键状态。

### 6.1 方案

| 方案 | 做法 | 评价 |
|---|---|---|
| **GDExtension（推荐）** | Win32 `GetAsyncKeyState(VK_LBUTTON)` + `GetCursorPos`，120Hz 轮询 | 核心交互不依赖外部进程；稳定 |
| Go sidecar | Go 读取全局鼠标，通过本机 IPC/WS 发给 Godot | 与 AI 客户端复用，但让核心交互依赖 Go 进程 |
| 仅窗口内 | 只用 Godot 事件 | 无法实现"桌面任意位置按住"；仅能做角色附近按住 |

结论：**采用 GDExtension `GlobalMouse`**。如果暂时不做扩展，降级为"仅光标在角色凸包内可按住"，并在设置里说明。
> 决策状态：C# `TrayHelper` 已输出全局鼠标状态，Godot `GlobalMouse` 读取；完整抓取语义仍属 P3。

### 6.2 接口

```gdscript
class_name GlobalMouse
static func is_left_down() -> bool
static func position() -> Vector2   # 屏幕坐标
static func poll() -> void          # 120Hz
```

- `GlobalMouse` 只提供状态，不产生输入事件；`InputRouter` 合并"窗口事件 + 全局状态"。
- 窗口内按下仍走事件通道；窗口外按下走全局轮询。
- 释放检测同样走全局状态，避免"在窗口外松手"丢失。

### 6.3 失败降级

- GDExtension 缺失：`PASSIVE` + 窗口内交互可用；桌面推/撞禁用，调试面板提示。
- 全局状态读取失败：退回窗口事件，不崩溃。

## 7. 视觉反馈

| 模式 | 光标 | 角色 |
|---|---|---|
| `PASSIVE` | 系统箭头 | 可看向光标，但不被推 |
| `PENDING` | 系统箭头 + 轻微高亮 | 注意到按压，准备反应 |
| `SOLID` | 10px 半透明圆环 | 被推时倾斜/踉跄 |
| `GRAB` | 抓取手型，隐藏圆环 | 身体一缩、手乱抓 |
| `HIT` | 圆环 + 冲击线 | 后仰/星星/汗滴 |

圆环只是提示，不改变系统光标形状（避免影响桌面使用）。

---

## 8. AI 状态暴露

AI 协议 `state.cursor` 增加：

```json
"cursor": {
  "mode": "passive|pending|solid|grab",
  "pos": [1200, 400],
  "vel": [0, 0],
  "down": false
}
```

- AI 必须知道 `PASSIVE` 时光标不是实体，不能假设"推"一定生效。
- `HIT` 通过 `event` 广播，不进入 `mode`。

---

## 9. 验收

- [ ] 不按键放置 10 分钟，角色不被光标推动
- [ ] 角色上短按 <180ms → 戳，不抓取
- [ ] 角色上长按 280ms → 抓取；移动 >6px 转为实体推
- [ ] 桌面空白处按住 → 实体光标，可推动待机角色
- [ ] 按住快速掠过（>900px/s）→ HIT + 受惊反应
- [ ] 松手立即回到 PASSIVE，不再有推力
- [ ] 窗口穿透状态下，桌面按住仍能推角色（GlobalMouse）
- [ ] 2000px/s 甩动不穿透细骨骼
- [ ] AI 的 `state.cursor.mode` 与实际一致

---

## 10. 与现有文档的差异

| 旧规则 | 新规则 |
|---|---|
| 按下即拖拽 | 角色上**长按 280ms** 才抓取 |
| 点击身体=抓取 | 短按=戳；长按=抓取 |
| 光标始终可碰撞 | 仅按住左键（`SOLID`）时碰撞 |
| 穿透时空白的点击不归 Godot | 用 `GlobalMouse` 读取全局按键，支持桌面推/撞 |

> 本文为准；旧文档中的"按下即拖拽"以本文替换。
