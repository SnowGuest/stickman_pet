## 2. 状态机

### 2.1 接口

```gdscript
class_name PetState extends RefCounted

var id: StringName
var priority: int
var clip: StringName

func enter(_pet) -> void: pass
func exit(_pet) -> void: pass
func update(_pet, _dt: float) -> StringName: return &""   # 返回下一个状态或空
```

```gdscript
class_name PetBrain extends Node

var _states := {}
var _current: PetState

func register(s: PetState) -> void:
    _states[s.id] = s

func request(id: StringName) -> void:
    var s: PetState = _states.get(id)
    if s == null or s == _current:
        return
    if _current and s.priority < _current.priority:
        return
    _current.exit(get_parent())
    _current = s
    s.enter(get_parent())
    state_changed.emit(s.id)
```

### 2.2 状态表

| 状态 | 优先级 | 进入条件 | 默认剪辑 | 退出 |
|---|---|---|---|---|
| `Drag` | 100 | 角色上长按 280ms 命中 | drag_idle | 松手 → Thrown/Recover |
| `Thrown` | 90 | 松手速度 > 400px/s | ragdoll | 静止 0.3s → Recover |
| `Startle` | 80 | 被甩/被戳/被撞击/落地重击 | startle | 0.8s → Idle |
| `Poke` | 70 | 单击未拖动 | poke | 0.6s → Idle |
| `Recover` | 60 | 落地静止 | recover | 剪辑结束 → Idle |
| `Sleep` | 40 | energy < 0.15 | sleep | 点击/拖拽 |
| `Sit` | 30 | 空闲 > 3min | sit | 点击/移动 |
| `Walk` | 20 | 想靠近光标/随机漫步 | walk | 到达/超时 |
| `LookAround` | 10 | boredom > 0.7 | look | 2–4s |
| `Idle` | 0 | 默认 | idle | 计时/事件 |

### 2.3 打断规则

| 当前 \ 请求 | Drag | Thrown | Startle | Poke | Recover | Sleep |
|---|---|---|---|---|---|---|
| Idle | ✅ | — | ✅ | ✅ | — | ✅ |
| Drag | — | ✅ | — | — | — | — |
| Thrown | — | — | — | — | ✅ | — |
| Recover | ✅ | — | ✅ | — | — | ❌ |
| Sleep | ✅ | — | ✅ | ✅ | — | — |

硬规则：

- `Drag` 可打断除 `Thrown` 外一切。
- `Thrown` 期间忽略点击，防止半空被抓。
- `Recover` 禁止 `Sleep`，避免"刚爬起来就睡"。
- 任何状态切换先 `PoseBlender.crossfade(old, new, 0.18)`。

## 3. 需求模型（让它像活的）

> 无 AI、无操作时的 10 条自主小剧场见 [内置行为清单](03-内置行为清单.md)。它们是 `Idle` 之上的 Activity，不新增 FSM 状态。

```gdscript
var energy := 1.0        # 0..1，随时间下降，睡眠恢复
var boredom := 0.0       # 0..1，无互动上升，看/走降低
var curiosity := 0.5     # 对光标/新事物的兴趣

func _tick_needs(dt: float) -> void:
    energy = clampf(energy - dt * 0.002, 0.0, 1.0)
    boredom = clampf(boredom + dt * 0.006, 0.0, 1.0)
    curiosity = clampf(curiosity + dt * 0.004, 0.0, 1.0)
```

决策每 0.5s 一次（不要每帧 roll）：

```gdscript
func _decide() -> StringName:
    if energy < 0.15:
        return &"Sleep"
    if boredom > 0.85 and randf() < 0.35:
        return &"Walk"
    if boredom > 0.7:
        return &"LookAround"
    if curiosity > 0.8 and _cursor_near():
        return &"LookAround"
    return &"Idle"
```

交互事件反向修正：被戳 `boredom -= 0.3`，被喂/被玩 `energy += 0.1`。

## 4. 剪辑映射

| 状态 | 剪辑 | 循环 | 备注 |
|---|---|---|---|
| Idle | idle | 是 | 呼吸/重心 |
| LookAround | look | 是 | 头跟随光标 |
| Walk | walk | 是 | 根位移由代码给，剪辑只做腿 |
| Sit | sit | 是 | 腿悬空摆动 |
| Sleep | sleep | 是 | 蜷缩 + Zzz |
| Drag | drag_idle | 是 | 物理主导，剪辑只给参考姿态 |
| Thrown | ragdoll | 是 | 无动画，纯物理 |
| Recover | recover | 否 | 播放一次 |
| Poke | poke | 否 | 弹跳 + 后仰 |
| Startle | startle | 否 | 汗滴 + 后仰 |

规则：非循环剪辑结束后必须主动 `request("Idle")`，不能靠 `AnimationPlayer` 信号。

## 5. 手势 → 意图
| 手势 | 条件 | 意图 |
|---|---|---|
| tap | 角色上 <180ms，<4px | Poke |
| long_press | 角色上保持 280ms，移动 ≤6px | Grab（抓取） |
| pet_press_move | 角色上按下后移动 >6px | Solid（实体推） |
| desktop_press | 角色外按下 | Solid（实体推） |
| fling | Solid 速度 >900px/s 撞到角色 | HIT + Startle |
| grab_release | Grab 松手 >900px/s | Thrown |
| shake | 0.5s 内 10 次反向 | Startle + dizzy |
| right_click | — | 菜单（静音/退出） |

冲突解决：

- 在角色上按下后：短按=戳，保持=抓，移动=实体推；三者互斥。
- 在角色外按下只进入实体推，不能抓取（抓取必须从角色身上开始）。
- 用户输入（PENDING/GRAB/SOLID）优先于 AI 命令。
- UI 菜单打开时，所有下层手势屏蔽。
- 抓取后忽略 double tap，直到松开。

> 完整模式、阈值与物理见 [光标交互规范](02-光标交互规范.md)。

## 7. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 状态抖动 | 两个状态互相 request | 加最短停留时间 0.2s |
| 卡在 Recover | 剪辑结束未派发 | 用时长兜底 |
| 一直 Sleep | energy 恢复逻辑缺失 | 睡眠时 `energy += dt*0.02` |
| 抓取被 Poke 抢先 | 手势优先级错 | Drag > Poke |
| 姿态不恢复 | 姿态未绑定状态退出 | `exit()` 里复位 |
