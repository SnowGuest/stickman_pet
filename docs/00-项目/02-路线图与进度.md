## 5. 关键路径

```
P0 ──► M0 ──► M1 ──► M2 ──► M3 ──► M4 ──► M5 ──► M6
        │              │       │
        │              │       └── 手感调参（最不可控，预留 2d 缓冲）
        │              └── 动画剪辑质量影响物理观感
        └── 穿透/坐标错了会拖累所有后续交互
```

关键路径上的风险：

- **M3 手感**：调参可能反复，必须先把调试面板做出来。
- **M0 穿透**：坐标/DPI 错会导致抓取全面偏移。
- **M2 剪辑**：动作不自然会让物理看起来更假，需先有可用的待机/被抓参考姿态。

## 9. 完成定义（DoD）

一个任务算完成，必须：

1. 代码合并（或本地提交）且可运行。
2. 对应文档的接口/参数已同步。
3. 验收步骤可复现，结果记录在本页或测试文档。
4. 没有新增警告/报错（允许的警告需注明）。
5. 性能在预算内，或有明确的后续优化项。
