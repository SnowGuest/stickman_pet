# P4 · 行为与姿态

> 版本：[v0.5.0-alpha](../版本迭代/v0.5.0.md) · 状态：⬜ 未开始 · 完成度：0%
> 目标：它不再只是"会动的物理模型"，而是有情绪、会自己待机、被戳会反应的宠物。
> 前提：**火柴人没有脸**；圆头无五官，不做面部系统。

---

## 1. 阶段目标

- 10 状态 FSM + 打断矩阵；
- 需求模型（energy/boredom/curiosity）驱动待机选择；
- 无脸表演：头部朝向、身体倾斜、预备/停顿/过冲、反应动作；
- 双骨 IK：手够鼠标、脚踩地、被拎起时挣扎；
- 音效池与事件映射。

---

## 5. 依赖与风险

| 项 | 说明 |
|---|---|
| 依赖 P3 | 需要 Drag/Thrown/Recover 的物理权重 |
| 风险：状态抖动 | 最短停留 0.2s；高优先级打断规则 |
| 风险：卡在 Recover | 剪辑时长兜底 |
| 风险：姿态不恢复 | 状态 `exit()` 复位 |
| 风险：手势冲突 | UI > 宠物，拖拽锁定 |
