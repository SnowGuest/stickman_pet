# P5 · 2.5D 表现

> 版本：[v0.6.0-beta](../版本迭代/v0.6.0.md) · 状态：🟡 进行中 · 完成度：50%
> 目标：从"能玩"到"好看"——同色 z-order 分层、接触阴影、透视倾斜、转身换层。

---

## 1. 阶段目标

- 同色 z-order 分层：后臂/躯干/前腿/前臂/头，仅调整前后关系，不压暗、不换色；
- 视差、倾斜、挤压/拉伸、转身换层；
- 接触阴影随高度缩放；
- 冲击特效（后置）。

---

## 5. 依赖与风险

| 项 | 说明 |
|---|---|
| 依赖 P3/P4 | 需要姿态、抓取、状态机 |
| 风险：分层闪烁 | 层交换只在 |scale.x| < 0.05 时执行一次 |
| 风险：性能 | 单笔路径 + 4 层同色，预算 < 1.2ms |
| 风险：阴影穿帮 | 阴影不随 Visual 变换，单独按骨盆高度计算 |
