## 1. 阶段目标

- 补齐单元/集成测试与手动验收清单；
- 性能达标：逻辑 < 4ms、60fps、内存 < 120MB；
- 8 小时挂机稳定，无崩溃/无增长；
- 安装 4.7.2 导出模板，产出 Windows 包；
- 发布检查清单、回滚流程、变更日志；
- 文档与版本记录完整。
