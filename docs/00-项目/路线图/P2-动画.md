# P2 · 动画

> 版本：[v0.3.0](../版本迭代/v0.3.0.md) · 状态：⬜ 未开始 · 完成度：0%
> 目标：火柴人"活"起来——待机、走路、被抓三套动作可切换、可混合。

---

## 1. 阶段目标

- 建立 JSON 剪辑格式、加载校验与采样器；
- 支持交叉淡化与加性层（呼吸/受击）；
- 至少产出 `idle`、`walk`、`drag_idle` 三套可用动作；
- 事件系统（呼吸/脚步等）可用；
- 为 P3 物理提供稳定的目标角输入。

---

## 2. 需求与验收

| ID | 需求 | 验收 | 状态 |
|---|---|---|---|
| P2-R1 | JSON 剪辑格式 | 骨骼名/时间升序/循环闭合校验通过 | ⬜ |
| P2-R2 | 采样器 | 1000 次采样无 NaN，循环处连续 | ⬜ |
| P2-R3 | 绝对角→相对角 | 加载转换与手算一致 | ⬜ |
| P2-R4 | 交叉淡化 | 0.2s 内无可见跳变 | ⬜ |
| P2-R5 | 加性层 | 呼吸不干扰状态切换 | ⬜ |
| P2-R6 | 事件 | 循环边界各触发一次，不重复 | ⬜ |
| P2-R7 | 三套剪辑 | idle/walk/drag_idle 可播放 | ⬜ |
| P2-R8 | 表演性关键帧（后置） | 至少一段含预备/停顿/过冲的表演，不像匀速循环 | ⏳ |

## 5. 依赖与风险

| 项 | 说明 |
|---|---|
| 依赖 P1 | 需要 Rig/FK 与渲染才能看到动画 |
| 风险：动作不自然 | 先用简单 keyframe 跑通，再打磨 |
| 风险：循环跳变 | 首尾帧闭合校验，门禁/测试兜底 |
| 风险：角度过冲 | 禁止 Catmull-Rom，使用 smoothstep |
