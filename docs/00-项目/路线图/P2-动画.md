# P2 · 动画

> 版本：[v0.3.0](../版本迭代/v0.3.0.md) · 状态：🟡 进行中 · 完成度：95%
> 目标：火柴人"活"起来——待机、走路、被抓三套动作可切换、可混合。

---

## 1. 阶段目标

- 建立 JSON 剪辑格式、加载校验与采样器；
- 支持交叉淡化与加性层（呼吸/受击）；
- 至少产出 `idle`、`walk`、`drag_idle` 三套可用动作；
- 事件系统（呼吸/脚步等）可用；
- 为 P3 物理提供稳定的目标角输入。

## 4. 当前状态

**进行中，约 95%。**

已完成：

- `AnimClip` / `AnimLibrary`：`assets/anims/*.json`，骨骼名/时间升序/循环闭合校验；
- `PoseSampler`：绝对角采样、smoothstep、循环、绝对→相对；
- `PoseBlender`：相对角最短路径交叉淡化 + 加性层；
- `AnimPlayer`：idle/walk/wave/cheer 播放、切换、seek、事件去重；
- 加性呼吸：spine/neck 正弦偏置，不参与剪辑切换；
- `wave` 表演剪辑：预备、停顿、多次挥手、过冲、收回；
- `walk` 前倾约 12°、颈/头下探约 25°，头圆沿颈方向偏移，表现“低头看地面物体”；
- 四套循环剪辑自动加载，默认 `idle`；
- `PetBrain` 0.2s 交叉淡化切换 idle/walk/wave/cheer；
- 调试骨架高亮当前剪辑涉及骨骼；
- `--anim=wave --anim-time=1.2` 可截图验收特定帧。

未完成：

- 0.2s 交叉淡化的视觉录像验收；
- 四套循环动作的最终表演质量打磨。

## 5. 依赖与风险

| 项 | 说明 |
|---|---|
| 依赖 P1 | 需要 Rig/FK 与渲染才能看到动画 |
| 风险：动作不自然 | 先用简单 keyframe 跑通，再打磨 |
| 风险：循环跳变 | 首尾帧闭合校验，门禁/测试兜底 |
| 风险：角度过冲 | 禁止 Catmull-Rom，使用 smoothstep |
