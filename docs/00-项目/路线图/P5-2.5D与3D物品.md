# P5 · 2.5D 与 3D 物品

> 版本：[v0.6.0-beta](../版本迭代/v0.6.0.md) · 状态：⬜ 未开始 · 完成度：0%
> 目标：从"能玩"到"好看"——纸片分层、接触阴影、透视倾斜，以及 Minecraft 风格的 3D 掉落物。

---

## 1. 阶段目标

- 2.5D 分层：后臂/躯干/前腿/前臂/头，各自 z_index 与压暗；
- 视差、倾斜、挤压/拉伸、转身换层；
- 接触阴影随高度缩放；
- 3D 物品：SubViewport 离屏渲染、正交相机、Nearest、Y 轴旋转；
- 物品 2D 合成：z_index、拖拽、落地、被拿起；
- 多物体穿透策略（光标轮询 + 整窗开关）。
