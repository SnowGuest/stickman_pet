# P1 · 最小可视

> 版本：[v0.2.0](../版本迭代/v0.2.0.md) · 状态：🟡 M0/M1 已完成；抓取误差待补 · 完成度：95%
> 目标：屏幕上出现一个透明置顶、可穿透、能画出静态火柴人的窗口。

---

## 1. 阶段目标

把"框架"变成"看得见的桌宠骨架"：

- M0：透明置顶窗口 + 动态鼠标穿透 + 单实例 + 1:1 坐标；
- M1：13 骨 Rig 数据 + FK + 线条渲染 + 调试面板。

完成后，角色还不会动，但已经具备后续所有系统所需的坐标、姿态与渲染基础。

## 4. 当前状态

**M0/M1 已完成；P1 抓取误差待补，完成度 95%。**

已完成：

- 透明/置顶/无边框窗口、可用区铺满、NO_FOCUS；`WS_EX_TOOLWINDOW` 隐藏 Alt+Tab/任务栏条目；
- 宠物渲染边界按实际缩放适配窗口，顶部 32px、底部按线宽留安全边距，脚/线宽不再被屏幕裁切；
- 2D MSAA 8× + `Line2D.antialiased`，减少锯齿；
- 凸包穿透：`tools/test_passthrough.ps1` 实测 50/50 空白点穿透，宠物中心命中本窗口；
- 150%/200% DPI 均跑通 50 点穿透（`-Dpi 2.0`）；全局/窗口坐标往返误差 0（4 项测试）；
- 任务栏四方向站立线：用合成 `Rect2` 对 bottom/top/left/right 做几何测试；
- 单实例：第二个进程启动即退出（`tools/test_single_instance.ps1`）；
- 退出清理：端口释放、托盘 helper 退出（`tools/test_exit.ps1`）；
- 启动 `_ready` 约 260ms（`tools/test_startup.ps1` 实测 279ms，上限 2000ms）；
- 13 骨 Rig JSON 编译、FK 测试通过；
- 橙色空心头 + 纯色一笔画渲染（无白描边），截图见 `build/p1_viewport.png`；
- 调试：`--pet-debug` 骨架点、F1/F6/F7、FloatPanel 缩放/线宽/色板/骨架开关；
- 托盘：C# 原生 helper `TrayHelper.cs`（Win32 NotifyIcon），菜单显示/隐藏、静音、置顶、缩放（1.25/1.50/2.00）与退出；
  `TrayService` 通过临时命令文件驱动主进程；PowerShell 仅作 helper 缺失时 fallback；
- 宠物右键菜单：同托盘命令，打开时临时锁定全窗穿透，关闭后恢复凸包。

> 调试参数放在 `--` 后：`godot --path . -- --pet-debug`。

未完成：

- 200% DPI 渲染与穿透抽点已实测，坐标往返误差 0；真实抓取点误差待抓取系统（P3）；
- `GlobalMouse` 等价原生实现仍留到 P3 抓取阶段。

> `desktop_ext` 采用 C# helper 作为等价原生实现；没有引入 GDExtension DLL。

## 5. 依赖与风险

| 项 | 说明 |
|---|---|
| 依赖 P0 | 工程设置、字体、门禁 |
| 风险：透明兼容 | 先做启动自检与白底降级 |
| 风险：穿透坐标 | 全链路只用窗口局部坐标，禁止混用屏幕坐标 |
| 风险：区域提交频率 | 30Hz + 0.75px 滞回，禁止每帧调用 |
| 风险：托盘原生实现 | C# helper 依赖 .NET Framework csc；PowerShell 作为 fallback |
