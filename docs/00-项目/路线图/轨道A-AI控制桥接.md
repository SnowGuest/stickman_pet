# 轨道 A · AI 控制桥接

> 版本：[v0.5.5-ai](../版本迭代/v0.5.5.md) · 状态：⬜ 未开始 · 完成度：0%
> 目标：独立 Go AI 客户端通过本机 WebSocket 下发高层意图，Godot 桌宠执行；AI 不存在时桌宠仍可自主运行。
> 协议详见 [AI 控制架构与协议](../../07-AI集成/01-控制架构与协议.md)。

---

## 1. 为什么是并行轨道

AI 控制依赖但不阻塞主线：

- 需要 P1 的窗口/输入/状态；
- 需要 P3 的物理与 P4 的状态机作为"可执行动作"；
- 但协议、Go 客户端骨架、模拟器可以提前开发，不必等表演层。

因此不插入 P0–P6 编号，作为**轨道 A** 与 P3/P4 并行推进。

## 2. 需求与验收

| ID | 需求 | 验收 | 状态 |
|---|---|---|---|
| A-R1 | 协议 v1 | `hello/welcome/state/command/ack/event/ping` 全部实现 | ⬜ |
| A-R2 | Godot WS Server | 只绑定 `127.0.0.1`，token 鉴权，单客户端 | ⬜ |
| A-R3 | 状态发布 | 15Hz 快照，包含 pet/input/items/events | ⬜ |
| A-R4 | 命令校验 | 白名单、范围、TTL、速率限制、ack 原因 | ⬜ |
| A-R5 | 模式仲裁 | 用户输入 > AI > 自主；断线 1s 回自主 | ⬜ |
| A-R6 | Go 客户端 | 连接、心跳、指数退避重连，不退出 | ⬜ |
| A-R7 | 模型接口 | `Policy.Act(state) -> Action`，ONNX 或原生实现 | ⬜ |
| A-R8 | 推理循环 | 10–20Hz，不阻塞 WS；慢推理不补发过期动作 | ⬜ |
| A-R9 | 日志回放 | JSONL 记录 state/action，可重放 | ⬜ |
| A-R10 | 安全 | 64KB 上限、非法 JSON/未知动作不崩溃 | ⬜ |

## 5. 依赖与风险

| 项 | 说明 |
|---|---|
| 依赖 P1 | 窗口/输入/状态就绪 |
| 依赖 P3/P4 | 可执行动作与 FSM |
| 风险：延迟 | 高层意图 + TTL，避免逐帧同步 |
| 风险：抖动 | Godot 侧平滑/限幅，AI 不直写关节 |
| 风险：断线 | 1s 回自主，Go 无限重连 |
| 风险：安全 | 本机绑定 + token + 白名单 |
