## 1. 阶段目标

在写任何游戏逻辑之前，先把"能长期维护的工程"搭好：

- 文档、仓库、门禁、CI 可运转；
- Godot 工程设置正确（透明窗口、1:1 坐标、主场景、版本、主题）；
- 发布流程可重复（staging 排除开发插件、校验禁止字符串）；
- 中文 UI 不出现方框；
- 新会话/新 agent 能按文档接手。

## 5. 依赖与风险

| 依赖/风险 | 影响 | 处理 |
|---|---|---|
| GitHub 认证未配置 | 无法 push、CI 不运行 | 安装 GCM 或配置 SSH key |
| 导出模板未安装 | 无法产出 exe | 编辑器 → 管理导出模板，安装 4.7.2 |
| 透明窗口兼容性 | 部分驱动黑底 | 启动自检 + 白底降级（P1 实现） |
| 中文字体体积 17MB | 包体偏大 | 可接受；后续按需子集化 |
