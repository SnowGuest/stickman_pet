## 1. 阶段目标

在写任何游戏逻辑之前，先把"能长期维护的工程"搭好：

- 文档、仓库、门禁、CI 可运转；
- Godot 工程设置正确（透明窗口、1:1 坐标、主场景、版本、主题）；
- 发布流程可重复（staging 排除开发插件、校验禁止字符串）；
- 中文 UI 不出现方框；
- 新会话/新 agent 能按文档接手。
