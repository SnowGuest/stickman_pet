# P3 · 物理与抓取

> 版本：[v0.4.0](../版本迭代/v0.4.0.md) · 状态：🟡 进行中 · 完成度：35%
> 目标：抓住任何部位都能自然下垂、摆动、抛出、落地——这是项目的核心手感。

---

## 1. 阶段目标

- 自研 PBD 求解器：距离、角度、抓取、碰撞四类约束；
- 抓取任意骨骼（腰/头/手/脚），抓点精确、不瞬移；
- 张力表 + 世界空间躯干偏置，做出"有肌肉"的下垂；
- 投掷、落地、休眠、渲染插值；
- 调试面板与参数热调先行，避免盲调。

## 4. 当前状态

**进行中，约 35%。**

已完成：

- `RagdollSolver`：固定步长、Verlet、距离约束、全骨骼相对静止角限位、地面/墙/顶部碰撞、抓取约束、休眠；
- **屏幕四边硬边界**：每个物理步最后 `_solve_collisions + _clamp_bounds`，约束不能把角色推出窗口；
- 头部按可视化半径单独扩大碰撞半径；
- 四套基础张力表（腰/头/手/腿）已定义，但抓取阶段主动角驱动暂设为 0，仅保留 spine 很弱的世界支撑，防止绕抓点翻转；
- 抓取目标按 14/s 平滑、按两端逆质量分配修正，并耗散绕抓点切向速度：移动鼠标时有惯性而不是瞬移，抓取不像无质量；
- 按住期间每帧轮询 `Viewport.get_mouse_position()`，不依赖可能丢失的 MouseMotion 事件；不使用全局键状态强制松手，避免输入链路冲突；
- 鼠标停住 >80ms 后冻结求解器并清零 `prev`，彻底消除关节残余抽动；移动时自动唤醒；
- 点中**关节**时只钉住该关节粒子，并把相邻骨长的距离修正质量设为 0，避免只移动单侧端点把骨头拉长；
- 点击命中重叠时按“四肢 > 颈/头 > 躯干”优先，肘/膝压到躯干上仍抓肢体，不会误抓躯干；
- 头部圆按渲染缩放单独命中，抓头映射到 `neck_top` 并保留“头部中心相对 neck_top”的偏移，头/颈骨长不被拉长；
- 全骨骼限位按“相对静止角”计算；肘后弯 ≤20°/前屈 150°，膝主弯 ≤90°/反向 ≤10°，spine ±18°、neck ±22°、head ±18°；
- 抓取保持被动：不做刚性位移混合，头/四肢完整受重力；左右平移时保留自然跟随摆动；
- 自由下落 `damping=1.0`、`max_speed=6000`，速度按 `g·t` 线性增加；抓取时用 0.985 额外阻尼稳定；
- 渲染插值：120Hz 物理位置按 accumulator 插值到显示帧；
- `PhysicsController`：从当前动画姿态启动、左键抓任意骨骼、拖动、松手抛出/落地；
- 抓取 offset 防瞬移，目标点夹在屏幕内；
- 松手后保持**纯物理**坠落/落地，不切脚本动画；
- 坠落慌乱/摔倒/爬起序列暂时移除，后续独立实现，避免中断物理；
- **去弹性落地**：`restitution=0`、接触额外耗散、松手后约束速度耗散与快速休眠；
- **坠落修复**：空中只做轻微阻尼，接触地面才强耗散；休眠要求关节接地，避免松手后在空中停住；
- 单元测试：600 步骨长误差 0.41px、抓点误差 0.001px、2400px/s 冲量后四边不越界、无 NaN、落地后残余速度 <40px/s、长按后松手继续坠落、关节抓取骨长误差 <1px、自由落体速度持续增加。
