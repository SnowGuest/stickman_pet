# P3 · 物理与抓取

> 版本：[v0.4.0](../版本迭代/v0.4.0.md) · 状态：🟡 进行中 · 完成度：35%
> 目标：抓住任何部位都能自然下垂、摆动、抛出、落地——这是项目的核心手感。

---

## 1. 阶段目标

- 自研 PBD 求解器：距离、角度、抓取、碰撞四类约束；
- 抓取任意骨骼（腰/头/手/脚），抓点精确、不瞬移；
- 张力表 + 世界空间躯干偏置，做出"有肌肉"的下垂；
- 投掷、落地、休眠、渲染插值；
- 调试面板与参数热调先行，避免盲调。

## 5. 依赖与风险

| 项 | 说明 |
|---|---|
| 依赖 P2 | 需要动画目标角作为张力输入 |
| 风险：抖/炸 | 固定步长、`max_corr`、质量下限、NaN 检查 |
| 风险：手感调不出 | 调试面板先行；按"重力→限位→张力→阻尼"顺序 |
| 风险：抓取瞬移 | 抓取瞬间记录 offset，鼠标平滑 22/s |
| 风险：时间超支 | P3 权重 25%，预留 2 天缓冲 |
