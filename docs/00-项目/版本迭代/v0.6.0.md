# v0.6.0-beta · 2.5D 表现

> 状态：⬜ 计划中 · 阶段：[P5](../路线图/P5-2.5D表现.md) · 发布日期：待定
> 版本号：`0.6.0`（计划，beta 标记）

---

## 1. 迭代说明

功能基本齐全，进入"好看"阶段：纸片分层、接触阴影、透视倾斜、转身换层。此版本对外可提供 beta 体验。

---

## 2. 计划内容

### 新增

- 2.5D 分层：后臂/躯干/前腿/前臂/头，同色 z-order，不压暗/不描边；
- 视差、倾斜、挤压/拉伸、转身换层；
- 接触阴影：随高度缩放/变淡；
- 冲击特效（后置）：速度线、尘土、星星、汗滴。

### 变更

- 渲染性能优化：分层后仍保持 60fps；
- 转身换层只在挤压到不可见时交换一次。

### 修复

- 层交换闪烁、阴影穿帮、挤压时线宽失真。

---

## 3. 验收目标

- [ ] 截图达到 2.5D 效果（前后层/阴影/倾斜）
- [ ] 转身换层不可见
- [ ] 60fps，无 draw call 增长
- [ ] 阴影随高度连续缩放
- [ ] 更新本页与 CHANGELOG

---

## 4. 依赖与风险

- 依赖 v0.5.0 的状态机与抓取；
- 风险：层交换闪烁 → 只在 |scale.x| < 0.05 时交换；
- 风险：阴影穿帮 → 阴影不随 Visual 变换；
- 风险：性能 → 单笔路径 + 4 层同色，预算 < 1.2ms。
