# v0.6.0-beta · 表现

> 状态：⬜ 计划中 · 阶段：[P5](../路线图/P5-2.5D与3D物品.md) · 发布日期：待定
> 版本号：`0.6.0`（计划，beta 标记）

---

## 1. 迭代说明

功能基本齐全，进入"好看"阶段：纸片分层、接触阴影、透视倾斜，以及 Minecraft 风格的 3D 旋转掉落物。此版本对外可提供 beta 体验。

---

## 2. 计划内容

### 新增

- 2.5D 分层：后臂/躯干/前腿/前臂/头，压暗与微缩；
- 视差、倾斜、挤压/拉伸、转身换层；
- 接触阴影：随高度缩放/变淡；
- `DroppedItem`：SubViewport 64×64、正交相机、Nearest、Y 轴旋转；
- 物品 2D 合成：位置/重力/落地/z_index；
- 拖拽/抛出/被宠物拿起；
- 多物体穿透：光标轮询 + 整窗开关。

### 变更

- 穿透策略从"宠物凸包"切换为"多岛轮询"（有物品时）；
- 渲染性能优化：静止时 3D 视口 `UPDATE_ONCE`。

### 修复

- 透明窗口 3D 黑底、像素糊、灰边、镂空排序等问题。

- 依赖 v0.5.0 的状态机与抓取；
- 风险：透明窗口 3D 黑底 → `BG_CLEAR_COLOR` + 自检；
- 风险：多物体穿透吞点击 → 轮询策略；
- 风险：物品性能 → 限制数量/静止停更。
