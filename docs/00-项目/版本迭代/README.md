## 2. 迭代规则

1. **SemVer**：`MAJOR.MINOR.PATCH`；破坏性改动升 MAJOR，功能升 MINOR，修复升 PATCH。
2. **单一事实源**：版本号只改 `project.godot` 的 `config/version`，并同步本目录与 `CHANGELOG.md`。
3. **发布即记录**：每个版本发布时补发布日期、变更条目、验收结果、已知问题。
4. **计划版本不写"已发布"**：未完成前状态保持"计划中"或"进行中"。
5. **范围冻结**：P3 验收后到 v1.0.0 前只修 bug 与调参，新功能进下一版本。
