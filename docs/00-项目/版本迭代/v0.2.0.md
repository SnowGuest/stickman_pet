## 1. 迭代说明

从"工程骨架"变成"看得见的桌宠"：透明窗口外壳 + 动态穿透 + 静态火柴人。此版本还不会动，但后续动画、物理、行为都依赖这里的坐标、Rig 与渲染。

---

## 2. 计划内容

### 新增

- `DesktopShell`：窗口 flags、屏幕可用区、启动/退出；
- `PassthroughService`：凸包区域、30Hz 提交、变化阈值；
- `SingleInstance`：TCP 42871–42873 + 连接探测，双开退出；
- `RigDefinition` / `BoneDef` / `RigPose` / `RigState`；
- `StickRenderer`：单条 Line2D 17 点一笔画 + 头（无五官），纯色无描边；
- 五色色板：橙（空心头）、绿/蓝/红/黄（实心）；
- 调试：`--pet-debug` 骨架点、F1/F6/F7、`[`/`]` 缩放；
- C# 原生托盘 helper：`TrayHelper.cs` + Win32 `WS_EX_TOOLWINDOW`；
- PowerShell `tray_helper.ps1` 仅作 helper 缺失时 fallback；
- 宠物右键菜单：同样的显示/隐藏、静音、缩放、退出命令；
- 截图模式：`--screenshot` 输出 `user://p1_viewport.png`。

### 变更

- `scenes/main.tscn` 从占位 Label 替换为 Pet 场景骨架；
- `project.godot` 视情况补充输入动作与层命名。

### 修复

- 透明兼容性自检与白底降级（若发现驱动问题）。
