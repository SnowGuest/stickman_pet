# v0.2.0 · 最小可视

> 状态：⬜ 计划中 · 阶段：[P1](../路线图/P1-最小可视.md) · 发布日期：待定

---

## 1. 迭代说明

从"工程骨架"变成"看得见的桌宠"：透明窗口外壳 + 动态穿透 + 静态火柴人。此版本还不会动，但后续动画、物理、行为都依赖这里的坐标、Rig 与渲染。

---

## 2. 计划内容

### 新增

- `DesktopShell`：窗口 flags、屏幕可用区、启动/退出；
- `PassthroughService`：凸包区域、30Hz 提交、变化阈值；
- `InputRouter`：全局鼠标、窗口事件、点击路由；
- `desktop_ext` 原生扩展：`TrayIcon` + `GlobalMouse`；
- `TrayService` + 基础设置菜单（显示/缩放/静音/置顶/退出）；
- 单实例 TCP 锁；
- `RigDefinition` / `BoneDef` / `RigPose` / `RigState`；
- `StickRenderer`：13 条 Line2D + 头（无五官） + 白描边；
- 五色色板：橙（空心头）、绿/蓝/红/黄（实心）；
- 调试面板：骨架、参数热调、穿透区域可视化。

### 变更

- `scenes/main.tscn` 从占位 Label 替换为 Pet 场景骨架；
- `project.godot` 视情况补充输入动作与层命名。

### 修复

- 透明兼容性自检与白底降级（若发现驱动问题）。

## 4. 依赖与风险

- 依赖 v0.1.0 的工程设置与字体；
- 风险：透明窗口在部分驱动黑底 → 启动自检；
- 风险：穿透坐标混用 → 全链路窗口局部坐标；
- 风险：区域提交每帧调用 → 30Hz + 滞回。
