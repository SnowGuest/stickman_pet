# v0.1.0 · 工程基线

> 状态：🟡 进行中（95%） · 阶段：[P0](../路线图/P0-工程基线.md) · 日期：2026-10-19
> 版本号：`0.1.0`（`project.godot`）

---

## 1. 迭代说明

这是项目的第一个版本，不包含游戏逻辑。目标是把"可以长期开发"的地基打好：文档、仓库、工程设置、字体、发布流程、门禁。完成后，后续所有功能都在同一套规范下迭代。

---

## 2. 本版目标

- 建立分级文档与项目门禁，支持多会话/多 agent 接手；
- git 仓库初始化并合并远端；
- Godot 工程设置正确（透明、置顶、1:1 坐标、主场景、版本）；
- 中文 UI 字体可用；
- 发布脚本可重复、可校验；
- CI/门禁能在本地跑通。

---

## 3. 新增

- 分级文档：总览 / 平台 / 仿真 / 表现 / 行为 / 工程 / 附录；
- `AGENTS.md` 协作契约、`CONTRIBUTING.md`、PR 模板；
- `tools/gate.ps1`、Git 钩子、GitHub Actions workflow；
- `CHANGELOG.md`、`.editorconfig`、版本迭代目录；
- 中文字体 Noto Sans SC（OFL 1.1）与 `pet_theme.tres`；
- `export_presets.cfg`、`tools/build_release.ps1`；
- 路线图/版本迭代目录（本页）。

## 4. 变更

- `project.godot`：关闭 stretch、开启透明/无边框/置顶、设置主场景与版本号；
- `.gitignore`：合并远端规则 + 构建物/日志/字体缓存；
- CI：并发取消、超时、最小权限；
- 构建脚本：`build/.gdignore`，避免 Godot 扫描 staging。

## 5. 修复

- 字体下载被截断导致 `FreeType: Error loading font`，已完整下载并校验；
- 门禁脚本 UTF-8 BOM 缺失导致 PowerShell 5.1 解析失败，已修复；
- 发布 staging 被 Godot 扫描产生警告，已加 `.gdignore`。
