# v0.4.0 · 手感

> 状态：🟡 进行中（15%） · 阶段：[P3](../路线图/P3-物理与抓取.md) · 发布日期：待定
> 版本号：`0.4.0`（计划）

---

## 1. 迭代说明

项目最核心的版本：抓取、下垂、摆动、抛出、落地。目标是"抓腰像拎起一只猫，抓头会倒挂，松手能扔出去再爬起来"。

---

## 2. 计划内容

### 新增

- `RagdollSolver`：Verlet 积分、距离/角度/抓取/碰撞约束；
- 固定步长与渲染插值；
- 张力表（腰/头/手/脚四套）与世界空间躯干偏置；
- 投掷速度采样与释放、休眠/唤醒；
- 光标实体：SOLID 下圆-胶囊推出与速度冲量；
- 调试面板：骨架、限位弧、抓点、约束误差、慢动作；
- 物理单元测试：长度、限位、NaN、确定性、休眠。

### 变更

- 渲染改为读取求解后的姿态；
- 状态机接入 Drag/Thrown/Recover（最小版本）。

### 修复

- 抓取瞬移、关节反折、落地穿模等手感问题。

---

## 3. 验收目标

- [ ] 抓腰 0.2s 内下垂，腿摆幅 ≥ 20°
- [ ] 抓头倒挂、抓手拉长、抓脚倒提
- [ ] 10 次抓取 0 反折、0 爆炸
- [ ] 摆动 3 周期内 < 5°
- [x] 抛出/落地不 NaN（首版）
- [ ] 落地 2 次弹跳内停，2.5s 内爬起
- [ ] SOLID 推/撞不穿透，松手后无残留
- [x] 单元测试全绿（长度/抓取/NaN）
- [ ] 更新本页与 CHANGELOG

---

## 4. 依赖与风险

- 依赖 v0.3.0 的动画目标角；
- 风险：手感调不出 → 调试面板先行，按"重力→限位→张力→阻尼"调；
- 风险：时间超支 → P3 权重最高，预留 2 天缓冲；
- 风险：性能 → 14 粒子 × 8 迭代，预算 < 1ms。
