# v0.3.0 · 动画

> 状态：⬜ 计划中 · 阶段：[P2](../路线图/P2-动画.md) · 发布日期：待定
> 版本号：`0.3.0`（计划）

---

## 1. 迭代说明

让火柴人"活"起来：剪辑可加载、可采样、可混合，至少有待机、走路、被抓三套动作。此版本为物理提供稳定的目标角输入，是 P3 手感的前置。

---

## 2. 计划内容

### 新增

- `AnimClip` / `AnimLibrary`：JSON 加载、校验、热重载；
- `PoseSampler`：二分查找、smoothstep、循环；
- `PoseBlender`：crossfade、additive、mask；
- 事件系统：眨眼、呼吸等；
- 剪辑：`idle`、`walk`、`drag_idle`；
- 调试：时间轴拖动、剪辑切换。

### 变更

- `RigPose` 增加事件/权重字段（如需要）；
- 状态机暂不接入（P4 再做）。

---

## 3. 验收目标

- [ ] JSON 校验通过（骨骼名/时间升序/循环闭合）
- [ ] 1000 次采样无 NaN，循环处连续
- [ ] 交叉淡化 0.2s 无可见跳变
- [ ] 加性呼吸不干扰切换
- [ ] 事件在循环边界各触发一次
- [ ] 新增动画只改 JSON
- [ ] 更新本页与 CHANGELOG

---

## 4. 依赖与风险

- 依赖 v0.2.0 的 Rig/FK 与渲染；
- 风险：动作不自然 → 先跑通再打磨；
- 风险：循环跳变 → 首尾帧校验；
- 风险：角度过冲 → 禁止 Catmull-Rom。
