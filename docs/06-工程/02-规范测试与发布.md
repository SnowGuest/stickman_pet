## 1. 目录结构

```
res://
├── scenes/
│   ├── main.tscn                 # 入口：Shell + World + UI
│   └── pet.tscn                  # 宠物：Brain + Solver + Visual
├── scripts/
│   ├── app/                      # main、服务装配、启动参数
│   ├── platform/                 # desktop_shell、screen_probe、passthrough、store
│   ├── input/                    # input_router、gesture、hit_router、grab_controller
│   ├── rig/                      # rig_definition、bone_def、rig_pose、rig_state
│   ├── anim/                     # anim_clip、anim_library、pose_sampler、pose_blender
│   ├── physics/                  # ragdoll_solver、constraints、collision
│   ├── render/                   # stick_renderer、shadow、fx、item_renderer
│   ├── brain/                    # pet_brain、states/*.gd、expression
│   └── debug/                    # overlay、recorder、hot_reload
├── assets/
│   ├── rigs/stickman.tres
│   ├── anims/*.json
│   └── items/*.tres
├── tests/
│   ├── run_tests.gd
│   ├── test_rig.gd
│   ├── test_anim.gd
│   ├── test_solver.gd
│   └── test_config.gd
└── tools/                        # 仅开发期，不导出
```

规则：

- 一个文件一个 `class_name`；文件名与类名 snake_case 对应（`RagdollSolver` → `ragdoll_solver.gd`）。
- `scenes/` 只放场景，`scripts/` 只放脚本；场景不内嵌长脚本。
- `tools/` 与 `tests/` 不进入发布包（导出排除）。

## 2. 命名与代码规范

| 对象 | 规范 | 示例 |
|---|---|---|
| 类 | PascalCase | `RagdollSolver` |
| 文件 | snake_case | `ragdoll_solver.gd` |
| 变量/函数 | snake_case | `grab_strength` |
| 常量 | SCREAMING_SNAKE | `H_STEP` |
| 信号 | 过去式 / 名词 | `grab_started`、`state_changed` |
| 私有 | 前缀 `_` | `_solve_angles()` |
| 资源 | PascalCase + 后缀 | `StickmanRig.tres` |

约定：

- 所有角度对外用**弧度**；只有 JSON 与导出参数用度，函数名带 `_deg`。
- 所有距离用**像素（窗口坐标）**；不使用世界单位。
- 禁止跨层 `get_node("../../")`；依赖通过 `setup(dep)` 注入。
- 每帧路径禁止 `new()` 容器；复用 `Packed*Array`。
- 随机数统一用 `RandomNumberGenerator` 实例，便于回放复现。

### 2.1 依赖检查

```bash
# L2 不应出现平台 API
rg -n "DisplayServer|get_window\(|Input\." scripts/rig scripts/anim scripts/physics
# L0 不应出现骨骼类型
rg -n "BoneDef|RigPose|RagdollSolver" scripts/platform
```

CI 中任一命中即失败（白名单除外）。

### 4.3 运行

```bash

# 或在 CI 中：
godot --headless --path . --script res://tests/run_tests.gd
```

`run_tests.gd` 自己遍历 `test_*.gd`，退出码 = 失败数。CI 只依赖引擎，不依赖编辑器插件。

## 5. 性能

### 5.1 预算（60fps = 16.6ms）

| 项 | 预算 |
|---|---|
| 行为 + 输入 | 0.6ms |
| 动画采样 + 混合 | 0.4ms |
| PBD（120Hz × 8） | 0.9ms |
| IK + FK | 0.2ms |
| 渲染（26 Line2D + 阴影 + FX） | 1.2ms |
| 穿透（30Hz 均摊） | 0.3ms |
| 其他 | 0.6ms |
| **合计** | **< 4.2ms** |

### 5.2 测量

```gdscript
var t := Performance.get_monitor(Performance.TIME_PROCESS)
var fps := Engine.get_frames_per_second()
var draws := RenderingServer.get_rendering_info(RenderingServer.RENDERING_INFO_TOTAL_DRAW_CALLS_IN_FRAME)
```

- 每 5s 打一条汇总日志；8h 长跑导出 CSV。
- 性能回归：固定输入回放 10s，比较总耗时，偏差 > 15% 告警。

### 5.3 优化清单

- 零每帧分配（`duplicate()` 只在水波纹/调试里用）。
- 静止休眠：物理停算。
- 穿透区域 30Hz + 0.75px 滞回。
- 避免 `get_node` 热路径，缓存引用。

## 6. 导出与发布

### 6.1 导出设置

| 项 | 值 |
|---|---|
| 预设 | Windows Desktop (x86_64) |
| 嵌入 PCK | 是（单文件） |
| 控制台 | 关闭（`application/run/disable_stdout=true`） |
| 图标 | `icon.ico`，含 16/32/48/256 |
| 版本 | `application/config/version` |
| 排除 | `addons/godot_ai`、`tests/`、`tools/`、`docs/`、`.vscode/` |

> 开发期保留 `_mcp_game_helper` 供 MCP 调试；**发布包必须由构建脚本移除**，否则 autoload 会指向被排除的插件路径。

### 6.1.1 发布脚本

```powershell
# 只生成并校验 staging（CI 可跑，不需要导出模板）
powershell -ExecutionPolicy Bypass -File tools\build_release.ps1 -NoExport

# 正式导出（需安装 4.7.2 导出模板）
powershell -ExecutionPolicy Bypass -File tools\build_release.ps1
```

脚本做的事：

1. 复制工程到 `build/staging`，排除 `.git`、`.godot`、`build`、`docs`、`tests`、`tools`、`addons/godot_ai`、`addons/.godot_ai_update`、`.vscode`。
2. 从 staging 的 `project.godot` 删除 `_mcp_game_helper` 与 `[editor_plugins]`。
3. 校验 staging 不含插件/测试/helper。
4. 调用 Godot `--import` 与 `--export-release`。
5. 扫描 exe/pck 字节，发现 `godot_ai` 或 `_mcp_game_helper` 直接失败。

> 导出模板未安装时第 4 步会失败；P0 目前只验证了 `-NoExport`。安装模板后再跑一次真实导出并留存产物。

### 6.2 自启

```gdscript
func set_autostart(enabled: bool) -> void:
    var key := "HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run"
    var args := ["add", key, "/v", "StickmanPet", "/t", "REG_SZ",
                 "/d", "\"%s\"" % OS.get_executable_path(), "/f"]
    if not enabled:
        args = ["delete", key, "/v", "StickmanPet", "/f"]
    OS.execute("reg", args)
```

- 只写 `HKCU`，不需要管理员。
- 退出时**不**擅自删除用户设置的自启项。

| 环境 | 预期 |
|---|---|
| Win10 1903+ / Win11 | 完整支持 |
| 远程桌面 | 透明可能失效 → 白底模式 |

### 6.5 回滚

- 版本号语义化；配置带 `version`，旧版遇到高版本配置只读不写。
- 发布包保留上一版下载入口；崩溃率异常时撤回。
