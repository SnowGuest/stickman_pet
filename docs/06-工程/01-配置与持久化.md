# 配置与持久化

> 上级：[文档中心](../README.md) · 领域：工程
> 覆盖：配置分层、Schema、原子写、迁移、损坏恢复、会话状态边界。

---

## 1. 分层

| 层 | 位置 | 内容 | 谁写 |
|---|---|---|---|
| 默认值 | 代码常量 / `PetDefaults` | 所有参数的出厂值 | 开发者 |
| 用户配置 | `user://pet.cfg` | 缩放、屏幕、开关、音量 | 用户操作 |
| 会话状态 | 内存 | 位置、速度、状态、energy | 运行时 |
| 调试覆盖 | 命令行 / 调试面板 | 临时参数 | 开发者 |

规则：**用户配置只存"用户改过的东西"**；不要存瞬时物理状态，否则启动时角色可能卡在半空。

## 2. Schema

```ini
[meta]
version=2

[window]
screen=0
scale=1.25
always_on_top=true
hide_from_taskbar=true

[pet]
energy=0.8
muted=false
volume=0.7

[debug]
overlay=false
passthrough=1
```

| 键 | 类型 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| `meta.version` | int | ≥1 | 2 | 迁移用 |
| `window.screen` | int | 0..N-1 | 0 | 目标屏幕 |
| `window.scale` | float | 0.8–2.0 | 1.25 | 角色缩放 |
| `window.always_on_top` | bool | — | true | 置顶 |
| `window.hide_from_taskbar` | bool | — | true | 任务栏隐藏（平台相关） |
| `pet.energy` | float | 0–1 | 1.0 | 仅粗粒度恢复 |
| `pet.muted` | bool | — | false | 静音 |
| `pet.volume` | float | 0–1 | 0.7 | 音量 |
| `debug.overlay` | bool | — | false | 调试面板 |
| `debug.passthrough` | int | 0/1/2 | 1 | 0=关，1=自动，2=强制穿透 |

未知键保留（向前兼容）；越界值 clamp 并写回。

## 3. 读取

```gdscript
func load_config() -> void:
    var cfg := ConfigFile.new()
    var err := cfg.load(PATH)
    if err != OK:
        _recover(err)
        return
    var v: int = cfg.get_value("meta", "version", 1)
    if v < CURRENT_VERSION:
        _migrate(cfg, v)
    _apply(cfg)
```

`_apply` 必须：

1. 校验类型（`typeof`），类型不符用默认值；
2. 校验范围，clamp；
3. 记录被修正的键（日志一次）；
4. 发出 `config_changed`，让窗口/渲染/音频各自响应。

## 4. 写入：原子与节流

```gdscript
func save_config() -> void:
    var cfg := ConfigFile.new()
    cfg.set_value("meta", "version", CURRENT_VERSION)
    cfg.set_value("window", "scale", _scale)
    # ...

    var tmp := PATH + ".tmp"
    var err := cfg.save(tmp)
    if err != OK:
        push_error("保存失败: %s" % err)
        return
    DirAccess.rename_absolute(tmp, PATH)     # 同分区，原子替换
```

- 先写 `.tmp` 再 rename；崩溃不会留下半个配置文件。
- 变更后 1s 防抖保存，退出时强制保存一次。
- 保存频率上限 1 次/秒，避免拖缩放手柄时狂写磁盘。

## 5. 迁移

```gdscript
const CURRENT_VERSION := 2

func _migrate(cfg: ConfigFile, from: int) -> void:
    var v := from
    if v == 1:
        # v1: [pet] size -> v2: [window] scale
        var old = cfg.get_value("pet", "size", 1.0)
        cfg.set_value("window", "scale", clampf(float(old), 0.8, 2.0))
        cfg.erase_section_key("pet", "size")
        v = 2
    cfg.set_value("meta", "version", v)
    cfg.save(PATH + ".migrated")
```

原则：

- 每步只处理相邻版本，链式迁移。
- 迁移前备份 `pet.cfg.bak`。
- 迁移失败 → 用默认值启动，保留原文件供排查。

## 6. 损坏恢复

| 情况 | 处理 |
|---|---|
| 文件不存在 | 默认值，首次退出时创建 |
| 解析错误 | 重命名为 `pet.corrupt-<时间戳>.cfg`，用默认值 |
| 部分键缺失 | 缺的用默认，其余保留 |
| 版本高于当前 | 只读，提示"配置来自更新版本"，不覆盖 |
| 写入失败（磁盘满/权限） | 保留内存值，下次退出重试 |

## 7. 会话状态

以下**不**持久化：

- 当前 `state`（启动总是 Idle）
- `pos/prev/velocity`
- 抓取状态
- 3D 物品实例（v1 不保存桌面物品）
- 窗口位置（v1 全屏，无位置）

持久化粗粒度 `energy` 只用于"睡醒没睡醒"的氛围，不参与物理。

## 8. 代码接口

```gdscript
signal config_changed(key: StringName, value: Variant)

class_name PetStore extends Node

func get_value(key: StringName, fallback: Variant) -> Variant
func set_value(key: StringName, value: Variant, save_now := false) -> void
func save_now() -> void
func reset_to_defaults() -> void
```

- 读用 `get_value(&"window.scale", 1.25)`，统一点号路径。
- 写后发信号；订阅者自行处理（窗口改尺寸、渲染改缩放）。
- 不把 `PetStore` 做成 autoload 之外的全局静态；通过注入传递，便于测试。

---

## 9. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 重启后缩放丢失 | 只在退出时保存，强杀 | 变更即防抖保存 |
| 配置被写坏 | 直接覆写 | 临时文件 + rename |
| 升级后旧键残留 | 没迁移 | 版本链 + 清理 |
| 两实例互相覆盖 | 无单实例 | TCP 锁 + 后写者胜 |
| 默认值漂移 | 代码与文档两处 | 默认值只在 Schema 表 + `PetDefaults` 一处 |

---

## 10. 验收

- [ ] 首次启动生成默认配置，退出后文件存在
- [ ] 改缩放后 1s 内落盘，强杀不丢
- [ ] 手工写坏配置文件，能备份并恢复默认
- [ ] v1 配置自动迁移到 v2，键不丢
- [ ] 未知键在保存后仍保留
- [ ] 版本高于当前时不覆盖
- [ ] 磁盘只读时只警告、不崩溃
