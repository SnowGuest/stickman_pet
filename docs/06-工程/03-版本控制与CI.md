## 2. 分支模型

| 分支 | 用途 | 规则 |
|---|---|---|
| `main` | 始终可运行 | 不直接提交；通过合并进入 |
| `feat/<scope>` | 新功能 | 从 main 拉出，完成后合并 |
| `fix/<scope>` | 修复 | 同上 |
| `exp/<scope>` | 实验（物理参数/渲染） | 可丢弃，不合并 |

单人项目可以简化：小改动直接 `main`，但**每个里程碑开一个 `feat/` 分支**，便于回滚。

---

## 3. 提交规范

采用 Conventional Commits：

```
feat(physics): 增加抓取约束与张力表
fix(platform): 修正 DPI 下的坐标换算
docs(rig): 补充 FK 与限位说明
test(solver): 增加 NaN 与休眠用例
chore(ci): 添加 headless 导入
```

规则：

- 一次提交只做一件事；不混格式化与逻辑。
- 提交信息写"为什么"，代码注释写"怎么做"。
- 不提交注释掉的死代码与调试输出。

## 4. 大文件与 LFS

| 类型 | 策略 |
|---|---|
| PNG/OGG（< 100KB） | 直接入库 |
| 源文件（.aseprite/.psd/.wav） | Git LFS |
| 导出包 | 不入库，放 Releases |
| 视频/参考素材 | 不入库（版权 + 体积） |

```gitattributes
*.aseprite filter=lfs diff=lfs merge=lfs -text
*.psd filter=lfs diff=lfs merge=lfs -text
*.wav filter=lfs diff=lfs merge=lfs -text
```

## 5. CI 流程

目标：每次 push 都能回答"工程还能打开吗、测试还过吗、能导出吗"。

```
checkout
  → 安装 Godot 4.7.2（缓存）
  → gate -Full                  # 导入 + 132 项测试 + 启动冒烟
  → build_release -PackOnly     # 导出预设/资源打包（无需模板）
  → 导出 Windows 包（仅 tag，需模板）
  → 上传 artifact
```

> 实际工作流以 [.github/workflows/gate.yml](../../.github/workflows/gate.yml) 为准；P0 阶段 CI 先跑静态门禁、Godot 导入、132 项测试和 PCK 打包。

### 5.1 GitHub Actions 示例

```yaml
name: gate

on: [push, pull_request, workflow_dispatch]

jobs:
  godot:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - name: Cache Godot
        uses: actions/cache@v4
        with:
          path: .godot-bin
          key: godot-4.7.2
      - name: Setup Godot
        shell: pwsh
        run: |
          if (!(Test-Path .godot-bin/Godot.exe)) {
            New-Item -ItemType Directory -Force .godot-bin | Out-Null
            $url = "https://github.com/godotengine/godot/releases/download/4.7.2-stable/Godot_v4.7.2-stable_win64.exe.zip"
            Invoke-WebRequest $url -OutFile godot.zip
            Expand-Archive godot.zip -DestinationPath .godot-bin -Force
            Rename-Item .godot-bin/Godot_v4.7.2-stable_win64.exe Godot.exe
          }
      - name: Gate
        shell: pwsh
        run: ./tools/gate.ps1 -Full -GodotExe ./.godot-bin/Godot.exe
      - name: PCK packaging
        shell: pwsh
        run: ./tools/build_release.ps1 -PackOnly -GodotExe ./.godot-bin/Godot.exe
```

> 测试失败时 `run_tests.gd` 返回 1，门禁阻断合并。

### 5.2 质量门

| 门 | 失败处理 |
|---|---|
| 导入成功 | 阻止合并 |
| 脚本解析无错误 | 阻止合并 |
| 单元测试全绿 | 阻止合并 |
| 新增警告 | 警告，不阻止（里程碑前清零） |
| 导出成功（main） | 阻止发布 |

## 6. 版本号与变更日志

| 项 | 规则 |
|---|---|
| 语义化版本 | `MAJOR.MINOR.PATCH` |
| 构建号 | `0.1.0+20261019`（写入关于页/日志） |
| 版本来源 | `project.godot` 的 `config/version`（单一来源） |
| 变更日志 | `CHANGELOG.md`，按 Keep a Changelog 分组 |

发布前：

1. 更新版本号与 `CHANGELOG.md`。
2. 打标签 `v0.1.0`。
3. CI 导出并附 artifact。
4. 发布说明写"新增/修复/已知问题"。

## 8. 日常命令

```bash
# 本地导入（不打开编辑器）
godot --headless --path . --import

# 跑测试
godot --headless --path . --script res://tests/run_tests.gd

# 导出（示例）
godot --headless --path . --export-release "Windows Desktop" build/StickmanPet.exe
```

> 把常用命令写进 `tools/dev.ps1`，避免每次手敲。
